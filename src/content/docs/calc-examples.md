## 1. ผลคูณจุดและขนาดเวกเตอร์

สูตรที่ใช้: $\mathbf{a}\cdot\mathbf{b} = \sum a_i b_i$ และ $\lvert\mathbf{v}\rvert = \sqrt{\sum v_i^2}$ ([บท 02](/module/02#topic-3))

> [!question]- โจทย์ 1.1: กำหนด $\mathbf{u} = (2, -3, 1)$ และ $\mathbf{v} = (4, 0, -2)$ จงหา $\mathbf{u}+\mathbf{v}$, $\mathbf{u}-\mathbf{v}$, $\mathbf{u}\cdot\mathbf{v}$ และ $\lvert\mathbf{v}\rvert$
> > [!success]- วิธีทำ
> > การบวกและลบทำทีละตำแหน่ง
> > $$\mathbf{u}+\mathbf{v} = (2+4,\ -3+0,\ 1+(-2)) = (6, -3, -1)$$
> > $$\mathbf{u}-\mathbf{v} = (2-4,\ -3-0,\ 1-(-2)) = (-2, -3, 3)$$
> > ผลคูณจุดคือผลรวมของผลคูณทีละตำแหน่ง (เหมือนที่ `dotv` วนซ้ำบวกสะสม)
> > $$\mathbf{u}\cdot\mathbf{v} = 2(4) + (-3)(0) + 1(-2) = 8 + 0 - 2 = 6$$
> > ขนาดของ $\mathbf{v}$
> > $$\lvert\mathbf{v}\rvert = \sqrt{4^2 + 0^2 + (-2)^2} = \sqrt{16 + 0 + 4} = \sqrt{20} \approx 4.472$$
> >
> > ![ผลคูณจุดของ u = (2, −3, 1) กับ v = (4, 0, −2) แบบคูณทีละตำแหน่งแล้วบวกรวมได้ 6 และขนาดของ v เท่ากับรากที่สองของ 20](/infographics/calc/dot-product-1-1.svg)
> >
> > อ่านภาพจากบนลงล่าง: แถวสีน้ำเงินคือ $\mathbf{u}$ แถวสีส้มคือ $\mathbf{v}$ แต่ละคอลัมน์คือตำแหน่งเดียวกันซึ่งต้องคูณกัน กล่องสีเขียวคือผลคูณทีละตำแหน่ง $8, 0, -2$ แล้วบวกรวมได้กล่องสีม่วง $= 6$ บรรทัดล่างสุดใช้หลักเดียวกันกับ $\mathbf{v}$ คูณตัวเอง (ยกกำลังสอง) ก่อนถอดรากจึงได้ขนาดเวกเตอร์
> >
> > **คำตอบ:** $(6,-3,-1)$, $(-2,-3,3)$, $6$, $\sqrt{20} \approx 4.472$

> [!question]- โจทย์ 1.2: เวกเตอร์ $(3, 4)$ และ $(-4, 3)$ ตั้งฉากกันหรือไม่ จงแสดงเหตุผลด้วยผลคูณจุด และบอกขนาดของเวกเตอร์ทั้งสอง
> > [!success]- วิธีทำ
> > จาก $\mathbf{a}\cdot\mathbf{b} = \lvert\mathbf{a}\rvert\lvert\mathbf{b}\rvert\cos\theta$ ถ้าผลคูณจุดเป็น 0 แสดงว่า $\cos\theta = 0$ คือ $\theta = 90°$
> > $$(3)(-4) + (4)(3) = -12 + 12 = 0$$
> > จึง **ตั้งฉากกัน** ขนาดของทั้งสอง
> > $$\sqrt{3^2 + 4^2} = \sqrt{25} = 5 \qquad \sqrt{(-4)^2 + 3^2} = \sqrt{25} = 5$$
> > ขนาดเท่ากันเพราะ $(-4, 3)$ คือ $(3, 4)$ ที่หมุน 90° ด้วยกฎ $(x, y) \to (-y, x)$ (ดูหมวด 4)
> >
> > ![เวกเตอร์ (3, 4) สีน้ำเงินและ (−4, 3) สีส้มบนระนาบพิกัด ทำมุมฉากกันที่จุดกำเนิด แต่ละตัวเป็นด้านตรงข้ามมุมฉากของสามเหลี่ยม 3-4-5](/infographics/calc/perpendicular-1-2.svg)
> >
> > ภาพวาดตามสเกล 1 ช่อง = 1 หน่วย เส้นประคือด้านประกอบมุมฉาก 3 และ 4 ของแต่ละเวกเตอร์ ความยาวลูกศรจึงเป็น $\sqrt{3^2+4^2} = 5$ เท่ากัน เครื่องหมายมุมฉากสีม่วงที่จุดกำเนิดยืนยันผลคูณจุดที่เป็น 0
> >
> > **คำตอบ:** ตั้งฉาก (ผลคูณจุด = 0) ขนาด 5 ทั้งคู่

> [!question]- โจทย์ 1.3: จงหา `lenv((1, 2, 3, 4))` และมุมระหว่าง $\mathbf{a} = (1, 2, 3)$ กับ $\mathbf{b} = (1, 0, 1)$ (ตอบเป็นองศา ทศนิยม 1 ตำแหน่ง)
> > [!success]- วิธีทำ
> > `lenv` บวกกำลังสองของทุกสมาชิกแล้วถอดราก
> > $$\sqrt{1 + 4 + 9 + 16} = \sqrt{30} \approx 5.477$$
> > มุมระหว่างเวกเตอร์หาจาก $\cos\theta = \dfrac{\mathbf{a}\cdot\mathbf{b}}{\lvert\mathbf{a}\rvert\lvert\mathbf{b}\rvert}$
> > $$\mathbf{a}\cdot\mathbf{b} = 1 + 0 + 3 = 4 \qquad \lvert\mathbf{a}\rvert = \sqrt{14} \approx 3.742 \qquad \lvert\mathbf{b}\rvert = \sqrt{2} \approx 1.414$$
> > $$\cos\theta = \frac{4}{\sqrt{14}\sqrt{2}} = \frac{4}{\sqrt{28}} \approx \frac{4}{5.292} \approx 0.756 \quad\Rightarrow\quad \theta = \cos^{-1}(0.756) \approx 40.9°$$
> > **คำตอบ:** $\sqrt{30} \approx 5.477$ และ $\theta \approx 40.9°$

> [!question]- โจทย์ 1.4 (แนวข้อสอบชุดที่ 2): กำหนด $\mathbf{a} = (2, -1, 3)$ และ $\mathbf{c} = (4, 0, -2)$ จงหา $\mathbf{a}\cdot\mathbf{c}$ (ผลลัพธ์ของ `dotv(a, c)`)
> > [!success]- วิธีทำ
> > สูตรผลคูณจุดของเวกเตอร์ 3 มิติ
> > $$\mathbf{a}\cdot\mathbf{c} = a_1c_1 + a_2c_2 + a_3c_3$$
> > แทนค่าทีละตำแหน่ง (ใส่วงเล็บให้จำนวนลบเสมอ)
> > $$\mathbf{a}\cdot\mathbf{c} = (2)(4) + (-1)(0) + (3)(-2)$$
> > $$= 8 + 0 + (-6) = 2$$
> >
> > ![ผลคูณจุดของ a = (2, −1, 3) กับ c = (4, 0, −2) คูณทีละตำแหน่งได้ 8, 0, −6 รวมเป็น 2](/infographics/calc/dot-product-1-4.svg)
> >
> > แต่ละคอลัมน์ในภาพคือคู่ที่ต้องคูณกัน ตำแหน่งที่ 1 คูณกับ 0 จึงหายไป และตำแหน่งที่ 2 ได้ค่าลบ $-6$ ซึ่งหักล้างกับ $8$ จนเหลือ $2$ ผลคูณจุดเป็นบวกแปลว่ามุมระหว่าง $\mathbf{a}$ กับ $\mathbf{c}$ น้อยกว่า 90°
> >
> > **คำตอบ:** $\mathbf{a}\cdot\mathbf{c} = 2$

> [!question]- โจทย์ 1.5 (แนวข้อสอบชุดที่ 3): กำหนด $\mathbf{a} = (3, -2, 5)$ และ $\mathbf{c} = (1, 4, 2)$ จงหา $\mathbf{a}\cdot\mathbf{c}$
> > [!success]- วิธีทำ
> > $$\mathbf{a}\cdot\mathbf{c} = a_1c_1 + a_2c_2 + a_3c_3$$
> > $$= (3)(1) + (-2)(4) + (5)(2)$$
> > $$= 3 + (-8) + 10 = 5$$
> >
> > ![ผลคูณจุดของ a = (3, −2, 5) กับ c = (1, 4, 2) คูณทีละตำแหน่งได้ 3, −8, 10 รวมเป็น 5](/infographics/calc/dot-product-1-5.svg)
> >
> > ผลคูณของตำแหน่งกลาง $(-2)(4) = -8$ เป็นค่าลบเพียงตัวเดียว ให้บวกรวมทีละขั้น $3 - 8 = -5$ แล้ว $-5 + 10 = 5$ เพื่อลดโอกาสผิดเครื่องหมาย
> >
> > **คำตอบ:** $\mathbf{a}\cdot\mathbf{c} = 5$

## 2. เวกเตอร์หนึ่งหน่วยและ scale_to_length

สูตรที่ใช้: $\hat{\mathbf{v}} = \mathbf{v}/\lvert\mathbf{v}\rvert$ และ `scale_to_length(L)` $= \hat{\mathbf{v}} \times L$ ([บท 07](/module/07), [บท 08](/module/08))

> [!question]- โจทย์ 2.1: จงหาเวกเตอร์หนึ่งหน่วยของ $(-5, 12)$ และตรวจสอบว่าขนาดของผลลัพธ์เท่ากับ 1
> > [!success]- วิธีทำ
> > $$\lvert\mathbf{v}\rvert = \sqrt{(-5)^2 + 12^2} = \sqrt{25 + 144} = \sqrt{169} = 13$$
> > $$\hat{\mathbf{v}} = \left(\frac{-5}{13},\ \frac{12}{13}\right) \approx (-0.385,\ 0.923)$$
> > ตรวจสอบ: $\left(\frac{-5}{13}\right)^2 + \left(\frac{12}{13}\right)^2 = \frac{25 + 144}{169} = 1$ ✓
> > **คำตอบ:** $(-5/13,\ 12/13) \approx (-0.385, 0.923)$

> [!question]- โจทย์ 2.2: ศัตรูสีแดงอยู่ที่ $(50, 50)$ ผู้เล่นอยู่ที่ $(110, 130)$ ใน `red_enemy.py` ศัตรูเร่งเข้าหาผู้เล่นด้วย `self.vel += direction.normalize() * 0.1` จงหาเวกเตอร์ความเร่งที่ถูกบวกเข้าความเร็วในเฟรมนี้
> > [!success]- วิธีทำ
> > เวกเตอร์จากศัตรูไปผู้เล่น = ผู้เล่น − ศัตรู
> > $$\mathbf{d} = (110 - 50,\ 130 - 50) = (60, 80)$$
> > $$\lvert\mathbf{d}\rvert = \sqrt{60^2 + 80^2} = \sqrt{3600 + 6400} = \sqrt{10000} = 100$$
> > $$\hat{\mathbf{d}} = (60/100,\ 80/100) = (0.6, 0.8)$$
> > คูณด้วย 0.1
> > $$\mathbf{a} = (0.6 \times 0.1,\ 0.8 \times 0.1) = (0.06, 0.08)$$
> > **คำตอบ:** ความเร่ง $(0.06, 0.08)$ พิกเซล/เฟรม² (ขนาด 0.1)

> [!question]- โจทย์ 2.3: (ก) ยานมีความเร็ว $(-9, 12)$ ซึ่งเกิน `max_speed = 5` จงหาความเร็วหลังเรียก `scale_to_length(5)` (ข) ยานอยู่ที่ $(100, 100)$ เมาส์อยู่ที่ $(-20, 260)$ และ `bullet_speed = 15` จงหาความเร็วกระสุนตามโค้ดใน `main.py` ของบท 08
> > [!success]- วิธีทำ
> > **(ก)** `scale_to_length(L)` คงทิศแต่เปลี่ยนขนาดเป็น $L$
> > $$\lvert\mathbf{v}\rvert = \sqrt{81 + 144} = \sqrt{225} = 15 \qquad \hat{\mathbf{v}} = (-9/15,\ 12/15) = (-0.6, 0.8)$$
> > $$\mathbf{v}_{new} = (-0.6 \times 5,\ 0.8 \times 5) = (-3, 4)$$
> > ตรวจ: $\sqrt{9 + 16} = 5$ ✓
> >
> > ![ความเร็ว (−9, 12) ยาว 15 ถูกย่อเหลือ (−3, 4) ยาว 5 ตามทิศเดิม โดยผ่านเวกเตอร์หนึ่งหน่วย (−0.6, 0.8)](/infographics/calc/scale-to-length-2-3.svg)
> >
> > ภาพใช้พิกัดจอ (แกน y ชี้ลง) วาดตามสเกล 1 ช่อง = 1 พิกเซล/เฟรม ลูกศรประสีแดงคือความเร็วเดิมที่ยาว 15 ลูกศรสีม่วงคือเวกเตอร์หนึ่งหน่วย และลูกศรสีเขียวคือผลของ `scale_to_length(5)` ซึ่งปลายแตะวงกลมรัศมี 5 พอดี ทั้งสามลูกศรอยู่บนเส้นตรงเดียวกัน แสดงว่าทิศไม่เปลี่ยน เปลี่ยนเฉพาะความยาว
> >
> > **(ข)** `dx = mouse_x - cx`, `dy = mouse_y - cy`
> > $$\mathbf{d} = (-20 - 100,\ 260 - 100) = (-120, 160) \qquad \lvert\mathbf{d}\rvert = \sqrt{14400 + 25600} = \sqrt{40000} = 200$$
> > $$\hat{\mathbf{d}} = (-0.6, 0.8) \qquad \mathbf{v}_{bullet} = (-0.6 \times 15,\ 0.8 \times 15) = (-9, 12)$$
> > **คำตอบ:** (ก) $(-3, 4)$ (ข) $(-9, 12)$

> [!question]- โจทย์ 2.4 (แนวข้อสอบชุดที่ 2): (ก) ผู้เล่นกดปุ่ม **ซ้าย** และ **ลง** พร้อมกัน ทำให้ `input_dir = (-1, 1)` จงหา `input_dir.normalize()` (ข) ยานอยู่ที่ $(200, 100)$ เมาส์อยู่ที่ $(-40, 420)$ และ `bullet_speed = 15` จงหาความเร็วกระสุน (`bullet_vx = direction.x * bullet_speed`, `bullet_vy = direction.y * bullet_speed` โดย `direction` คือเวกเตอร์หนึ่งหน่วยจากยานไปเมาส์)
> > [!success]- วิธีทำ
> > **(ก)** หาขนาดก่อน แล้วหารแต่ละองค์ประกอบด้วยขนาด
> > $$\lvert\mathbf{v}\rvert = \sqrt{(-1)^2 + 1^2} = \sqrt{2} \approx 1.414$$
> > $$\hat{\mathbf{v}} = \left(\frac{-1}{\sqrt2},\ \frac{1}{\sqrt2}\right) \approx (-0.707,\ 0.707)$$
> > เหตุผลที่ต้อง normalize: ถ้าใช้ $(-1, 1)$ ตรง ๆ ยานจะเดินทแยงเร็วกว่าแนวตรง $\sqrt2 \approx 1.414$ เท่า
> >
> > **(ข)** เวกเตอร์จากยานไปเมาส์ = เมาส์ − ยาน
> > $$\mathbf{d} = (-40 - 200,\ 420 - 100) = (-240,\ 320)$$
> > $$\lvert\mathbf{d}\rvert = \sqrt{(-240)^2 + 320^2} = \sqrt{57600 + 102400} = \sqrt{160000} = 400$$
> > $$\hat{\mathbf{d}} = \left(\frac{-240}{400},\ \frac{320}{400}\right) = (-0.6,\ 0.8)$$
> > $$\mathbf{v}_{bullet} = (-0.6 \times 15,\ 0.8 \times 15) = (-9,\ 12)$$
> >
> > ![ซ้าย: input_dir (−1, 1) ยาวราก 2 ถูกย่อเป็น (−0.707, 0.707) บนวงกลมหนึ่งหน่วย ขวา: เวกเตอร์จากยาน (200, 100) ไปเมาส์ (−40, 420) มี dx = −240, dy = 320 และยาว 400](/infographics/calc/unit-bullet-2-4.svg)
> >
> > กรอบซ้ายวาดตามสเกลของเวกเตอร์ทิศ ลูกศรประสีส้มยาว $\sqrt2$ ยื่นออกนอกวงกลมหนึ่งหน่วย ส่วนลูกศรสีม่วงหลัง normalize ปลายแตะวงกลมพอดี กรอบขวาวาดตามสเกลพิกเซลของจอ (y ชี้ลง) เส้นประสีส้มคือ dx และ dy ซึ่งเป็นสามเหลี่ยมมุมฉาก 3-4-5 ขยาย 80 เท่า แถวล่างสรุป 4 ขั้นที่ต้องเขียนในกระดาษคำตอบ
> >
> > **คำตอบ:** (ก) $\approx(-0.707,\ 0.707)$ (ข) $(-9,\ 12)$

> [!question]- โจทย์ 2.5 (แนวข้อสอบชุดที่ 3): (ก) ผู้เล่นกดปุ่ม **ซ้าย** และ **ขึ้น** พร้อมกัน ทำให้ `input_dir = (-1, -1)` จงหา `input_dir.normalize()` (ข) ยานอยู่ที่ $(100, 100)$ เมาส์อยู่ที่ $(220, 260)$ และ `bullet_speed = 20` จงหาความเร็วกระสุน
> > [!success]- วิธีทำ
> > **(ก)** ปุ่มขึ้นทำให้ y ลดลง (พิกัดจอ) จึงได้ $(-1, -1)$
> > $$\lvert\mathbf{v}\rvert = \sqrt{(-1)^2 + (-1)^2} = \sqrt{2} \approx 1.414$$
> > $$\hat{\mathbf{v}} = \left(\frac{-1}{\sqrt2},\ \frac{-1}{\sqrt2}\right) \approx (-0.707,\ -0.707)$$
> >
> > **(ข)**
> > $$\mathbf{d} = (220 - 100,\ 260 - 100) = (120,\ 160)$$
> > $$\lvert\mathbf{d}\rvert = \sqrt{120^2 + 160^2} = \sqrt{14400 + 25600} = \sqrt{40000} = 200$$
> > $$\hat{\mathbf{d}} = \left(\frac{120}{200},\ \frac{160}{200}\right) = (0.6,\ 0.8)$$
> > $$\mathbf{v}_{bullet} = (0.6 \times 20,\ 0.8 \times 20) = (12,\ 16)$$
> > ตรวจ: $\sqrt{12^2 + 16^2} = \sqrt{400} = 20$ เท่ากับ `bullet_speed` ✓
> >

## 3. การคูณเมทริกซ์

สูตรที่ใช้: $c_{ij} = \text{แถว } i \text{ ของ } A \cdot \text{คอลัมน์ } j \text{ ของ } B$ ([บท 06](/module/06))

> [!question]- โจทย์ 3.1: จงหา $\begin{bmatrix}1&-1\\2&0\end{bmatrix}\begin{bmatrix}3&1\\1&2\end{bmatrix}$
> > [!success]- วิธีทำ
> > สมาชิกแต่ละตัวคือผลคูณจุดระหว่างแถวของตัวตั้งกับคอลัมน์ของตัวคูณ
> > $$c_{11} = (1)(3) + (-1)(1) = 2 \qquad c_{12} = (1)(1) + (-1)(2) = -1$$
> > $$c_{21} = (2)(3) + (0)(1) = 6 \qquad c_{22} = (2)(1) + (0)(2) = 2$$
> >
> > ![การคูณเมทริกซ์ 2×2 แยกเป็น 4 การ์ด แต่ละการ์ดไฮไลต์แถวของเมทริกซ์ตัวตั้งด้วยสีน้ำเงินและคอลัมน์ของตัวคูณด้วยสีส้ม ได้ผลลัพธ์ 2, −1, 6, 2](/infographics/calc/matrix-multiply-3-1.svg)
> >
> > แถวบนแสดงภาพรวม $A \times B = C$ การ์ด 4 ใบด้านล่างคือการหาช่องละหนึ่งค่า เช่น $c_{12}$ ใช้แถว 1 ของตัวตั้ง (น้ำเงิน) จับคู่กับคอลัมน์ 2 ของตัวคูณ (ส้ม) แล้วคูณคู่ที่ตรงกันและบวกรวม $1(1) + (-1)(2) = -1$ จำง่าย ๆ ว่าตำแหน่ง $c_{ij}$ บอกว่าใช้แถว $i$ กับคอลัมน์ $j$
> >
> > **คำตอบ:** $\begin{bmatrix}2&-1\\6&2\end{bmatrix}$

> [!question]- โจทย์ 3.2: กำหนด $A = \begin{bmatrix}2&5\\-1&3\end{bmatrix}$ และ $I$ คือเมทริกซ์เอกลักษณ์ 2×2 จงหา $A + I$ และ $AI$
> > [!success]- วิธีทำ
> > $I = \begin{bmatrix}1&0\\0&1\end{bmatrix}$ การบวกทำทีละตำแหน่ง
> > $$A + I = \begin{bmatrix}2+1&5+0\\-1+0&3+1\end{bmatrix} = \begin{bmatrix}3&5\\-1&4\end{bmatrix}$$
> > การคูณกับเมทริกซ์เอกลักษณ์ได้ตัวเดิม (ตรวจ: $c_{11} = 2(1) + 5(0) = 2$, $c_{12} = 2(0) + 5(1) = 5$ …)
> > $$AI = \begin{bmatrix}2&5\\-1&3\end{bmatrix} = A$$
> > นี่คือเหตุผลที่ `np.matmul(A, B)` ใน `02_matix_operate.py` ได้ค่าเท่ากับ `A` เมื่อ `B` เป็นเมทริกซ์เอกลักษณ์
> > **คำตอบ:** $A + I = \begin{bmatrix}3&5\\-1&4\end{bmatrix}$, $AI = A$

> [!question]- โจทย์ 3.3: กำหนด `P = np.array([[1,2],[3,4]])` และ `Q = np.array([[0,1],[1,0]])` จงหา `P @ Q`, `Q @ P` และ `P * P` แล้วสรุปข้อสังเกต
> > [!success]- วิธีทำ
> > $$PQ = \begin{bmatrix}1(0)+2(1) & 1(1)+2(0)\\ 3(0)+4(1) & 3(1)+4(0)\end{bmatrix} = \begin{bmatrix}2&1\\4&3\end{bmatrix} \quad(\text{สลับคอลัมน์ของ } P)$$
> > $$QP = \begin{bmatrix}0(1)+1(3) & 0(2)+1(4)\\ 1(1)+0(3) & 1(2)+0(4)\end{bmatrix} = \begin{bmatrix}3&4\\1&2\end{bmatrix} \quad(\text{สลับแถวของ } P)$$
> > `P * P` ใน NumPy คือคูณทีละตำแหน่ง ไม่ใช่การคูณเมทริกซ์
> > $$P * P = \begin{bmatrix}1&4\\9&16\end{bmatrix} \qquad\text{ส่วน}\qquad P @ P = \begin{bmatrix}7&10\\15&22\end{bmatrix}$$
> > **คำตอบ:** $PQ = \begin{bmatrix}2&1\\4&3\end{bmatrix} \ne QP = \begin{bmatrix}3&4\\1&2\end{bmatrix}$ (การคูณเมทริกซ์ไม่สลับที่) และ $P * P = \begin{bmatrix}1&4\\9&16\end{bmatrix}$

## 4. เมทริกซ์การหมุน (รอบจุดกำเนิดและรอบจุดอื่น)

สูตรที่ใช้: $(x, y) \to (x\cos\theta - y\sin\theta,\ x\sin\theta + y\cos\theta)$ และหมุนรอบ $\mathbf{c}$: $R(\mathbf{p}-\mathbf{c}) + \mathbf{c}$ ([บท 06](/module/06))

> [!question]- โจทย์ 4.1: จงหมุนจุด $(0, 6)$ รอบจุดกำเนิดเป็นมุม $90°$ และ $30°$
> > [!success]- วิธีทำ
> > **มุม 90°:** $\cos 90° = 0$, $\sin 90° = 1$
> > $$x' = 0(0) - 6(1) = -6 \qquad y' = 0(1) + 6(0) = 0 \quad\Rightarrow\quad (-6, 0)$$
> > (ตรงกับกฎลัด $(x, y) \to (-y, x)$)
> >
> > **มุม 30°:** $\cos 30° = \sqrt3/2 \approx 0.866$, $\sin 30° = 0.5$
> > $$x' = 0(0.866) - 6(0.5) = -3 \qquad y' = 0(0.5) + 6(0.866) = 5.196$$
> > ตรวจระยะจากจุดกำเนิด: $\sqrt{9 + 27} = \sqrt{36} = 6$ เท่าเดิม ✓
> >
> > ![จุด (0, 6) สีน้ำเงินถูกหมุน 30° ไปที่ (−3, 5.196) สีเขียว และหมุน 90° ไปที่ (−6, 0) สีม่วง ทุกจุดอยู่บนวงกลมรัศมี 6](/infographics/calc/rotation-4-1.svg)
> >
> > ภาพวาดตามสเกล 1 ช่อง = 1 หน่วย แกน y ชี้ขึ้นแบบคณิตศาสตร์ ส่วนโค้งพร้อมหัวลูกศรแสดงว่ามุมบวกหมุนทวนเข็มนาฬิกาจากตำแหน่งเดิม ปลายลูกศรทั้งสามแตะวงกลมเส้นประรัศมี 6 เดียวกัน ยืนยันว่าการหมุนไม่เปลี่ยนระยะจากจุดกำเนิด
> >
> > **คำตอบ:** $90°: (-6, 0)$; $30°: (-3,\ 5.196)$

> [!question]- โจทย์ 4.2: จงหมุนจุด $(5, 1)$ รอบจุดศูนย์กลาง $(2, 1)$ เป็นมุม $180°$ (ตามโค้ด `R.dot(world_pos - ori_pos) + ori_pos`)

> > **ขั้นที่ 2 หมุน** 180°: $\cos 180° = -1$, $\sin 180° = 0$
> > $$x' = 3(-1) - 0(0) = -3 \qquad y' = 3(0) + 0(-1) = 0 \quad\Rightarrow\quad (-3, 0)$$
> > **ขั้นที่ 3 เลื่อนกลับ:** $(-3 + 2,\ 0 + 1) = (-1, 1)$
> > ตรวจ: ระยะจาก $(2,1)$ ถึง $(5,1)$ คือ 3 และถึง $(-1,1)$ คือ 3 เท่ากัน ✓
> >
> > ![การหมุนจุด (5, 1) รอบ (2, 1) เป็น 180° แบ่งเป็น 3 กรอบ: เลื่อนได้ (3, 0), หมุนได้ (−3, 0), เลื่อนกลับได้ (−1, 1)](/infographics/calc/rotate-about-center-4-2.svg)

> [!question]- โจทย์ 4.3: (ก) จงหมุนจุด $(7, 3)$ รอบจุด $(3, 3)$ เป็นมุม $90°$ (ข) ใน `04_matrix_animate.py` ถ้าเปลี่ยนมุมเป็น `theta_deg = frame * 3` ต้องใช้กี่เฟรมจึงหมุนครบรอบ

> [!question]- โจทย์ 4.4 (แนวข้อสอบชุดที่ 2): (ก) จงหมุนจุด $(0, 8)$ รอบจุดกำเนิดเป็นมุม $30°$ (ตอบทศนิยม 2 ตำแหน่ง) (ข) ใน `04_matrix_animate.py` ถ้าใช้ `theta_deg = frame * 3` และ `frames=120` ที่เฟรมที่ 50 จุดหมุนไปแล้วกี่องศา และตลอดแอนิเมชันหมุนรวมกี่องศา

> > (เฟรม 0–119 แสดงมุม 0°–357° แล้ววนกลับมาที่ 0° ซึ่งเท่ากับ 360°)

> >
> > **คำตอบ:** (ก) $(-4.00,\ 6.93)$ (ข) $150°$ และรวม $360°$

> [!question]- โจทย์ 4.5 (แนวข้อสอบชุดที่ 3): (ก) จงหมุนจุด $(4, 0)$ รอบจุดกำเนิดเป็นมุม $60°$ (ตอบทศนิยม 2 ตำแหน่ง) (ข) ถ้าใช้ `theta_deg = frame * 4` และ `frames=90` ที่เฟรมที่ 30 หมุนไปแล้วกี่องศา และหมุนรวมกี่องศา

> > $$y' = x\sin\theta + y\cos\theta = 4(0.866) + 0(0.5) = 2\sqrt3 \approx 3.46$$

> >
> > **คำตอบ:** (ก) $(2.00,\ 3.46)$ (ข) $120°$ และรวม $360°$

## 5. องศา เรเดียน และ atan2 (มุมเป้าหมายของยาน)

สูตรที่ใช้: $\theta_{rad} = \theta_{deg} \times \pi/180$ และ `target_angle = degrees(atan2(-input_dir.y, input_dir.x)) - 90` ([บท 06](/module/06))

> [!question]- โจทย์ 5.1: จงแปลง $210°$ เป็นเรเดียน (ตอบทั้งรูป $\pi$ และทศนิยม 3 ตำแหน่ง) และแปลง $\pi/12$ เรเดียนเป็นองศา
> > [!success]- วิธีทำ
> > $$210° \times \frac{\pi}{180} = \frac{210\pi}{180} = \frac{7\pi}{6} \approx \frac{7 \times 3.1416}{6} \approx 3.665 \text{ rad}$$
> > $$\frac{\pi}{12} \times \frac{180}{\pi} = \frac{180}{12} = 15°$$
> > **คำตอบ:** $7\pi/6 \approx 3.665$ rad และ $15°$

> [!question]- โจทย์ 5.2: ผู้เล่นกดปุ่ม **ลง** และ **ซ้าย** พร้อมกัน ทำให้ `input_dir = (-1, 1)` จงหา `target_angle` ตามโค้ด `math.degrees(math.atan2(-input_dir.y, input_dir.x)) - 90`
> > [!success]- วิธีทำ
> > แทนค่า: `atan2(-input_dir.y, input_dir.x)` = `atan2(-1, -1)`
> > เวกเตอร์ $(-1, -1)$ อยู่ในจตุภาคที่ 3 (x ลบ y ลบ) `atan2` คืนมุมในช่วง $(-180°, 180°]$ จึงได้
> > $$\text{atan2}(-1, -1) = -135°$$
> > (ไม่ใช่ $+45°$ ซึ่งเป็นค่าของ $\tan^{-1}(1)$ — นี่คือเหตุผลที่ใช้ `atan2` แทน `atan`)
> > $$\text{target\_angle} = -135 - 90 = -225°$$
> >
> > ![สามขั้นจากปุ่มที่กดไปเป็นมุมของยาน: ① input_dir (−1, 1) ชี้ลงซ้ายบนจอ ② กลับแกน y ได้ (−1, −1) และ atan2 ให้ −135° ไม่ใช่ 45° ③ ลบ 90° ได้ −225° ซึ่งเท่ากับหันทวนเข็ม 135° จากทิศขึ้น](/infographics/calc/atan2-5-2.svg)
> >
> > กรอบ ① ใช้พิกัดจอที่ y ชี้ลง ปุ่มลงจึงให้ y = +1 กรอบ ② โค้ดส่ง `-input_dir.y` เข้า `atan2` เพื่อแปลงเป็นแกนคณิตศาสตร์ ได้เวกเตอร์ $(-1, -1)$ ในจตุภาคที่ 3 ส่วนโค้งสีแดงคือ $-135°$ (ลูกศรประสีเทาคือคำตอบผิด 45° ที่ได้จาก `atan`) กรอบ ③ ลบ 90° เพราะภาพยานหันขึ้นที่มุม 0° ผลคือยานหันลงซ้ายตรงกับปุ่มที่กดในกรอบ ①
> >
> > **คำตอบ:** $-225°$ (เทียบเท่า $135°$ เมื่อ mod 360 แต่โค้ดจะได้ $-225$ ตรง ๆ)

> [!question]- โจทย์ 5.3: (ก) กดปุ่มขึ้นและขวาพร้อมกัน `input_dir = (1, -1)` จงหา `target_angle` (ข) จุดบนวงโคจรรัศมี 8 ศูนย์กลาง $(2, 1)$ ที่มุม $180°$ อยู่ที่ใด (ตามสูตร `orbit_x = ori[0] + radius*cos`)
> > [!success]- วิธีทำ
> > **(ก)** `atan2(-(-1), 1)` = `atan2(1, 1)` เวกเตอร์ $(1, 1)$ อยู่จตุภาคที่ 1 → $45°$
> > $$\text{target\_angle} = 45 - 90 = -45°$$
> > ความหมาย: ยานหันขึ้น (0°) เอียงไปทางขวา 45° ตามที่ผู้เล่นกด
> >
> > **(ข)** $x = c_x + r\cos\theta$, $y = c_y + r\sin\theta$ โดย $\cos 180° = -1$, $\sin 180° = 0$
> > $$x = 2 + 8(-1) = -6 \qquad y = 1 + 8(0) = 1$$
> > **คำตอบ:** (ก) $-45°$ (ข) $(-6, 1)$

## 6. มุมที่สั้นที่สุดและ lerp

สูตรที่ใช้: `angle_diff = (target - angle) % 360` แล้วถ้า `> 180` ให้ `-= 360`; `angle += angle_diff * smoothness` ([บท 07](/module/07))

> [!question]- โจทย์ 6.1: ยานหันอยู่ที่ `angle = -30` และ `target_angle = 200` จงหา `angle_diff` แบบมุมที่สั้นที่สุด และบอกว่ายานควรหมุนไปทางใด
> > [!success]- วิธีทำ
> > $$\text{target} - \text{angle} = 200 - (-30) = 230$$
> > $$230 \bmod 360 = 230 \quad (\text{อยู่ในช่วง } [0, 360) \text{ อยู่แล้ว})$$
> > เนื่องจาก $230 > 180$ ทางที่สั้นกว่าคือหมุนย้อนกลับ
> > $$230 - 360 = -130$$
> >
> > ![วงกลมมุมแสดง angle = −30° สีน้ำเงินและ target = 200° สีส้ม ทางบวก 230° เป็นเส้นประสีแดง ทางลบ −130° เป็นเส้นสีเขียวที่สั้นกว่า](/infographics/calc/shortest-angle-6-1.svg)
> >
> > วงกลมใช้แบบแผนคณิตศาสตร์ คือ 0° อยู่ทางขวาและมุมบวกหมุนทวนเข็มนาฬิกา จากลูกศรสีน้ำเงินไปลูกศรสีส้มมีสองทาง ทางบวก (เส้นประสีแดง) ต้องหมุน 230° ส่วนทางลบ (สีเขียว) หมุนเพียง 130° ขั้นตอน "ถ้าเกิน 180 ให้ลบ 360" ในกรอบด้านขวาคือการเลือกทางสีเขียวเสมอ
> >
> > **คำตอบ:** `angle_diff = -130` ยานหมุนในทิศลบ 130° (แทนที่จะหมุนบวก 230°)

> [!question]- โจทย์ 6.2: `angle = 350`, `target_angle = 20`, `rotation_smoothness = 0.15` จงหา `angle_diff` และมุมของยานหลังอัปเดต 1 เฟรม
> > [!success]- วิธีทำ
> > $$20 - 350 = -330$$
> > มอดุโลของจำนวนลบในไพทอนได้ค่าบวกเสมอ (เครื่องหมายตามตัวหาร): $-330 = 360(-1) + 30$
> > $$(-330) \bmod 360 = 30 \quad (\le 180 \text{ จึงไม่ต้องลบ } 360)$$
> > lerp: $\text{angle}_{new} = \text{angle} + \text{angle\_diff} \times 0.15$
> > $$350 + 30 \times 0.15 = 350 + 4.5 = 354.5$$
> > **คำตอบ:** `angle_diff = 30` มุมใหม่ $354.5°$ (หมุนบวกผ่าน 360 ไปหา 20 ซึ่งห่างแค่ 30° ไม่ใช่ย้อน 330°)

> [!question]- โจทย์ 6.3: (ก) มุมต่างเริ่มต้น $80°$ และ `smoothness = 0.5` หลังอัปเดต 3 เฟรม เหลือมุมต่างเท่าใด (ข) จงหา $\text{lerp}(10, 50, 0.25)$
> > [!success]- วิธีทำ
> > **(ก)** ทุกเฟรมหมุนไป $t$ ของมุมที่เหลือ จึงเหลือ $(1 - t)$ เท่า → หลัง $n$ เฟรมเหลือ $d(1-t)^n$
> > $$80 \times (1 - 0.5)^3 = 80 \times 0.125 = 10°$$
> > (ไล่ทีละเฟรม: $80 \to 40 \to 20 \to 10$ ✓)
> >
> > **(ข)** $\text{lerp}(a, b, t) = a + (b - a)t$
> > $$10 + (50 - 10)(0.25) = 10 + 10 = 20$$
> > **คำตอบ:** (ก) $10°$ (ข) $20$

> [!question]- โจทย์ 6.4 (แนวข้อสอบชุดที่ 2): ยานหันอยู่ที่ `angle = -30` และ `target_angle = 200` จงหา `angle_diff` ตามโค้ด
> ```python
> angle_diff = (self.target_angle - self.angle) % 360
> if angle_diff > 180:
>     angle_diff -= 360
> ```
> > [!success]- วิธีทำ
> > (ตัวเลขชุดเดียวกับโจทย์ 6.1 แต่ข้อนี้ให้ไล่ตามบรรทัดของโค้ด)
> >
> > **บรรทัดที่ 1** ผลต่างดิบแล้วมอดุโล 360
> > $$\text{target} - \text{angle} = 200 - (-30) = 230$$
> > $$230 \bmod 360 = 230$$
> > **บรรทัดที่ 2–3** ตรวจว่าเกินครึ่งรอบหรือไม่
> > $$230 > 180 \quad\Rightarrow\quad \text{angle\_diff} = 230 - 360 = -130$$
> >
> > ![เส้นจำนวนสองเส้น: เส้นแรก 0 ถึง 360 มีจุด 230 อยู่ในโซนเกิน 180 สีแดง เส้นที่สอง −180 ถึง 180 มีจุด −130 อยู่ในช่วงทางสั้นสีเขียว](/infographics/calc/angle-diff-steps-6-4.svg)
> >
> > เส้นจำนวนบนคือผลหลัง `% 360` ซึ่งอยู่ในช่วง $[0, 360)$ เสมอ จุด 230 ตกอยู่ในโซนสีแดง (เกิน 180 = อ้อมไกล) การลบ 360 ย้ายจุดไปที่ $-130$ บนเส้นจำนวนล่าง ซึ่งอยู่ในช่วงทางสั้น $(-180, 180]$ เครื่องหมายลบบอกว่าหมุนทางลบ ขนาด 130 บอกว่าหมุนกี่องศา
> >
> > **คำตอบ:** `angle_diff = -130`

> [!question]- โจทย์ 6.5 (แนวข้อสอบชุดที่ 3): ยานหันอยู่ที่ `angle = 10` และ `target_angle = 350` จงหา `angle_diff` แบบมุมที่สั้นที่สุด และบอกทิศที่ยานหมุน
> > [!success]- วิธีทำ
> > $$\text{target} - \text{angle} = 350 - 10 = 340$$
> > $$340 \bmod 360 = 340$$
> > $$340 > 180 \quad\Rightarrow\quad \text{angle\_diff} = 340 - 360 = -20$$

## 7. แรงเสียดทานและจำนวนเฟรม (ใช้ log)

สูตรที่ใช้: $v_n = v_0 f^n$ และ $n > \dfrac{\ln(v_{min}/v_0)}{\ln f}$ ([บท 07](/module/07))

> [!question]- โจทย์ 7.1: ความเร็วเริ่มต้น 6 และ `friction = 0.8` (ก) หลัง 2 เฟรมเหลือเท่าใด (ข) ต้องผ่านไปกี่เฟรมจึงต่ำกว่า 2 (ใช้ $\ln(1/3) \approx -1.099$ และ $\ln 0.8 \approx -0.223$)
> > [!success]- วิธีทำ
> > **(ก)** $v_2 = 6 \times 0.8^2 = 6 \times 0.64 = 3.84$
> >
> > **(ข)** ต้องการ $6 \times 0.8^n < 2$ หารทั้งสองข้างด้วย 6: $0.8^n < 1/3$ ใส่ ln ทั้งสองข้าง
> > $$n \ln 0.8 < \ln\tfrac13$$
> > เนื่องจาก $\ln 0.8 < 0$ เมื่อหารต้อง **กลับเครื่องหมายอสมการ**
> > $$n > \frac{\ln(1/3)}{\ln 0.8} = \frac{-1.099}{-0.223} \approx 4.93$$
> > $n$ เป็นจำนวนเต็ม จึงปัดขึ้นเป็น 5
> > ตรวจ: $6 \times 0.8^4 = 2.458$ (ยังไม่ต่ำกว่า 2) และ $6 \times 0.8^5 = 1.966 < 2$ ✓
> >
> > ![กราฟแท่งความเร็ว 6 × 0.8 ยกกำลัง n สำหรับ n = 0 ถึง 7 พร้อมเส้นเกณฑ์ 2 สีแดง แท่ง n = 5 ค่า 1.966 เป็นแท่งแรกที่ต่ำกว่าเกณฑ์](/infographics/calc/friction-7-1.svg)
> >
> > ความสูงของแท่งเท่ากับค่าจริงของ $v_n$ แต่ละแท่งเตี้ยลงเหลือ 0.8 เท่าของแท่งก่อนหน้า แท่ง n = 2 คือคำตอบข้อ (ก) 3.84 ส่วนข้อ (ข) ดูว่าแท่งแรกที่ลงไปอยู่ใต้เส้นประสีแดงคือแท่งใด ซึ่งก็คือแท่ง n = 5 (สีเขียวเข้ม) ตรงกับค่า 4.92 ที่ได้จาก ln แล้วปัดขึ้น
> >
> > **คำตอบ:** (ก) $3.84$ (ข) 5 เฟรม

> [!question]- โจทย์ 7.2: ใน `space_move.py` ความเร็วเริ่มต้นมีขนาด 5 และ `velocity *= 0.97` ทุกเฟรม วงวนหยุดเมื่อ `np.linalg.norm(velocity) < 1` (ก) วงวนทำงานกี่รอบ (ข) ยานเคลื่อนที่ได้ระยะทางรวมไม่เกินเท่าใดถ้าไม่หยุด
> > [!success]- วิธีทำ
> > **(ก)** $5 \times 0.97^n < 1 \Rightarrow 0.97^n < 0.2$
> > $$n > \frac{\ln 0.2}{\ln 0.97} = \frac{-1.609}{-0.0305} \approx 52.8 \quad\Rightarrow\quad n = 53$$
> > ตรวจ: $5 \times 0.97^{52} \approx 1.026$ (ยังไม่หยุด) และ $5 \times 0.97^{53} \approx 0.995 < 1$ (หยุด) ✓
> >
> > **(ข)** ระยะรวมคือผลรวมอนุกรมเรขาคณิตอนันต์ $v_0 + v_0 f + v_0 f^2 + \dots = \dfrac{v_0}{1 - f}$
> > $$\frac{5}{1 - 0.97} = \frac{5}{0.03} \approx 166.7 \text{ พิกเซล}$$
> >
> > ![กราฟเส้นความเร็ว 5 × 0.97 ยกกำลัง n ลดลงจาก 5 ตัดเส้นเกณฑ์ 1 ระหว่างรอบที่ 52 (1.026) กับรอบที่ 53 (0.995)](/infographics/calc/friction-line-7-2.svg)
> >
> > จุดสีน้ำเงินแต่ละจุดคือขนาดความเร็วหลังรอบที่ n ซึ่งลดลงช้า ๆ เพราะเหลือ 97% ทุกรอบ จุดสีส้ม (n = 52) ยังอยู่เหนือเส้นแดงเล็กน้อย จุดสีเขียว (n = 53) เป็นจุดแรกที่ต่ำกว่า 1 วงวนจึงหยุด ส่วนเส้นประสีเทาหลังจากนั้นคือค่าที่จะเกิดขึ้นถ้าไม่หยุด ซึ่งใช้คิดระยะรวมในข้อ (ข)
> >
> > **คำตอบ:** (ก) 53 รอบ (ข) ประมาณ 166.7 พิกเซล

> [!question]- โจทย์ 7.3: (ก) ความเร็วเริ่มต้น 10 และ `friction = 0.5` ต้องกี่เฟรมจึงต่ำกว่า 1 (ข) ลูกบอลกระทบพื้นด้วย `vy = 10` และ `BOUNCE_DAMPING = 0.9` กระทบครั้งที่ 3 จะเด้งขึ้นด้วยอัตราเร็วเท่าใด (ไม่คิดความโน้มถ่วงระหว่างกระทบ)
> > [!success]- วิธีทำ
> > **(ก)** $10 \times 0.5^n < 1 \Rightarrow 0.5^n < 0.1 \Rightarrow 2^n > 10$ ไล่ค่า: $2^3 = 8$ (ไม่พอ), $2^4 = 16$ ✓ หรือใช้ ln: $n > \ln 0.1 / \ln 0.5 = 3.32$ → 4
> > ตรวจ: $10, 5, 2.5, 1.25, 0.625$ → เฟรมที่ 4 ได้ $0.625 < 1$ ✓
> >
> > **(ข)** แต่ละครั้งที่กระทบ อัตราเร็วเหลือ 0.9 เท่า (ลำดับเรขาคณิตเช่นกัน)
> > $$10 \times 0.9^3 = 10 \times 0.729 = 7.29$$
> > **คำตอบ:** (ก) 4 เฟรม (ข) $7.29$

> [!question]- โจทย์ 7.4 (แนวข้อสอบชุดที่ 2): ยานมีความเร็วเริ่มต้นขนาด 8 และ `friction = 0.9` (ความเร็วคูณ 0.9 ทุกเฟรม) ต้องผ่านไปอย่างน้อยกี่เฟรมความเร็วจึงต่ำกว่า 1 (ใช้ $\ln 0.125 \approx -2.0794$ และ $\ln 0.9 \approx -0.10536$)
> > [!success]- วิธีทำ
> > ความเร็วหลัง $n$ เฟรม $v_n = v_0 f^n = 8 \times 0.9^n$ ต้องการ
> > $$8 \times 0.9^n < 1 \quad\Rightarrow\quad 0.9^n < \frac18 = 0.125$$
> > ใส่ ln ทั้งสองข้าง
> > $$n \ln 0.9 < \ln 0.125$$
> > หารด้วย $\ln 0.9$ ซึ่งเป็นลบ จึงต้อง **กลับเครื่องหมายอสมการ**
> > $$n > \frac{\ln 0.125}{\ln 0.9} = \frac{-2.0794}{-0.10536} \approx 19.74$$
> > จำนวนเฟรมเป็นจำนวนเต็ม จึงปัดขึ้นเป็น $n = 20$
> > ตรวจ: $8 \times 0.9^{19} \approx 1.081$ (ยังไม่ต่ำกว่า 1) และ $8 \times 0.9^{20} \approx 0.973 < 1$ ✓
> >

> [!question]- โจทย์ 7.5 (แนวข้อสอบชุดที่ 3): ความเร็วเริ่มต้น 10 และ `friction = 0.5` ต้องผ่านไปอย่างน้อยกี่เฟรมความเร็วจึงต่ำกว่า 1 (ใช้ $\ln 0.1 \approx -2.303$ และ $\ln 0.5 \approx -0.693$)

> > $$10 \times 0.5^n < 1 \quad\Rightarrow\quad 0.5^n < 0.1$$

> >
> > ![กราฟแท่งความเร็ว 10 × 0.5 ยกกำลัง n ลดลงครึ่งหนึ่งทุกเฟรม 10, 5, 2.5, 1.25, 0.625 แท่ง n = 4 เป็นแท่งแรกที่ต่ำกว่าเส้นเกณฑ์ 1](/infographics/calc/friction-7-5.svg)

## 9. การชนแบบ AABB และกริด

สูตรที่ใช้: จุดในกล่อง $x \le p_x \le x + w$ **และ** $y \le p_y \le y + h$; ช่องกริด $(\text{row}, \text{col}) = (y \mathbin{//} s,\ x \mathbin{//} s)$ ([บท 08](/module/08))

> [!question]- โจทย์ 9.4 (แนวข้อสอบชุดที่ 2): ใน `first_gam.py` ถ้าตั้งจอเป็น `WIDTH = 1000`, `HEIGHT = 800` จงหาจุดศูนย์กลางวงกลม รัศมี ความยาวด้าน `a` ของสี่เหลี่ยมจัตุรัสแนบใน และมุมบนซ้าย `(rect_x, rect_y)`
> ```python
> circle_x, circle_y = WIDTH//2, HEIGHT//2
> circle_radius = HEIGHT//2
> a = 2*math.sqrt(circle_radius**2/2)
> rect_x, rect_y = circle_x - a//2, circle_y - a//2
> ```
> > [!success]- วิธีทำ
> > **① จุดศูนย์กลางและรัศมี**

> > ตรงกับโค้ด $2\sqrt{r^2/2}$
> > $$a = 2\sqrt{\frac{400^2}{2}} = 2\sqrt{80000} \approx 2(282.843) \approx 565.69$$
> > **③ มุมบนซ้าย** `a//2` คือหารปัดเศษลง และเพราะ `a` เป็น float ผลจึงเป็น float
> > $$a \mathbin{//} 2 = 565.685\ldots \mathbin{//} 2 = 282.0$$

> > **คำตอบ:** ศูนย์กลาง $(500, 400)$, $r = 400$, $a \approx 565.69$, `(rect_x, rect_y) = (218.0, 118.0)`

## 10. การอ่านผลลัพธ์โปรแกรม (ลิสต์ สแตก f-string การวนซ้ำ)

> [!question]- โจทย์ 10.1: จงเขียนผลลัพธ์ของโปรแกรม

> >
> > | บรรทัด | xs หลังทำ | หมายเหตุ |

> >
> > **คำตอบ:** `[6, 7, 9, 3]`

> [!question]- โจทย์ 10.2: ใช้คลาส `Stack` จากบท 04 (มี `push`, `pop`, `peek`, `size`, `is_empty`) จงเขียนผลลัพธ์
> ```python
> s = Stack()

> ```

> > |---|---|
> > | push 10, 20, 30 | `[10, 20, 30]` |
> > | `pop()` | `[10, 20]` (ดึง 30 ออก) |
> > | `push(40)` | `[10, 20, 40]` |
> >
> > `peek()` คืนตัวบนสุดโดยไม่ดึงออก = 40, `size()` = 3, `is_empty()` = `False`
> >
> > ![สแตก 5 ภาพเรียงตามคำสั่ง push(10), push(20), push(30), pop() คืน 30, push(40) ตัวบนสุดระบายสีส้ม ภาพสุดท้ายมี 10, 20, 40](/infographics/calc/stack-10-2.svg)

> [!question]- โจทย์ 10.6 (แนวข้อสอบชุดที่ 2): จงเขียนผลลัพธ์ของโปรแกรม (โค้ดหาความกว้างคอลัมน์จาก `exam_table.py`)
> ```python
> table = [["Name", "Score"], ["Somchai", 9], ["Ann", 100]]
> num_cols = len(table[0])
> col_widths = [max(len(str(row[i])) for row in table) for i in range(num_cols)]
> line_length = sum(col_widths) + (num_cols * 3)
> print(col_widths, line_length)
> ```
> > [!success]- วิธีทำ
> > `num_cols = len(table[0]) = 2` อ่าน list comprehension จากในออกนอก: ทุกค่าในคอลัมน์ `i` → `str()` → `len()` → เลือกค่ามากสุด
> > $$\text{คอลัมน์ 0: } \max(\text{len}(\texttt{"Name"}), \text{len}(\texttt{"Somchai"}), \text{len}(\texttt{"Ann"})) = \max(4, 7, 3) = 7$$
> > $$\text{คอลัมน์ 1: } \max(\text{len}(\texttt{"Score"}), \text{len}(\texttt{"9"}), \text{len}(\texttt{"100"})) = \max(5, 1, 3) = 5$$
> > $$\text{line\_length} = (7 + 5) + 2 \times 3 = 12 + 6 = 18$$
> >
> > ![ตาราง 3 แถว 2 คอลัมน์พร้อมความยาวสตริงของแต่ละช่อง ช่องที่ยาวที่สุดของแต่ละคอลัมน์ระบายสีเขียว Somchai = 7 และ Score = 5 ด้านล่างเป็นไม้บรรทัด 18 ช่องตัวอักษร แบ่งเป็น 7 + 3 + 5 + 3](/infographics/calc/table-widths-10-6.svg)
> >
> > ตัวเลข "len" มุมขวาของแต่ละช่องคือความยาวหลังแปลงเป็นสตริง เช่น `9` กลายเป็น `"9"` ยาว 1 ช่องสีเขียวคือค่ามากที่สุดของคอลัมน์ซึ่งกลายเป็น `col_widths` ไม้บรรทัดด้านล่างวาด 1 ช่อง = 1 ตัวอักษร ส่วนสีเขียวคือความกว้างข้อมูล ส่วนสีส้มคือ +3 ต่อคอลัมน์ รวม 18 ช่อง
> >
> > **คำตอบ:** `[7, 5] 18`

> [!question]- โจทย์ 10.8 (แนวข้อสอบชุดที่ 2): วงวนเกมต่อไปนี้ทำงานประมาณกี่วินาที และแต่ละเฟรมห่างกันประมาณกี่มิลลิวินาที (สมมติว่าเครื่องคำนวณทันทุกเฟรม)
> ```python
> clock = pygame.time.Clock()
> FRAME_LIMIT = 900
> frame_count = 0
> running = True
> while running:
>     # ... อัปเดตและวาดวัตถุ ...
>     frame_count += 1
>     if frame_count >= FRAME_LIMIT:
>         running = False
>     clock.tick(30)
> ```
> > [!success]- วิธีทำ
> > `clock.tick(30)` จำกัดไว้ที่ 30 เฟรมต่อวินาที (FPS) และวงวนหยุดเมื่อครบ 900 เฟรม
> > $$\text{เวลา} = \frac{\text{FRAME\_LIMIT}}{\text{FPS}} = \frac{900}{30} = 30 \text{ วินาที}$$
> > $$\text{ระยะห่างต่อเฟรม} = \frac{1000}{30} \approx 33.3 \text{ มิลลิวินาที}$$
> >
> > ![แถบเวลา 900 เฟรมแบ่งเป็น 30 ช่อง ช่องละ 1 วินาที = 30 เฟรม พร้อมสเกลเฟรมด้านบนและวินาทีด้านล่าง](/infographics/calc/game-loop-10-8.svg)
> >
> > แต่ละช่องในแถบคือ 1 วินาทีซึ่งบรรจุ 30 เฟรม ตัวเลขสีน้ำเงินด้านบนคือหมายเลขเฟรม ตัวเลขด้านล่างคือวินาที เฟรมที่ 900 ตรงกับวินาทีที่ 30 พอดี
> >
> > **คำตอบ:** ประมาณ 30 วินาที และเฟรมละ ≈ 33.3 มิลลิวินาที

> [!question]- โจทย์ 10.9 (แนวข้อสอบชุดที่ 3): ใช้วงวนเกมเดียวกับโจทย์ 10.8 แต่ `FRAME_LIMIT = 1200` และ `clock.tick(50)` โปรแกรมทำงานประมาณกี่วินาที และแต่ละเฟรมห่างกันประมาณกี่มิลลิวินาที
> > [!success]- วิธีทำ
> > $$\text{เวลา} = \frac{1200}{50} = 24 \text{ วินาที} \qquad \text{ระยะห่างต่อเฟรม} = \frac{1000}{50} = 20 \text{ มิลลิวินาที}$$
> >
> > ![แถบเวลา 1200 เฟรมแบ่งเป็น 24 ช่อง ช่องละ 1 วินาที = 50 เฟรม](/infographics/calc/game-loop-10-9.svg)
> >
> > เทียบกับข้อ 10.8 แต่ละช่อง (1 วินาที) บรรจุเฟรมมากขึ้นเป็น 50 เฟรม ถึงจำนวนเฟรมรวมมากกว่า แต่ก็จบเร็วกว่า คือ 24 วินาที เพราะเฟรมถี่กว่า
> >
> > **คำตอบ:** ประมาณ 24 วินาที และเฟรมละ 20 มิลลิวินาที

> [!tip] เครื่องมือตรวจคำตอบด้วยไพทอน
> หลังทำโจทย์บนกระดาษ ให้ตรวจด้วยโค้ดสั้น ๆ เหล่านี้ (ใช้ได้กับทุกหมวดข้างต้น)
> ```python
> import math

>
> # หมวด 1–2: ผลคูณจุด ขนาด เวกเตอร์หนึ่งหน่วย

>
> # หมวด 3–4: คูณเมทริกซ์และหมุนจุด (ใช้ @ ไม่ใช่ *)
> A, B = np.array([[1, -1], [2, 0]]), np.array([[3, 1], [1, 2]])
> print(A @ B)                                      # [[2 -1] [6 2]]
> t = np.radians(180)
> R = np.array([[np.cos(t), -np.sin(t)], [np.sin(t), np.cos(t)]])

> # หมวด 5–6: atan2 และมุมที่สั้นที่สุด

> print(diff, 350 + diff * 0.15)                    # 30 354.5
>
> # หมวด 7: จำนวนเฟรมด้วย log
> print(math.log(2 / 6) / math.log(0.8))            # 4.92... → ปัดขึ้น 5

>
> # หมวด 8–9: ไล่ค่าและกริด
> x, y, vx, vy = 100, 200, -4, 2
> x += vx; y += vy; vy += 0.1; vx *= 0.999; vy *= 0.999
> print(x, y, vx, vy)                               # 96 202 -3.996 2.0979
> print(0 // 100, 1199 // 100)                      # 0 11
> ```
