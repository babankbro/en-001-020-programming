## ภาพรวมบท
บทนี้ทำให้วัตถุในเกม "คิดเองได้" ด้วยคณิตศาสตร์เวกเตอร์ที่ถูกคำนวณใหม่ทุกเฟรม เริ่มจากแรงเสียดทานที่ลดความเร็วแบบเรขาคณิต แยกค่าคงที่ไว้ใน `config.py` แล้วสร้างศัตรูสองแบบ (สุ่ม-สะท้อน และไล่ตาม-แยกตัว) ปิดท้ายด้วยการหมุนยานทางสั้นแบบนุ่มนวลและการชนขอบจอ

**วิธีอ่านภาพ** (เริ่มจากกล่องบนสุด "ทุกเฟรม: คำนวณเวกเตอร์ → `pos` (float) → `rect` (int)" แล้วไล่ตามเส้นแกนกลางลงมา สีของกล่องแทนหัวข้อ แถบสีท้ายกล่องคือคำตอบตัวเลขสำคัญ)
1. แรงเสียดทาน: `velocity *= 0.97` → $n > \ln 0.2 / \ln 0.97 \approx 52.84$ → หยุดที่เฟรม 53
2. มอดูลและ `config.py`: `from config import *` ใช้ `SCREEN_WIDTH` ตรง ๆ ส่วน `import config` ต้องใช้ `config.SCREEN_WIDTH` → แก้ที่เดียว เปลี่ยนทั้งเกม
3. ศัตรูสุ่ม + สะท้อน: ชนบนกลับเฉพาะ $v_y$ เช่น (2.4, −1.8) → (2.4, 1.8) → อัตราเร็ว 3.0 คงเดิม
4. ไล่ตาม + แยกตัว: (300, −400) ÷ 500 = (0.6, −0.8) แล้วคูณ 0.1 → ความเร่ง (0.06, −0.08)
5. หมุนนุ่มนวล + ชนขอบ: `(-340) % 360 = 20` → หมุน +20° ทางสั้น แล้ว lerp × 0.15 ได้ 13.5 → 24.975 → 34.7288

กล่อง "เส้นเชื่อมระหว่างหัวข้อ" ชี้ว่าหัวข้อ 1 และ 5 ลดลงแบบเรขาคณิตเหมือนกัน ($0.97^n$ และ $0.85^n$) หัวข้อ 3–5 ตรวจขอบด้วย `SCREEN_WIDTH` จากหัวข้อ 2 ร่วมกัน ส่วนกล่อง ✗/✓ ด้านล่างจับคู่กับดักที่พบบ่อยของแต่ละหัวข้อเรียงแถวต่อแถว

## สิ่งที่ต้องจำ (Key Facts)

### 1. แรงเสียดทานและการลดลงแบบเรขาคณิต
- `velocity *= 0.97` ทุกเฟรม = **ลำดับเรขาคณิต** $v_n = v_0 \cdot 0.97^n$ ลดลง 3% ของค่า **ปัจจุบัน** ไม่ใช่ลดทีละเท่ากัน
- ความเร็ว **ไม่มีวันเป็นศูนย์** ($5 \times 0.97^{100} \approx 0.238$) จึงต้องมีเกณฑ์หยุด เช่น `< 1` หรือ `< 0.1`
- จำนวนเฟรมใช้ลอการิทึม $n > \ln(v_{min}/v_0)/\ln f$ แล้วปัดขึ้น — $\ln f < 0$ ทำให้อสมการกลับทิศ
- ระยะทางรวมเป็นอนุกรมเรขาคณิต ไม่เกิน $v_0/(1-f)$ · ความเร็วลดครึ่งทุก ≈ 22.76 เฟรม (เมื่อ $f = 0.97$)
- `(cos θ, sin θ)` มีขนาด 1 เสมอ → ใช้เป็นทิศได้ทันที คูณอัตราเร็วได้ความเร็ว
- `friction` = สัดส่วนที่ **เหลือ** → ลดลงร้อยละ $(1-f) \times 100$ ต่อเฟรม: 0.9 → ร้อยละ 10 · 0.97 → **ร้อยละ 3** · 0.98 → ร้อยละ 2
- `friction = 1.0` → ความเร็วคงที่ **ไม่มีวันหยุด** (ลูปรอ `< 1` วนไม่รู้จบ) · `friction > 1` → **เร่งขึ้นเอง** · ค่าที่ใช้ได้ $0 < f < 1$

### 2. มอดูลและ config.py
- **มอดูล** = ไฟล์ `.py` หนึ่งไฟล์ · `config.py` เก็บ `SCREEN_WIDTH = 1200`, `SCREEN_HEIGHT = 900`
- `from config import *` → ใช้ `SCREEN_WIDTH` ตรง ๆ · `import config` → ต้องใช้ `config.SCREEN_WIDTH`
- ไพทอนรัน `config.py` ครั้งเดียวตอนนำเข้าครั้งแรก แล้วทุกไฟล์ใช้ค่าชุดเดียวกัน → **แก้ที่เดียว เปลี่ยนทั้งเกม**
- `config.py` ต้องอยู่โฟลเดอร์เดียวกับ `main.py` ไม่เช่นนั้น `ModuleNotFoundError`
- เส้นทาง `"Lab07/game/images/enemy.png"` นับจากโฟลเดอร์ที่ **สั่งรัน** ไม่ใช่ที่ไฟล์อยู่ → `FileNotFoundError`

### 3. ศัตรูเคลื่อนที่สุ่มและสะท้อนขอบจอ
- `random.uniform(a, b)` คืน float ทุกค่าในช่วงโอกาสเท่ากัน ค่าเฉลี่ย $(a+b)/2$ · `randint` คืน int รวมปลาย · `random.seed(n)` สุ่มซ้ำได้
- สุ่ม $v_x, v_y$ แยกกันในช่วง $[-3, 3]$ → อัตราเร็วอาจถึง $\sqrt{18} \approx 4.24$ เกิน `max_speed`
- เก็บ `pos` เป็น `Vector2` (float) แล้วค่อย `rect.topleft = (int(pos.x), int(pos.y))` — บวก 0.3 เข้า `rect.x` ตรง ๆ จะไม่ขยับ
- ชนซ้าย/ขวา กลับเฉพาะ `vel.x` · ชนบน/ล่าง กลับเฉพาะ `vel.y` · อัตราเร็วคงเดิม
- ไม่วางตำแหน่งกลับที่ขอบก่อนสะท้อน → อาจ **ติดผนัง** สั่นค้าง

### 4. ศัตรูสีแดงไล่ตาม (Seek) และแยกตัว (Separation)
- **เวกเตอร์จาก A ไป B = B − A**: ไล่ตาม = ผู้เล่น − ตัวเอง · แยกตัว = ตัวเอง − อีกตัว · สลับลำดับ = หนีแทนไล่
- `normalize()` ตัดระยะทางทิ้ง เหลือแต่ทิศ → ทุกตัวเร่ง 0.1 เท่ากันไม่ว่าจะอยู่ใกล้หรือไกล
- `normalize()` เวกเตอร์ศูนย์ → `ValueError` ต้องตรวจ `length() > 0` ก่อนเสมอ
- `scale_to_length(L)` = $\hat v \times L$ คงทิศ เปลี่ยนขนาด ใช้จำกัดอัตราเร็วไม่ให้เกิน `max_speed = 3`
- `RedEnemy` เก็บ **การอ้างอิง** `self.player` → อ่าน `self.player.rect.center` ได้ตำแหน่งล่าสุดทุกเฟรม

### 5. การหมุนแบบนุ่มนวล มุมที่สั้นที่สุด และยานชนขอบจอ
- `angle_diff = (target - angle) % 360` แล้วถ้า `> 180` ให้ลบ 360 → อยู่ในช่วง $(-180, 180]$ = ทางสั้นเสมอ
- `%` ของจำนวนลบในไพทอนได้ผลบวกเมื่อตัวหารเป็นบวก: `(-340) % 360 = 20`
- `angle += diff * 0.15` คือ lerp ด้วย $t = 0.15$ → มุมที่เหลือ $d_0 \times 0.85^n$ (เรขาคณิตเหมือนแรงเสียดทาน)
- ยานชนขอบ: วาง `rect` กลับที่ขอบ → กลับทิศ → ซิงก์ `pos = Vector2(rect.center)`

## สูตร (Formulas)
| เรื่อง | สูตร | โค้ด | ตัวอย่างตัวเลข |
|---|---|---|---|
| อัตราเร็วหลัง n เฟรม | $\lvert v_n \rvert = \lvert v_0 \rvert f^{\,n}$ | `velocity *= 0.97` | $5 \times 0.97^{3} = 4.5634$ |
| เฟรมจนต่ำกว่าเกณฑ์ | $n > \dfrac{\ln(v_{min}/v_0)}{\ln f}$ | `math.ceil(math.log(vmin/v0)/math.log(f))` | $\ln 0.2/\ln 0.97 \approx 52.84 \to 53$ |
| ร้อยละที่ลดต่อเฟรม | $(1 - f) \times 100$ | — | $f = 0.97$ → 3 · $f = 0.98$ → 2 |
| ระยะสูงสุด | $S_\infty = \dfrac{v_0}{1-f}$ | — | $5/0.03 \approx 166.7$ |
| ระยะจริงใน n เฟรม | $S_n = \dfrac{v_0(1-f^{\,n})}{1-f}$ | ผลรวม `pos += velocity` | $n = 53$: ≈ 133.5 |
| ทิศจากมุม | $(\cos\theta, \sin\theta)$ | `np.array([np.cos(rad), np.sin(rad)])` | 230° → (−0.643, −0.766) |
| สะท้อน | $(v_x, v_y) \to (-v_x, v_y)$ / $(v_x, -v_y)$ | `self.vel.x *= -1` | (1.5, −2) ชนบน → (1.5, 2) |
| ไล่ตาม | $v \mathrel{+}= 0.1 \cdot \dfrac{P - E}{\lvert P - E \rvert}$ | `(Vector2(player.rect.center) - self.pos).normalize() * 0.1` | (200, 500)→(500, 100): (0.06, −0.08) |
| แยกตัว | $v \mathrel{+}= 0.1 \cdot \dfrac{E_{me} - E_{o}}{\lvert E_{me} - E_{o} \rvert}$ | `(Vector2(self.rect.center) - Vector2(other.rect.center)).normalize() * 0.1` | (20, −10) → (0.894, −0.447) × 0.1 |
| จำกัดอัตราเร็ว | $v \leftarrow \hat v \cdot v_{max}$ ถ้า $\lvert v \rvert > v_{max}$ | `vel.scale_to_length(max_speed)` | (−9, 12) → (−3, 4) เมื่อ $v_{max} = 5$ |
| มุมที่สั้นที่สุด | $d = (t - a) \bmod 360$; $d > 180 \Rightarrow d - 360$ | `angle_diff = (target - angle) % 360` | 350 → 20: $d = 30$ |
| Lerp | $a + (b - a)t$ · เหลือ $d_0(1-t)^n$ | `self.angle += angle_diff * 0.15` | lerp(10, 50, 0.25) = 20 |

## โค้ดที่ต้องเขียนได้โดยไม่ดู
```python
# 1) แรงเสียดทานจนหยุด
n = 0
while True:
    pos = pos + velocity
    velocity *= 0.97
    n += 1
    if np.linalg.norm(velocity) < 1:
        break

# 2) config.py และการนำเข้า
SCREEN_WIDTH = 1200          # config.py
SCREEN_HEIGHT = 900
from config import *         # ในไฟล์อื่น

# 3) ศัตรูสุ่ม + สะท้อนขอบ
self.vel = pygame.math.Vector2(random.uniform(-3, 3), random.uniform(-3, 3))
self.pos += self.vel
self.rect.topleft = (int(self.pos.x), int(self.pos.y))
if self.rect.left < 0 or self.rect.right > SCREEN_WIDTH:
    self.vel.x *= -1
if self.rect.top < 0 or self.rect.bottom > SCREEN_HEIGHT:
    self.vel.y *= -1

# 4) ศัตรูแดงไล่ตาม + แยกตัว + จำกัดอัตราเร็ว
direction = pygame.math.Vector2(self.player.rect.center) - self.pos
if direction.length() > 0:
    self.vel += direction.normalize() * 0.1
for other in self.red_enemys:
    if other is not self and self.rect.colliderect(other.rect):
        push = pygame.math.Vector2(self.rect.center) - pygame.math.Vector2(other.rect.center)
        if push.length() > 0:
            self.vel += push.normalize() * 0.1
if self.vel.length() > self.max_speed:
    self.vel.scale_to_length(self.max_speed)

# 5) มุมที่สั้นที่สุด + lerp
angle_diff = (target_angle - self.angle) % 360
if angle_diff > 180:
    angle_diff -= 360
self.angle += angle_diff * self.rotation_smoothness
```

## ทดสอบตัวเอง 5 ข้อ

> [!question]- 1. ความเร็วเริ่มต้น 6 และ friction = 0.9 ต้องผ่านไปกี่เฟรมจึงต่ำกว่า 1
> > [!success]- เฉลย
> > $n > \ln(1/6)/\ln 0.9 \approx 17.006$ จึงเป็น **18 เฟรม** — ระวัง ค่า 17.006 เกือบเป็นจำนวนเต็ม: $6 \times 0.9^{17} \approx 1.0006$ ยังไม่ต่ำกว่า 1 แต่ $6 \times 0.9^{18} \approx 0.9006$ ต่ำกว่าแล้ว

> [!question]- 2. ความเร็วเริ่มต้น 4 และ friction = 0.95 ถ้าปล่อยให้ไหลไม่มีที่สิ้นสุด ระยะทางรวมเข้าใกล้เท่าใด
> > [!success]- เฉลย
> > $S_\infty = 4/(1 - 0.95) = 4/0.05 = 80$ พิกเซล

> [!question]- 3. ศัตรูแดงอยู่ที่ (10, 20) ผู้เล่นอยู่ที่ (34, 27) ความเร่งไล่ตาม `direction.normalize() * 0.1` คือเท่าใด
> > [!success]- เฉลย
> > $\mathbf{d} = (24, 7)$ ขนาด $\sqrt{576 + 49} = 25$ → $(0.96, 0.28) \times 0.1 = (0.096, 0.028)$

> [!question]- 4. `angle = 20`, `target = 300`, `rotation_smoothness = 0.15` จงหา `angle_diff` และมุมใหม่
> > [!success]- เฉลย
> > $(300 - 20) \% 360 = 280 > 180$ → $280 - 360 = -80$ (หมุนลบ 80° สั้นกว่าหมุนบวก 280°) → มุมใหม่ $20 + (-80)(0.15) = 8$

> [!question]- 5. ศัตรูความเร็ว (−2, 1.5) ชนขอบซ้ายของจอ ความเร็วใหม่และอัตราเร็วคือเท่าใด
> > [!success]- เฉลย
> > ชนผนังแนวตั้งกลับเฉพาะแกน x → $(2, 1.5)$ อัตราเร็ว $\sqrt{4 + 2.25} = 2.5$ เท่าเดิม

### เพิ่มเติม: แนวข้อสอบปลายภาค
> [!question]- 6. `velocity *= 0.97` ทุกเฟรม ข้อใดถูก: ลดลง 0.97 หน่วยทุกเฟรม / ลดลงร้อยละ 3 ทุกเฟรม / ลดลงร้อยละ 97 ทุกเฟรม
> > [!success]- เฉลย
> > **ลดลงร้อยละ 3 ทุกเฟรม** — $(1 - 0.97) \times 100 = 3$ เป็นการคูณ (เหลือร้อยละ 97) ไม่ใช่การลบ 0.97 หน่วย

> [!question]- 7. ถ้าตั้ง `friction = 1.0` แล้วปล่อยปุ่ม ยานที่มีอัตราเร็ว 5 จะเป็นอย่างไร และถ้า `friction = 1.02` ล่ะ
> > [!success]- เฉลย
> > `1.0`: อัตราเร็วคงที่ 5 ตลอด ไม่มีวันหยุด · `1.02`: เร็วขึ้นเรื่อย ๆ เช่นเฟรม 10 ≈ 6.09

> [!question]- 8. friction 0.9, 0.97, 0.98 จากอัตราเร็ว 5 ต่ำกว่า 1 ที่เฟรมใด
> > [!success]- เฉลย
> > 16 · 53 · 80 เฟรมตามลำดับ (ยิ่ง $f$ ใกล้ 1 ยิ่งช้า) · $f = 1.0$ ไม่มีวัน
