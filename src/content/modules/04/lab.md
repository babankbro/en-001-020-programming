```python
def print_table(table):
    num_cols = len(table[0])
    col_widths = [max(len(str(row[i])) for row in table) for i in range(num_cols)]
    line_length = sum(col_widths) + (num_cols * 3)
    print("-" * line_length)
    for row in table:
        for i, item in enumerate(row):
            print(f"{str(item):<{col_widths[i]}}", end=" | ")
        print()
    print("-" * line_length)

print_table(scores)
```
```
--------------------
55 | 63 | 77 | 81 | 
65 | 61 | 67 | 72 | 
97 | 95 | 92 | 88 | 
--------------------
```

### ขั้นตอนที่ 7: คลาส Stack และการไล่ลำดับ
15. พิมพ์คลาส `Stack` ลงในไฟล์ `stack_v2.py` (หรือเซลล์ใหม่) แล้ว **วาดตารางไล่ลำดับ `items` บนกระดาษก่อนรัน**

```python
class Stack:
    def __init__(self):
        self.items = []
    def push(self, item):
        self.items.append(item)
    def pop(self):
        if not self.items:
            raise IndexError("pop from empty stack")
        return self.items.pop()
    def peek(self):
        if not self.items:
            raise IndexError("peek from empty stack")
        return self.items[-1]
    def is_empty(self):
        return len(self.items) == 0
    def size(self):
        return len(self.items)

m = Stack()
print(m.is_empty(), m.size())
m.push('x')
m.push('y')
m.push('z')
print(m.items, m.size())
print(m.peek(), m.size())
print(m.pop(), m.items)
print(m.pop(), m.items)
print(m.pop(), m.items)
print(m.is_empty())
```

True

### ขั้นตอนที่ 9: กลับลำดับและตรวจวงเล็บ
20. เขียนฟังก์ชัน `reverse(text)` และ `balanced(text)` โดยใช้คลาส `Stack`

```python
def reverse(text):
    s = Stack()
    for ch in text:
        s.push(ch)
    out = ""
    while not s.is_empty():
        out += s.pop()
    return out

def balanced(text):
    s = Stack()
    for ch in text:
        if ch == "(":
            s.push(ch)
        elif ch == ")":
            if s.is_empty():
                return False
            s.pop()
    return s.is_empty()

print(reverse("Python"))
print(reverse("KSU"))
print(balanced("(a+b)*(c-d)"))
print(balanced("((a+b)"))
print(balanced("a+b)("))
print(balanced(""))
```
```
nohtyP
USK
True
False
False
True
```

21. ไล่ `balanced("a+b)(")` ด้วยมือ: พบ `)` ขณะสแตกว่าง → คืน `False` ทันทีโดยไม่ดู `(` ตัวท้าย ส่วน `balanced("")` ไม่มีวงเล็บเลย สแตกว่างตอนจบจึงเป็น `True`

![reverse("KSU") push K S U แล้ว pop ได้ USK และการไล่ balanced ทีละตัวอักษรของ "(a+b)*(c-d)" "((a+b)" และ "a+b)(" พร้อมจำนวนวงเล็บค้างในสแตก](/infographics/04/lab-part3-balanced.svg)

**วิธีอ่านภาพ** (น้ำเงิน = push `(` เข้าสแตก, ส้ม = pop เมื่อเจอ `)`, แดง = เจอ `)` ตอนสแตกว่าง หรือผล `False`, เขียว = `True`, เทา = ตัวที่ไม่ได้อ่าน)
1. ① `reverse("KSU")`: push K, S, U ซ้อนกันขึ้นไป แล้ว pop ออกจากด้านบนได้ U, S, K ตัวแปร `out` จึงโตเป็น `"U"` → `"US"` → `"USK"` เพราะตัวที่เข้าหลังสุดออกก่อน (LIFO) แบบเดียวกับ `reverse("Python") = "nohtyP"`
2. ② อ่านแต่ละแถวจากซ้ายไปขวาทีละตัวอักษร ตัวเลขใต้วงเล็บคือจำนวน `(` ที่ค้างในสแตกหลังอ่านตัวนั้น: `"(a+b)*(c-d)"` ขึ้น 1 ลง 0 สองรอบ จบด้วยสแตกว่างจึง `True`
3. `"((a+b)"` push สองครั้ง (1, 2) แล้ว pop ครั้งเดียวเหลือ 1 ตอนจบ `return s.is_empty()` จึงได้ `False`
4. `"a+b)("` เจอ `)` ขณะสแตกว่าง (ช่องแดง "ว่าง!") ฟังก์ชันคืน `False` ทันทีโดยไม่อ่าน `(` ตัวท้าย (ช่องเทา) ส่วน `balanced("")` ไม่มีวงเล็บเลยจึงได้ `True`
5. กล่อง "จุดที่มักผิด": pop โดยไม่ตรวจว่าว่างก่อนทำให้ `"a+b)("` เกิด `IndexError` แทนที่จะได้ `False` และ `return True` ท้ายฟังก์ชันทำให้ `"((a+b)"` ได้ `True` ทั้งที่มีวงเล็บค้าง

> [!tip] ขยายให้รองรับ `[]` และ `{}`
> push วงเล็บเปิดทุกชนิด และเมื่อพบวงเล็บปิดให้ `pop()` แล้วตรวจว่าเป็นคู่ที่ถูกต้อง เช่น `"([)]"` ต้องได้ `False` — ลองทำเป็นการบ้าน
