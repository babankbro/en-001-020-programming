## ภาพรวมบท
บทนี้เริ่มเขียนไพทอนบน Jupyter Notebook ตั้งแต่ `print` ตัวแปร และ f-string ผ่านตัวดำเนินการคณิตศาสตร์ ไปจนถึงฟังก์ชันคำนวณผลคูณจุดและขนาดของเวกเตอร์ที่ใช้ได้ทุกมิติด้วยการวนซ้ำ แล้วปิดท้ายด้วยการวาดรูปจาก `#` แบบ Top-Down Design ทุกหัวข้อต่อยอดกันเป็นลำดับ และจะถูกใช้ซ้ำในเกม Pygame บทที่ 5–8

![แผนที่แนวคิด 5 หัวข้อของบทที่ 2 เชื่อมกับหัวข้อกลางของบท](/infographics/02/summary.svg)

อ่านภาพจากวงรีกลางออกไปหาการ์ด 5 ใบตามหมายเลขหัวข้อ แต่ละการ์ดมีโค้ดหรือตัวเลขสำคัญ 4 บรรทัดที่ต้องจำ แถบข้อความด้านล่างบอกลำดับการต่อยอด: แสดงผลด้วย f-string → คำนวณด้วยตัวดำเนินการ → `dotv` → `lenv` ที่สร้างจาก `dotv` → ใช้ลูปแบบเดียวกันวาดรูป

## สิ่งที่ต้องจำ (Key Facts)

### 1. โปรแกรมแรก ตัวแปร และ f-string
- `print(a, b)` พิมพ์คั่นด้วยช่องว่าง · `print("#", end="")` ไม่ขึ้นบรรทัดใหม่ · `print()` เปล่า = ขึ้นบรรทัด
- ตัวแปรไม่ต้องประกาศชนิด: `5` → `int`, `5.0` → `float`, `"5"` → `str`, `True` → `bool` · ไพทอนไม่มีชนิด `char`
- f-string ต้องมี `f` นำหน้า **และ** ใส่นิพจน์ในปีกกา `{}` — ลืม `f` จะพิมพ์ `{x}` ตรง ๆ โดยไม่มี error
- รูปแบบ: `{x:.2f}` ทศนิยม 2 · `{s:>5}` ชิดขวากว้าง 5 · `{s:<10}` ชิดซ้ายกว้าง 10
- ต่อด้วย `+` ได้เฉพาะ `str` กับ `str` — `"age: " + 20` → `TypeError`
- `"15" + "5"` = `'155'` (ต่อ) · `"7" * 2` = `'77'` (ทำซ้ำ) · `int("15") + int("5")` = `20`
- ในปีกกาใส่ **นิพจน์** ได้: `{age + 1}`, `{len(name)}` · ค่าในปีกกามาจากพารามิเตอร์ที่ผูกกับอาร์กิวเมนต์ **ตามลำดับตำแหน่ง**
- พิมพ์ตาม **ชื่อในปีกกาที่เขียนจริง**: `{name}` สองช่อง → ชื่อซ้ำสองครั้ง พารามิเตอร์ที่ไม่ถูกใช้ไม่ทำให้เกิด error

### 2. ค่าเฉลี่ยและตัวดำเนินการคณิตศาสตร์
- `/` ได้ `float` เสมอ (`7 / 7 = 1.0`) · `//` หารปัดลงไปทางลบอนันต์ (`-7 // 2 = -4`)
- `%` เศษมีเครื่องหมายตามตัวหาร (`-7 % 2 = 1`) และ `a == (a // b) * b + a % b` เสมอ
- `**` ยกกำลัง ทำก่อนทุกตัวและทำจากขวาไปซ้าย (`2 ** 3 ** 2 = 512`, `-2 ** 2 = -4`)
- ค่าเฉลี่ยต้องใส่วงเล็บ `(n1 + n2 + n3) / 3` และห้ามใช้ `//`
- `round(x, 2)` ใช้ปัดตอนแสดงผล เช่น `round(5.4772, 2) = 5.48` · ไม่ใส่ตำแหน่ง → ได้ `int` · ครึ่งพอดีปัดไปหาเลขคู่ `round(2.5) = 2`
- `round` = ปัด · `int()` = ตัดทิ้งเข้าหาศูนย์ (`int(3.7) = 3`) · `//` = ปัดลงไปทางลบอนันต์ · `math.sqrt` คืน `float` เสมอ (`math.sqrt(16) = 4.0`)
- `and` จริงเมื่อจริงทั้งคู่ · `or` จริงเมื่อจริงอย่างน้อยหนึ่ง · `not` กลับค่า · ลำดับ `( )` → `not` → `and` → `or`
- การลัดวงจร: `False and X` และ `True or X` ไม่ประเมิน `X` เลย

### 3. ผลคูณจุดของเวกเตอร์ (Dot Product)
- $\mathbf{a}\cdot\mathbf{b} = \sum a_i b_i$ คูณทีละดัชนีแล้วบวก ได้ **สเกลาร์** ไม่ใช่เวกเตอร์
- เวกเตอร์เก็บเป็นทูเพิล `(1, 2, 3)` ดัชนีเริ่มที่ 0
- $\mathbf{a}\cdot\mathbf{b} = \lvert\mathbf{a}\rvert\lvert\mathbf{b}\rvert\cos\theta$ → บวก = มุมแหลม · 0 = ตั้งฉาก · ลบ = มุมป้าน
- `dotv3` เขียน 3 พจน์ตายตัว ใช้กับ 4 มิติแล้ว **ไม่ error แต่ผิด** (ไม่อ่าน `v[3]`)

### 4. ขนาดของเวกเตอร์และการวนซ้ำกี่มิติก็ได้
- $\lvert\mathbf{v}\rvert = \sqrt{\sum v_i^2} = \sqrt{\mathbf{v}\cdot\mathbf{v}}$ มาจากทฤษฎีบทพีทาโกรัส
- `for i in range(len(v))` วนตามจำนวนสมาชิกจริง → ใช้ได้ทุกมิติ
- รูปแบบตัวสะสม: ตั้ง `total = 0` ก่อนลูป → `total += ...` ในลูป → `return` **นอกลูป**
- เวกเตอร์หนึ่งหน่วย $\hat{\mathbf{v}} = \mathbf{v}/\lvert\mathbf{v}\rvert$ ยาว 1 เสมอ (ห้ามหารเวกเตอร์ศูนย์)
- ฟังก์ชันไม่มี `return` คืน `None` · ตัวแปรในฟังก์ชันเป็น local

### 5. การวนซ้ำและการวาดรูปด้วย # แบบ Top-Down Design
- `range(start, stop, step)` ไม่รวม `stop` · `range(5, 0, -1)` = 5, 4, 3, 2, 1
- ลูปซ้อน: ลูปในวิ่งครบทุกรอบต่อ 1 รอบของลูปนอก → งานในสุดทำ (รอบนอก × รอบใน) ครั้ง
- `line(n)` → `block(row, col)` เรียก `line(col)` row ครั้ง → `triangle(n)` เรียก `line(i + 1)`
- Top-Down: แตกงานใหญ่ (`tree()`) เป็นงานย่อย (`top_leaf`, `bottom_leaf`, `clone`) จนถึงฟังก์ชันพื้นฐาน (`linespace`)

## สูตร (Formulas)
| เรื่อง | สูตร | โค้ด | ตัวอย่างตัวเลข |
|---|---|---|---|
| ปัดเศษ | ปัดให้เหลือ $n$ ตำแหน่ง | `round(x, n)` | `round(math.sqrt(2), 2)` = 1.41 · `round(math.pi, 3)` = 3.142 |
| ตรรกะ | `not` > `and` > `or` | `(A and B) or C` | `(True and False) or True` = True |
| ค่าเฉลี่ย | $\bar{x} = \frac{1}{n}\sum x_i$ | `total / n` | (5 + 10 + 15) / 3 = 10.0 |
| หารปัดลง/เศษ | $a = (a /\!/ b)b + a \% b$ | `a // b`, `a % b` | −7 // 2 = −4, −7 % 2 = 1 |
| ผลคูณจุด | $\mathbf{a}\cdot\mathbf{b} = \sum a_i b_i$ | `total += v[i]*u[i]` | (1,2,0,4)·(1,2,3,4) = 21 |
| มุมระหว่างเวกเตอร์ | $\cos\theta = \frac{\mathbf{a}\cdot\mathbf{b}}{\lvert\mathbf{a}\rvert\lvert\mathbf{b}\rvert}$ | `math.acos(...)` | (4,2), (1,3) → 10/√200 ≈ 0.707 → 45° |
| ขนาดเวกเตอร์ | $\lvert\mathbf{v}\rvert = \sqrt{\mathbf{v}\cdot\mathbf{v}}$ | `math.sqrt(dotv(v, v))` | (1,2,3,4) → √30 ≈ 5.477 |
| เวกเตอร์หนึ่งหน่วย | $\hat{\mathbf{v}} = \mathbf{v}/\lvert\mathbf{v}\rvert$ | `v[i] / lenv(v)` | (3,4) → (0.6, 0.8) |
| ตั้งฉาก | $\mathbf{a}\cdot\mathbf{b} = 0$ | `dotv(a, b) == 0` | (3,4)·(−4,3) = 0 |
| # ใน `block(row, col)` | $row \times col$ | | block(2, 10) → 20 |
| # ใน `triangle(n)` | $n(n+1)/2$ | | triangle(10) → 55 |

## โค้ดที่ต้องเขียนได้โดยไม่ดู
```python
import math

def dotv(v, u):
    total = 0
    for i in range(len(v)):
        total += v[i] * u[i]
    return total

def lenv(v):
    return math.sqrt(dotv(v, v))

def line(n):
    for i in range(n):
        print("#", end="")
    print()

def block(row, col):
    for i in range(row):
        line(col)

def triangle(n):
    for i in range(n):
        line(i + 1)

def linespace(s, n):
    print(" " * s + "#" * n)     # เทียบเท่าลูปพิมพ์ช่องว่าง s ตัวและ # n ตัว
```

## ตัวอย่างไล่ค่า (Trace)
**`dotv((1, 2, 0, 4), (1, 2, 3, 4))`**

| `i` | `v[i]` | `u[i]` | `v[i]*u[i]` | `total` |
|---|---|---|---|---|
| เริ่ม | | | | 0 |
| 0 | 1 | 1 | 1 | 1 |
| 1 | 2 | 2 | 4 | 5 |
| 2 | 0 | 3 | 0 | 5 ← `dotv3` หยุดตรงนี้ |
| 3 | 4 | 4 | 16 | **21** |

**`top_leaf()` เรียก `linespace(3 - i, 2*i + 1)`**

| `i` | `s = 3 - i` | `n = 2*i + 1` | แถวที่พิมพ์ |
|---|---|---|---|
| 0 | 3 | 1 | `   #` |
| 1 | 2 | 3 | `  ###` |
| 2 | 1 | 5 | ` #####` |

## ตัวเลขที่ออกสอบบ่อย
- `dotv3((1,2,3), (1,0,1))` = 4 · `(1,2,0,4)·(1,2,3,4)` = 21 แต่ `dotv3` ของคู่นี้ได้ 5
- `(2,−1,4)·(3,5,1)` = 5 · `(3,4)·(−4,3)` = 0 → ตั้งฉาก · `(4,2)·(1,3)` = 10 → 45°
- `lenv((1,2,3,4))` = √30 ≈ 5.477 (`round` 2 ตำแหน่ง = 5.48) · `lenv((3,4))` = 5.0 · `lenv((2,3,6))` = 7.0
- `9 // 4, 9 % 4, 9 / 4, 9 ** 0.5` = `2 1 2.25 3.0` · `2 ** 10` = 1024
- `f"{2/3:.3f}|{'ab':>4}|"` = `0.667|  ab|`
- `greeting("Sarayut", 40)` ที่เขียน `{name}` สองช่อง → `Hello, Sarayut, I'm Sarayut years old ` · `{year}` สองช่องกับ 21 → `Hello, 21, I'm 21 years old ` · `{age + 1}` กับ 19 → `20`
- `(True and False) or True` = **True** · `(False or True) and False` = **False** · `(True or False) and True` = **True** · `True or False and False` = True
- `round(math.sqrt(2), 2)` = 1.41 · `round(math.pi, 3)` = 3.142 · `round(10 / 3, 2)` = 3.33 · `round(2.5)` = 2 · `round(3.5)` = 4 · `int(3.7)` = 3 · `-3.7 // 1` = −4.0
- `"15" + "5"` = `155` · `"7" * 2` = `77` · `15 + 5` = 20 · `7 * 2` = 14
- `block(2, 10)` พิมพ์ # 20 ตัว · `triangle(4)` 10 ตัว · `triangle(10)` 55 ตัว · `triangle(100)` 5,050 ตัว
- `tree()` ได้ 8 แถว: `(s, n)` = (3,1) (2,3) (1,5) (2,3) (1,5) (0,7) (3,1) (3,1)

## กับดักที่พบบ่อย
| ✗ ผิด | ✓ ถูก | เหตุผล |
|---|---|---|
| `print("{a*b}")` | `print(f"{a*b}")` | ไม่มี `f` → พิมพ์ปีกกาตรง ๆ |
| `print(f"(a*b)")` | `print(f"{a*b}")` | ต้องใช้ปีกกา ไม่ใช่วงเล็บ |
| `avg = n1 + n2 + n3 / 3` | `avg = (n1 + n2 + n3) / 3` | `/` ทำก่อน `+` ได้ 20.0 แทน 10.0 |
| `avg = total // 3` | `avg = total / 3` | `//` ตัดเศษทิ้ง |
| `dotv3` กับเวกเตอร์ 4 มิติ | `dotv` ที่วน `range(len(v))` | ไม่ error แต่ได้ 5 แทน 21 |
| `dotv((1,2,3), (1,2))` | ตรวจ `len(v) == len(u)` ก่อน | `u[2]` ไม่มี → `IndexError` |
| `return` ย่อหน้าอยู่ในลูป | `return` ระดับเดียวกับ `for` | คืนค่าตั้งแต่รอบแรก |
| `print("#")` ใน `line()` | `print("#", end="")` | ทุก `#` ขึ้นบรรทัดใหม่ กลายเป็นเสา |
| `"15" + "5"` ได้ 20 | ได้ `'155'` | สายอักขระ + สายอักขระ = ต่อกัน · `"7" * 2` = `'77'` |
| เดาว่า `I'm {name} years old` จะพิมพ์อายุ | พิมพ์ชื่อ เพราะในปีกกาเขียน `name` | ไพทอนพิมพ์ตามชื่อในปีกกา ไม่ตามความหมายของประโยค |
| `{age} + 1` ได้ 20 | `{age + 1}` | `+ 1` นอกปีกกาเป็นข้อความ ได้ `19 + 1` |
| `True or False and False` ทำซ้ายไปขวาได้ `False` | `True or (False and False)` = `True` | `and` ทำก่อน `or` |
| `round(2.5)` ได้ 3 | ได้ 2 | ครึ่งพอดีปัดไปหาเลขคู่ (Banker's Rounding) |
| `int(3.7)` ได้ 4 | ได้ 3 | `int()` ตัดทิ้ง ไม่ปัด · ใช้ `round(3.7)` = 4 |
| `(1, 2) + (3, 4)` เป็นการบวกเวกเตอร์ | บวกทีละดัชนี หรือใช้ NumPy (บทที่ 6) | ทูเพิลบวกกันคือการต่อ ได้ `(1, 2, 3, 4)` |

## ทดสอบตัวเอง 5 ข้อ
> [!question]- 1. `print(f"{7/4:.2f}|{'ok':>4}|")` แสดงผลอะไร
> > [!success]- เฉลย
> > `1.75|  ok|` — `7/4 = 1.75` แสดงทศนิยม 2 ตำแหน่ง และ `'ok'` ชิดขวาในช่องกว้าง 4 จึงมีช่องว่างนำหน้า 2 ช่อง

> [!question]- 2. `print(-17 // 5, -17 % 5)` แสดงผลอะไร
> > [!success]- เฉลย
> > `-4 3` — $-17/5 = -3.4$ ปัดลงเป็น $-4$ และเศษ $= -17 - (-4)(5) = 3$

> [!question]- 3. จงหา `dotv((2, 0, -1, 3), (1, 5, 4, 2))`
> > [!success]- เฉลย
> > $2(1) + 0(5) + (-1)(4) + 3(2) = 2 + 0 - 4 + 6 = 4$

> [!question]- 4. จงหา `lenv((1, 4, 8))` และบอกว่าเวกเตอร์หนึ่งหน่วยของมันคืออะไร
> > [!success]- เฉลย
> > $\sqrt{1 + 16 + 64} = \sqrt{81} = 9.0$ → เวกเตอร์หนึ่งหน่วย $(1/9,\ 4/9,\ 8/9)$

> [!question]- 5. `block(3, 7)` และ `triangle(6)` พิมพ์ `#` อย่างละกี่ตัว
> > [!success]- เฉลย
> > `block(3, 7)` = 3 × 7 = 21 ตัว · `triangle(6)` = 6 × 7 / 2 = 21 ตัว — เท่ากันพอดีแต่รูปต่างกัน

### เพิ่มเติม: แนวข้อสอบปลายภาค
> [!question]- 6. `def greeting(name, age): print(f"Hello, {name}, I'm {name} years old ")` แล้วเรียก `greeting("Sarayut", 40)` แสดงผลอะไร
> > [!success]- เฉลย
> > `Hello, Sarayut, I'm Sarayut years old ` — `name = "Sarayut"`, `age = 40` แต่ทั้งสองช่องเขียน `{name}` จึงพิมพ์ชื่อซ้ำ ไม่มี 40 และไม่มี error (แก้ช่องที่สองเป็น `{age}`)

> [!question]- 7. `print((True and False) or True)`, `print((False or True) and False)`, `print((True or False) and True)` แสดงผลอะไรตามลำดับ
> > [!success]- เฉลย
> > `True` · `False` · `True` — ทำในวงเล็บก่อน: `False or True` = True · `True and False` = False · `True and True` = True

> [!question]- 8. `print(round(math.sqrt(2), 2), round(math.pi, 3), round(10 / 3, 2), "15" + "5", "7" * 2)` แสดงผลอะไร
> > [!success]- เฉลย
> > `1.41 3.142 3.33 155 77` — ปัดตามหลักถัดไป (1.414… → 1.41, 3.1415… → 3.142, 3.333… → 3.33) และ `str` ใช้ `+` ต่อกัน `*` ทำซ้ำ

## เชื่อมโยงบทถัดไป
