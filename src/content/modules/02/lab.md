> [!warning] สิ่งที่ควรสังเกต

### ขั้นตอนที่ 4: ทำให้รองรับทุกมิติด้วยการวนซ้ำ
```python
import math

def dotv(v, u):
    total = 0
    for i in range(len(v)):
        total += v[i] * u[i]
    return total

def lenv(v):
    sumofPower2 = 0
    for i in range(len(v)):
        sumofPower2 += v[i]*v[i]
    return math.sqrt(sumofPower2)

print(dotv((1, 2, 0, 4), (1, 2, 3, 4)))
lena = lenv((1, 2, 3, 4))
print(lena)
print(round(lena, 2))
```
```
21
5.477225575051661
5.48
```

![dotv3 กับ dotv: คูณทีละตำแหน่งแล้วบวก dotv3 ได้ 4 กับ (1,2,3)·(1,0,1) แต่ได้ 5 กับเวกเตอร์ 4 มิติ ส่วน dotv วนครบได้ 21](/infographics/02/lab-dotv-trace.svg)

**วิธีอ่านภาพ** (น้ำเงิน = `v`, เขียว = `u`, ม่วง = ผลคูณแต่ละตำแหน่ง, ส้ม = ผลรวม)
1. ขั้นตอนที่ 3: คูณสมาชิกดัชนีเดียวกันลงมาทีละคอลัมน์ $1\cdot1 = 1$, $2\cdot0 = 0$, $3\cdot1 = 3$ แล้วบวกกันได้ `a . b = 4` ตรงกับการคิดมือในข้อ 5
2. ข้อ 6: `dotv3` เขียนตายตัวแค่ `v[0]`, `v[1]`, `v[2]` คอลัมน์ `i = 3` (เส้นประ ขีดฆ่าสีแดง) จึงถูกมองข้าม ได้ $1 + 4 + 0 = 5$ แทนที่จะเป็น $1 + 4 + 0 + 16 = 21$ โดยไม่มี error เตือน
3. ขั้นตอนที่ 4: ตารางไล่ค่า `dotv` อ่านทีละแถวจากบนลงล่าง คอลัมน์ `total` สะสม 0 → 1 → 5 → 5 → 21 เพราะ `range(len(v))` วนครบ `i = 0, 1, 2, 3` จึงใช้ได้กับเวกเตอร์กี่มิติก็ได้

7. เพิ่มฟังก์ชัน `unitv(v)` ที่คืนเวกเตอร์หนึ่งหน่วย (แต่ละสมาชิกหารด้วย `lenv(v)`) แล้วทดสอบกับ `(3, 4)` — ควรได้ `[0.6, 0.8]`

```python
def unitv(v):
    L = lenv(v)
    result = []
    for i in range(len(v)):
        result.append(v[i] / L)
    return result

print(unitv((3, 4)))
print(lenv(unitv((3, 4))))
```
```
[0.6, 0.8]
1.0
```

> [!question]- คำถาม 2.1: ถ้าเรียก `unitv((0, 0))` จะเกิดอะไรขึ้น และควรป้องกันอย่างไร
> > [!success]- แนวคำตอบ
> > `lenv((0,0))` ได้ 0 จึงเกิด `ZeroDivisionError` ควรตรวจ `if L == 0: return v` ก่อนหาร — หลักเดียวกับ `if direction.length() > 0:` ที่จะใช้ในเกมบทที่ 6–8

**วิธีอ่านภาพ**
1. `lenv((1, 2, 3, 4))`: ตารางยกกำลังสองทีละตัว (1, 4, 9, 16) สะสมใน `sumofPower2` ได้ 30 แล้วแถบสามกล่อง: `math.sqrt(30)` = `5.477225575051661` → `round(lena, 2)` = `5.48` ตรงกับ output 3 บรรทัดของขั้นตอนที่ 4
2. ข้อ 7: กราฟซ้ายวาดตามสเกล (1 หน่วย = 50 พิกเซล) เวกเตอร์สีน้ำเงิน $(3, 4)$ ยาว $L = \sqrt{25} = 5$ หารแต่ละสมาชิกด้วย 5 ได้เวกเตอร์สีเขียว $(0.6, 0.8)$ ซึ่งชี้ทิศเดิมแต่ยาว 1 หน่วย กล่องขวาไล่ค่าตามลำดับจนได้ `[0.6, 0.8]` และ `1.0`
3. กล่อง ✗/✓ (คำถาม 2.1): `unitv((0, 0))` ได้ `L = 0` จึงหาร 0 เกิด `ZeroDivisionError` ต้องตรวจ `if L == 0: return v` ก่อนหาร

### ขั้นตอนที่ 7 (การบ้าน): ต้นไม้

```python
def linespace(s, n):
    for i in range(s):
        print(" ", end="")
    for i in range(n):
        print("#", end="")
    print()

def top_leaf():
    for i in range(3):
        linespace(3 - i, 2*i + 1)

def bottom_leaf():
    for i in range(3):
        linespace(2 - i, 2*i + 3)

def clone():
    for i in range(2):
        linespace(3, 1)

def tree():
    top_leaf()
    bottom_leaf()
    clone()

tree()
```

> [!tip] วาดแผนภาพการเรียกฟังก์ชันก่อนเขียนโค้ด
> `tree()` → `top_leaf()` / `bottom_leaf()` / `clone()` → ทุกตัวเรียก `linespace()` — นี่คือ Top-Down Design: ออกแบบจากฟังก์ชันระดับบนลงมาถึงฟังก์ชันพื้นฐาน

**วิธีอ่านภาพ** (น้ำเงิน = `top_leaf`, เขียว = `bottom_leaf`, ส้ม = `clone`, ช่องเส้นประ `·` = ช่องว่าง)
1. แผนภาพการเรียก: `tree()` เรียกฟังก์ชันย่อย 3 ตัว และทั้ง 3 ตัวเรียก `linespace(s, n)` ตัวเดียวกัน — ออกแบบจากบนลงล่าง (Top-Down)
2. ตารางตัวอักษรด้านซ้ายคือ output ของ `tree()` 8 แถว แต่ละแถวจับคู่กับแถวในตารางขวาที่บอกว่ามาจากฟังก์ชันใด รอบ `i` เท่าใด และเรียก `linespace(s, n)` ด้วยค่าใด เช่น แถว 6 คือ `bottom_leaf` รอบ `i = 2` เรียก `linespace(0, 7)` ได้ `#######`
3. หาสูตรจากตาราง: เมื่อ `i` เพิ่ม 1 ช่องว่างลด 1 และ `#` เพิ่ม 2 จึงได้ `s = 3 - i, n = 2*i + 1` (top_leaf) และ `s = 2 - i, n = 2*i + 3` (bottom_leaf) ส่วน `clone` คงที่ `linespace(3, 1)` 2 ครั้ง
4. กล่อง ✗/✓: ถ้าใช้ `line(n)` แทน `linespace(s, n)` จะไม่มีช่องว่างนำหน้าและทุกแถวชิดซ้าย ที่ถูกต้องคือทุกแถวมีกึ่งกลางที่ช่อง 3 ($s + n // 2 = 3$) ใช้หลักนี้ตรวจต้นไม้ที่ออกแบบเองได้
