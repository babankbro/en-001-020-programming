## 1. โปรแกรมแรก ตัวแปร และ f-string

### โปรแกรมแรก
```python
print("Hello, my name is Sarayut Gonwirat.")
a = 5
b = 2
print("a x b =", a*b)        # a x b = 10
```
`print()` รับได้หลายอาร์กิวเมนต์ คั่นด้วยจุลภาค และจะพิมพ์คั่นด้วยช่องว่างให้อัตโนมัติ

### ชนิดข้อมูลพื้นฐาน
| ชนิด | ตัวอย่าง | `type()` |
|---|---|---|
| จำนวนเต็ม (Integer) | `5`, `-7` | `<class 'int'>` |
| จำนวนจริง (Floating Point) | `5.0`, `0.97` | `<class 'float'>` |
| สายอักขระ (String) | `"Sarayut"`, `'25'` | `<class 'str'>` |

| ทูเพิล (Tuple) | `(1, 2, 3)` | `<class 'tuple'>` |
| ลิสต์ (List) | `[1, 2, 3]` | `<class 'list'>` |

> [!note] ไพทอนไม่มีชนิด `char`
> อักขระตัวเดียวก็เป็น `str` และ `7 / 7` ได้ `1.0` (float) เสมอ ส่วน `7 // 7` ได้ `1` (int)

### การต่อสายอักขระและ f-string
```python
fname = "Sarayut"; lname = "Gowirat"
full_name = fname + " " + lname         # ต่อด้วย +
full_name = f"{fname} {lname}"          # f-string → Sarayut Gowirat
full_name = "{fname} {lname}"           # ไม่มี f → {fname} {lname}
full_name = f"(fname) (lname)"          # วงเล็บธรรมดา → (fname) (lname)
```

> [!important] กฎของ f-string
> 1. ต้องมีอักษร `f` นำหน้าเครื่องหมายคำพูด
> 2. ชื่อตัวแปรหรือนิพจน์ต้องอยู่ใน **วงเล็บปีกกา** `{ }` เช่น `f"a * b = {a * b}"`
> 3. จัดรูปแบบได้ เช่น `{x:.2f}` ทศนิยม 2 ตำแหน่ง, `{s:<10}` ชิดซ้ายกว้าง 10, `{s:>5}` ชิดขวากว้าง 5

![เปรียบเทียบ f-string แบบถูกและแบบผิด พร้อมโครงสร้าง {นิพจน์:รูปแบบ} และการจัดความกว้างช่อง](/infographics/02/fstring-rules.svg)

ภาพนี้แบ่งเป็น 3 ส่วน ส่วนบนเป็นตาราง ✓/✗ ให้อ่านจากซ้ายไปขวา คือโค้ดในวงเล็บของ `print()` → สิ่งที่พิมพ์ออกมาจริง → เหตุผล แถวสีแดงคือความผิดพลาดที่พบบ่อยที่สุด (ลืม `f` หรือใช้วงเล็บธรรมดาแทนปีกกา) ซึ่ง **ไม่เกิด error** แต่พิมพ์ข้อความผิด ส่วนกลางแยกโครงสร้าง `{2/3:.3f}` เป็นนิพจน์ ตัวคั่น `:` และรูปแบบ ส่วนล่างวาดผลลัพธ์เป็นช่องละ 1 อักขระ ช่องเส้นประคือช่องว่าง ทำให้เห็นว่า `>4` เติมช่องว่างไว้ **ด้านซ้าย** ส่วน `<6` เติมไว้ **ด้านขวา**

### ไพทอนประมวลผล f-string อย่างไร (ทีละขั้น)
เมื่อไพทอนพบ `f"a * b = {a * b}"` โดย `a = 5`, `b = 2` จะทำงานดังนี้

| ขั้น | สิ่งที่เกิดขึ้น | ผลระหว่างทาง |
|---|---|---|
| 1 | เห็นอักษร `f` จึงรู้ว่าต้องค้นหาปีกกา | `"a * b = {a * b}"` |
| 2 | ข้อความนอกปีกกาเก็บไว้ตามเดิม (รวม `*` ตัวแรก) | `"a * b = "` |
| 3 | คำนวณนิพจน์ในปีกกา `a * b` | `10` |
| 4 | แปลงผลเป็นสายอักขระแล้วต่อท้าย | `"a * b = 10"` |

สังเกตว่าเครื่องหมาย `*` ที่อยู่ **นอก** ปีกกาเป็นเพียงตัวอักษรธรรมดา ส่วน `*` ที่อยู่ **ใน** ปีกกาคือการคูณจริง ถ้ามีรูปแบบ เช่น `{10/3:.2f}` ขั้นที่ 3 จะได้ `3.3333333333333335` แล้วขั้นที่ 4 จัดรูปแบบเป็น `3.33` ก่อนต่อ — ค่าในตัวแปรไม่เปลี่ยน เปลี่ยนเฉพาะ "หน้าตาที่แสดง"

### เลือกวิธีแสดงผลให้เหมาะ
| วิธี | ตัวอย่าง (`age = 20`) | ข้อควรระวัง |
|---|---|---|
| คั่นด้วยจุลภาค | `print("age:", age)` | เติมช่องว่างให้อัตโนมัติ เลือกจุดทศนิยมไม่ได้ |
| ต่อด้วย `+` | `print("age: " + str(age))` | ต้องแปลงเป็น `str` เอง ไม่เช่นนั้น `TypeError` |
| f-string | `print(f"age: {age}")` | ต้องมี `f` และปีกกา — แนะนำให้ใช้เป็นหลัก |

## 2. ค่าเฉลี่ยและตัวดำเนินการคณิตศาสตร์

```python
n1, n2, n3 = 5, 10, 15
total = n1 + n2 + n3
avg = total / 3
print(f"average of {n1} {n2} and {n3} is {avg}.")   # 10.0
```

ค่าเฉลี่ยเลขคณิต (Arithmetic Mean) ของข้อมูล $x_1, x_2, \dots, x_n$ คือ
$$\bar{x} = \frac{1}{n}\sum_{i=1}^{n} x_i$$

### ตัวดำเนินการที่ต้องแยกให้ออก
| ตัวดำเนินการ | ความหมาย | ตัวอย่าง |
|---|---|---|
| `/` | หาร (ได้ float เสมอ) | `10 / 4 = 2.5` |
| `//` | หารปัดลง | `10 // 4 = 2`, `-7 // 2 = -4` |
| `%` | เศษจากการหาร (เครื่องหมายตามตัวหาร) | `10 % 4 = 2`, `-7 % 2 = 1` |
| `**` | ยกกำลัง | `2 ** 10 = 1024`, `(-1) ** 3 = -1` |

> [!warning] `/` กับ `//` ในการหาค่าเฉลี่ย
> `sum / n` ได้จำนวนจริงเสมอ แต่ `sum // n` ตัดเศษทิ้ง เช่น `10 // 4 = 2` จึง **ไม่ควรใช้ `//` หาค่าเฉลี่ย**

### ทำไม `-7 // 2 = -4` และ `-7 % 2 = 1`
`//` คือ **การหารปัดลง (Floor Division)** — ปัดไปทางลบอนันต์ ไม่ใช่ตัดทศนิยมทิ้ง และ `%` ถูกนิยามให้สอดคล้องกับ `//` เสมอตามเอกลักษณ์
$$a = (a \,/\!/\, b)\times b + (a \,\%\, b)$$

| นิพจน์ | ขั้นที่ 1: หารจริง | ขั้นที่ 2: ปัดลง (`//`) | ขั้นที่ 3: เศษ = a − (a // b)·b |
|---|---|---|---|
| `10 // 4`, `10 % 4` | 2.5 | 2 | 10 − 8 = 2 |
| `-7 // 2`, `-7 % 2` | −3.5 | −4 (ไม่ใช่ −3) | −7 − (−8) = 1 |
| `7 // -2`, `7 % -2` | −3.5 | −4 | 7 − 8 = −1 |

ดังนั้นเศษจึงมี **เครื่องหมายตามตัวหาร** เสมอ — คุณสมบัตินี้ทำให้ `x % 2` ใช้ตรวจเลขคู่/คี่ได้ทั้งจำนวนบวกและลบ และจะใช้ `//` กับ `%` แปลงดัชนีเป็นแถว/คอลัมน์ของตาราง (บทที่ 4) และกริด (บทที่ 8)

### ลำดับการคำนวณ (Operator Precedence)
`**` ทำก่อน → `*` `/` `//` `%` → `+` `-` (ระดับเดียวกันทำจากซ้ายไปขวา ยกเว้น `**` ทำจากขวาไปซ้าย)

| นิพจน์ | ผล | เหตุผล |
|---|---|---|
| `2 + 3 * 4` | `14` | คูณก่อนบวก |
| `(2 + 3) * 4` | `20` | วงเล็บทำก่อน |
| `2 ** 3 ** 2` | `512` | $2^{(3^2)} = 2^9$ ขวาไปซ้าย |
| `-2 ** 2` | `-4` | ยกกำลังก่อนติดลบ คือ $-(2^2)$ |
| `n1 + n2 + n3 / 3` (5, 10, 15) | `20.0` | หารแค่ `n3` — **bug ค่าเฉลี่ยที่พบบ่อย** ต้องเขียน `(n1 + n2 + n3) / 3` = `10.0` |

การปัดเศษแสดงผล: `round(3.14159, 2)` → `3.14` (ในคาบใช้ `lena = round(lena, 2)` แสดงขนาดเวกเตอร์)

> [!question]- ฝึกทำ: จงหาผลลัพธ์ของ `print(9 // 4, 9 % 4, 9 / 4, 9 ** 0.5)`
> > [!success]- เฉลย
> > `2 1 2.25 3.0`

> [!question]- ฝึกทำ: จงหาผลลัพธ์ของ `print(30 // 4, 30 % 4, -9 // 4, 2 + 6 / 2)`
> > [!success]- เฉลย
> > `7 2 -3 5.0` — $30 = 7 \times 4 + 2$ · $-9/4 = -2.25$ ปัดลงเป็น $-3$ · `6 / 2` ทำก่อนได้ `3.0` แล้วบวก 2 ได้ `5.0` (เป็น float เพราะ `/`)

## 3. ผลคูณจุดของเวกเตอร์ (Dot Product)

### นิยาม
$$\mathbf{a} \cdot \mathbf{b} = \sum_{i=1}^{n} a_i b_i = a_1b_1 + a_2b_2 + \dots + a_nb_n$$
ผลลัพธ์เป็น **สเกลาร์ (Scalar)** ไม่ใช่เวกเตอร์

### ความหมายเชิงเรขาคณิต
$$\mathbf{a} \cdot \mathbf{b} = |\mathbf{a}|\,|\mathbf{b}|\cos\theta$$
- มากกว่า 0 → มุมระหว่างเวกเตอร์น้อยกว่า 90° (ชี้ไปทางเดียวกัน)
- เท่ากับ 0 → ตั้งฉากกัน (Perpendicular)
- น้อยกว่า 0 → มุมมากกว่า 90° (ชี้ไปทางตรงข้าม)

![ผลคูณจุดของ a = (4, 2) และ b = (1, 3) วาดตามสเกล พร้อมขั้นตอนคูณทีละตำแหน่ง บวก และตรวจมุมด้วย cos](/infographics/02/dot-product.svg)

ภาพซ้ายวาดเวกเตอร์ $\mathbf{a} = (4, 2)$ (สีน้ำเงิน) และ $\mathbf{b} = (1, 3)$ (สีเขียว) บนระนาบพิกัดตามสเกลจริง ภาพขวาอ่านจากบนลงล่างตามหมายเลข 1–3 ขั้นที่ 1 จับคู่สมาชิกดัชนีเดียวกันมาคูณ ($4 \cdot 1 = 4$, $2 \cdot 3 = 6$) ขั้นที่ 2 บวกได้ $10$ ซึ่งเป็นตัวเลขตัวเดียว (สเกลาร์) ขั้นที่ 3 นำ 10 ไปหาร $\lvert\mathbf{a}\rvert\lvert\mathbf{b}\rvert$ ได้ $\cos\theta \approx 0.707$ จึงได้มุม 45° ตรงกับส่วนโค้งสีม่วงในภาพซ้าย แถบล่างสรุปว่าเครื่องหมายของผลคูณจุดบอกได้ทันทีว่ามุมแหลม ตั้งฉาก หรือมุมป้าน

### หามุมระหว่างเวกเตอร์ทีละขั้น
จัดรูปสูตรใหม่ได้ $\cos\theta = \dfrac{\mathbf{a}\cdot\mathbf{b}}{\lvert\mathbf{a}\rvert\,\lvert\mathbf{b}\rvert}$ ตัวอย่าง $\mathbf{a} = (4, 2)$, $\mathbf{b} = (1, 3)$

1. ผลคูณจุด: $4(1) + 2(3) = 10$
2. ขนาด: $\lvert\mathbf{a}\rvert = \sqrt{16 + 4} = \sqrt{20} \approx 4.472$ และ $\lvert\mathbf{b}\rvert = \sqrt{1 + 9} = \sqrt{10} \approx 3.162$
3. $\cos\theta = 10 / (4.472 \times 3.162) = 10/\sqrt{200} \approx 0.7071$
4. $\theta = \cos^{-1}(0.7071) = 45^\circ$

```python
import math
a, b = (4, 2), (1, 3)
dot = a[0]*b[0] + a[1]*b[1]
cos_t = dot / (math.sqrt(20) * math.sqrt(10))
print(dot, round(cos_t, 4), round(math.degrees(math.acos(cos_t)), 1))
```
```
10 0.7071 45.0
```

> [!tip] ใช้ในเกมที่ไหน
> เกมไม่ได้ต้องการมุมทุกครั้ง บ่อยครั้งแค่ดู **เครื่องหมาย** ของผลคูณจุดก็พอ เช่น ศัตรูอยู่ "ข้างหน้า" ยานหรือไม่ (ผลคูณจุดของทิศหัวยานกับเวกเตอร์จากยานไปศัตรูเป็นบวก) ซึ่งต่อยอดจากการหมุนและทิศของยานในบทที่ 6–7

### จากสูตรสู่โค้ด
```python
# 3 มิติแบบเขียนตรง
def dotv3(v, u):
    return v[0]*u[0] + v[1]*u[1] + v[2]*u[2]

print(dotv3((1, 2, 3), (1, 0, 1)))    # 1 + 0 + 3 = 4
```
เวกเตอร์ในบทนี้เก็บเป็น **ทูเพิล** `(1, 2, 3)` เข้าถึงสมาชิกด้วยดัชนี `v[0]`, `v[1]`, `v[2]` (ดัชนีเริ่มที่ 0)

### ตัวอย่างคำนวณมือ
$(1, 2, 3) \cdot (1, 0, 1) = 1\cdot1 + 2\cdot0 + 3\cdot1 = 4$

$(1, 2, 0, 4) \cdot (1, 2, 3, 4) = 1 + 4 + 0 + 16 = 21$

เขียนเป็นตารางคูณทีละดัชนีจะไม่หลงตำแหน่ง (เทคนิคที่ใช้ในข้อสอบ)

| ดัชนี `i` | `v[i]` | `u[i]` | `v[i]*u[i]` |
|---|---|---|---|
| 0 | 1 | 1 | 1 |
| 1 | 2 | 2 | 4 |
| 2 | 0 | 3 | 0 |
| 3 | 4 | 4 | 16 |
| **รวม** | | | **21** |

> [!warning] `dotv3` กับเวกเตอร์ 4 มิติ
> ถ้าเรียก `dotv3((1, 2, 0, 4), (1, 2, 3, 4))` จะได้ `5` (เฉพาะ 3 แถวแรกของตาราง) โดย **ไม่มี error** เพราะ `dotv3` ไม่เคยอ่าน `v[3]` — นี่คือเหตุผลที่หัวข้อถัดไปต้องเปลี่ยนเป็นการวนซ้ำ

> [!question]- ฝึกทำ: จงหา $(2, -1, 4) \cdot (3, 5, 1)$
> > [!success]- เฉลย
> > $6 - 5 + 4 = 5$

> [!question]- ฝึกทำ: เวกเตอร์ (3, 4) และ (−4, 3) ตั้งฉากกันหรือไม่
> > [!success]- เฉลย
> > $3(-4) + 4(3) = -12 + 12 = 0$ จึงตั้งฉากกัน (เป็นผลจากการหมุน 90° ซึ่งจะเรียนในบทที่ 6)

## 4. ขนาดของเวกเตอร์และการวนซ้ำกี่มิติก็ได้

### ขนาดของเวกเตอร์ (Magnitude)
มาจากทฤษฎีบทพีทาโกรัส
$$|\mathbf{v}| = \sqrt{v_1^2 + v_2^2 + \dots + v_n^2} = \sqrt{\mathbf{v}\cdot\mathbf{v}}$$

```python
import math

def lenv3(v):
    s = v[0]*v[0] + v[1]*v[1] + v[2]*v[2]
    return math.sqrt(s)

def lenv(v):                      # ขนาดของเวกเตอร์กี่มิติก็ได้
    sumofPower2 = 0
    for i in range(len(v)):
        sumofPower2 += v[i]*v[i]
    return math.sqrt(sumofPower2)

print(lenv((1, 2, 3, 4)))         # sqrt(30) ≈ 5.477
```

### ทำไมต้องวนซ้ำ
`lenv3` เขียนบวกสามพจน์ตายตัว จึงใช้ได้เฉพาะ 3 มิติ ส่วน `lenv` ใช้ `for i in range(len(v))` วนตามจำนวนสมาชิกจริง จึงใช้ได้ทั้ง 2, 3, 4 มิติ หรือมากกว่า — หลักเดียวกันใช้ทำ `dotv` ให้รองรับทุกมิติ:

```python
def dotv(v, u):
    total = 0
    for i in range(len(v)):
        total += v[i] * u[i]
    return total
```

### ไล่ค่า `lenv((1, 2, 3, 4))` ทีละรอบ
`len(v) = 4` ดังนั้น `range(4)` ให้ `i = 0, 1, 2, 3` และตัวแปรสะสม `sumofPower2` เริ่มที่ 0

| รอบ | `i` | `v[i]` | `v[i]*v[i]` | `sumofPower2` หลังบวก |
|---|---|---|---|---|
| 1 | 0 | 1 | 1 | 0 + 1 = 1 |
| 2 | 1 | 2 | 4 | 1 + 4 = 5 |
| 3 | 2 | 3 | 9 | 5 + 9 = 14 |
| 4 | 3 | 4 | 16 | 14 + 16 = 30 |
| จบลูป | | | | `math.sqrt(30)` ≈ 5.477 |

รูปแบบ "ตั้งตัวแปรสะสมเป็น 0 → วนบวกทีละตัว → ใช้ผลหลังจบลูป" เรียกว่า **รูปแบบตัวสะสม (Accumulator Pattern)** เป็นแม่แบบของ `dotv`, ผลรวม, ค่าเฉลี่ย และการนับ ข้อสังเกตสำคัญ: `return` ต้องอยู่ **นอกลูป** (ย่อหน้าระดับเดียวกับ `for`) ถ้าย่อหน้าเข้าไปในลูป ฟังก์ชันจะคืนค่าหลังรอบแรก ได้ $\sqrt{1} = 1.0$

### เทียบ `dotv3` กับ `dotv` บนเวกเตอร์ 4 มิติ
| การเรียก | ดัชนีที่ถูกอ่าน | ผลลัพธ์ | ถูกหรือไม่ |
|---|---|---|---|
| `dotv3((1,2,0,4), (1,2,3,4))` | 0, 1, 2 (ตายตัว) | `5` | ✗ ตก `4·4 = 16` |
| `dotv((1,2,0,4), (1,2,3,4))` | 0, 1, 2, 3 (ตาม `len(v)`) | `21` | ✓ |
| `dotv((3,4), (-4,3))` | 0, 1 | `0` | ✓ ใช้กับ 2 มิติได้ด้วย |

และเมื่อมี `dotv` แล้ว ขนาดเวกเตอร์เขียนสั้นได้เป็น `math.sqrt(dotv(v, v))` เพราะ $\lvert\mathbf{v}\rvert = \sqrt{\mathbf{v}\cdot\mathbf{v}}$ — เป็นตัวอย่างการนำฟังก์ชันกลับมาใช้ซ้ำ

### เวกเตอร์หนึ่งหน่วย (Unit Vector)
หารสมาชิกทุกตัวด้วยขนาด ได้เวกเตอร์ทิศเดิมที่ยาว 1 หน่วย: $\hat{\mathbf{v}} = \mathbf{v} / \lvert\mathbf{v}\rvert$ เช่น $(3, 4)$ มีขนาด 5 จึงได้ $(0.6, 0.8)$ ซึ่ง $\sqrt{0.36 + 0.64} = 1$ ในเกมบทที่ 6–8 ใช้แนวคิดนี้ผ่าน `normalize()` ให้ยาน ศัตรู และกระสุนเคลื่อนที่ด้วยความเร็วเท่ากันทุกทิศ (ต้องระวังเวกเตอร์ศูนย์ที่ขนาดเป็น 0 ห้ามหาร)

> [!warning] ถ้าเวกเตอร์ยาวไม่เท่ากัน
> `dotv((1,2,3), (1,2))` วนตาม `len(v) = 3` เมื่อ `i = 2` จะเรียก `u[2]` ซึ่งไม่มี → `IndexError` ควรตรวจ `len(v) == len(u)` ก่อน

## 5. การวนซ้ำและการวาดรูปด้วย # แบบ Top-Down Design

### `for` กับ `range()`
| คำสั่ง | ค่าที่ได้ | จำนวนรอบ |
|---|---|---|
| `range(5)` | 0, 1, 2, 3, 4 | 5 |
| `range(1, 6)` | 1, 2, 3, 4, 5 | 5 |
| `range(1, 10, 3)` | 1, 4, 7 | 3 |
| `range(5, 0, -1)` | 5, 4, 3, 2, 1 | 5 |

`range(start, stop, step)` **ไม่รวม** ค่า `stop`

### วาดเส้นและสี่เหลี่ยม
```python
def line(n):
    for i in range(n):
        print("#", end="")      # end="" ไม่ขึ้นบรรทัดใหม่
    print()                     # ขึ้นบรรทัดใหม่เมื่อครบแถว

def block(row, col):
    for i in range(row):
        line(col)

block(2, 10)
```

`line(n)` ใช้การวนซ้ำ 1 ชั้น ส่วน `block(row, col)` เรียก `line()` ซ้ำ ซึ่งเทียบเท่า **การวนซ้ำซ้อน (Nested Loop)** — จำนวนครั้งที่พิมพ์ `#` = row × col = 20

![ตาราง 2 × 10 แสดงลำดับการพิมพ์ # ของ block(2, 10) และบันไดของ triangle(4) พร้อมตารางสะสมจำนวน #](/infographics/02/nested-loop-grid.svg)

ส่วน A มองผลลัพธ์ของ `block(2, 10)` เป็นตารางช่อง: แถว (สีส้ม `i=0`, `i=1`) คือรอบของ **ลูปนอก** ใน `block()` ส่วนคอลัมน์ 0–9 (สีน้ำเงิน) คือรอบของ **ลูปใน** ใน `line()` เลขเล็กใต้ `#` บอกลำดับที่ถูกพิมพ์ จะเห็นว่าลูปในวิ่งครบ 10 รอบก่อน แล้วจึงขึ้นบรรทัด (↵) ลูปนอกจึงขยับไปแถวถัดไป ส่วน B แสดงว่า `triangle(4)` แต่ละแถวยาวไม่เท่ากัน (`line(i + 1)`) จึงนับจำนวน `#` ด้วยการสะสม 1, 3, 6, 10 แทนการคูณ

### ไล่ลำดับการทำงานของลูปซ้อน
ถ้าเขียน `block(2, 3)` แบบลูปซ้อนตรง ๆ (ใช้ `j` สำหรับลูปในเพื่อไม่ให้สับสน)
```python
for i in range(2):          # ลูปนอก: แถว
    for j in range(3):      # ลูปใน: คอลัมน์
        print("#", end="")
    print()                 # อยู่ในลูปนอก แต่อยู่นอกลูปใน
```

| ลำดับ | `i` | `j` | การกระทำ |
|---|---|---|---|
| 1–3 | 0 | 0, 1, 2 | พิมพ์ `###` |
| — | 0 | (จบลูปใน) | `print()` ขึ้นบรรทัด |
| 4–6 | 1 | 0, 1, 2 | พิมพ์ `###` |
| — | 1 | (จบลูปใน) | `print()` ขึ้นบรรทัด |

กฎจำ: **ลูปในวิ่งครบทุกรอบ ต่อ 1 รอบของลูปนอก** จำนวนครั้งที่คำสั่งในสุดทำงานจึงเท่ากับผลคูณของจำนวนรอบ (2 × 3 = 6) และตำแหน่งย่อหน้าของ `print()` เป็นตัวกำหนดว่าขึ้นบรรทัดเมื่อไร

### การออกแบบจากบนลงล่าง (Top-Down Design)
แยกปัญหาใหญ่เป็นปัญหาย่อย แก้ทีละส่วนด้วยฟังก์ชันเล็ก แล้วประกอบกลับ

| ฟังก์ชัน | หน้าที่ | เรียกใช้ |
|---|---|---|
| `line(n)` | พิมพ์ # n ตัวแล้วขึ้นบรรทัด | — |
| `block(row, col)` | สี่เหลี่ยม | `line(col)` row ครั้ง |
| `triangle(n)` | สามเหลี่ยมชิดซ้าย | `line(i + 1)` |
| `tree()` | ต้นไม้ (การบ้าน) | `top_leaf()`, `bottom_leaf()`, `clone()` |

ข้อดี: อ่านง่าย ทดสอบทีละส่วนได้ แก้ไขที่เดียว และนำกลับมาใช้ซ้ำ (Reuse) — ดูเพิ่มที่ [EN-001-002 บท 05 การออกแบบจากบนลงล่าง](https://en-001-002-computer-programming.vercel.app/module/05)

### ตัวอย่างเต็ม: ต้นไม้จาก `tree()`
การบ้านของบทนี้คือวาดต้นไม้ ขั้นแรกของ Top-Down คือ **มองภาพผลลัพธ์แล้วแบ่งเป็นส่วน** (ใบบน 3 แถว · ใบล่าง 3 แถว · ลำต้น 2 แถว) ขั้นที่สองคือหาว่าทุกแถวมีรูปแบบร่วมกันคือ "ช่องว่าง `s` ตัว ตามด้วย `#` `n` ตัว" จึงสร้างฟังก์ชันพื้นฐาน `linespace(s, n)` ขึ้นมาตัวเดียว

```python
def linespace(s, n):            # ฟังก์ชันระดับล่างสุด
    for i in range(s):
        print(" ", end="")
    for i in range(n):
        print("#", end="")
    print()

def top_leaf():                 # ใบบน: (3,1) (2,3) (1,5)
    for i in range(3):
        linespace(3 - i, 2*i + 1)

def bottom_leaf():              # ใบล่าง: (2,3) (1,5) (0,7)
    for i in range(3):
        linespace(2 - i, 2*i + 3)

def clone():                    # ลำต้น: (3,1) สองครั้ง
    for i in range(2):
        linespace(3, 1)

def tree():                     # ฟังก์ชันระดับบนสุด อ่านแล้วเข้าใจทันที
    top_leaf()
    bottom_leaf()
    clone()

tree()
```

![แผนภาพการเรียกฟังก์ชัน tree() ไปยัง top_leaf(), bottom_leaf(), clone() และ linespace(s, n) พร้อมภาพผลลัพธ์ที่ระบายสีตามฟังก์ชันที่พิมพ์แต่ละแถว](/infographics/02/topdown-tree.svg)

ด้านซ้ายของภาพคือ **แผนภาพการเรียกฟังก์ชัน (Call Tree)** อ่านจากบนลงล่าง: `tree()` เรียกฟังก์ชันระดับกลาง 3 ตัว และทั้งสามเรียก `linespace(s, n)` ตัวเดียวกัน กล่องด้านล่างซ้ายสรุปสูตร `(s, n)` ของแต่ละฟังก์ชัน ด้านขวาคือผลลัพธ์ 8 แถว ช่องเส้นประคือช่องว่าง และสีของ `#` บอกว่าแถวนั้นพิมพ์โดยฟังก์ชันใด (เขียว = ใบบน, น้ำเงิน = ใบล่าง, ส้ม = ลำต้น) ตัวเลข `(s, n)` ท้ายแถวคืออาร์กิวเมนต์ที่ส่งให้ `linespace` ในแถวนั้น

ลองตรวจสูตรของ `top_leaf()` ทีละรอบ: `i = 0` → `linespace(3, 1)` · `i = 1` → `linespace(2, 3)` · `i = 2` → `linespace(1, 5)` — ช่องว่างลด 1 และ `#` เพิ่ม 2 ทุกแถว ทำให้ `#` อยู่กึ่งกลางที่คอลัมน์ 3 เสมอ ถ้าต้องการต้นไม้ที่ใหญ่ขึ้นก็แก้แค่ฟังก์ชันระดับกลาง ไม่ต้องแตะ `linespace` เลย นี่คือประโยชน์ของการแยกระดับ

> [!tip] ถ้าเปลี่ยน `print("#", end="")` เป็น `print("#")`
> ทุก `#` จะขึ้นบรรทัดใหม่ รูปสี่เหลี่ยมจะกลายเป็นเสา `#` ยาว row × col บรรทัด
