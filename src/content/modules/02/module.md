## 1. โปรแกรมแรก ตัวแปร และ f-string

### โปรแกรมแรก
```python
print("Hello, my name is Sarayut Gonwirat.")
a = 5
b = 2
print("a x b =", a*b)        # a x b = 10
```
`print()` รับได้หลายอาร์กิวเมนต์ คั่นด้วยจุลภาค และจะพิมพ์คั่นด้วยช่องว่างให้อัตโนมัติ

### ชนิดข้อมูลพื้นฐาน
| ชนิด | ตัวอย่าง | `type()` |
|---|---|---|
| จำนวนเต็ม (Integer) | `5`, `-7` | `<class 'int'>` |
| จำนวนจริง (Floating Point) | `5.0`, `0.97` | `<class 'float'>` |
| สายอักขระ (String) | `"Sarayut"`, `'25'` | `<class 'str'>` |
| ค่าความจริง (Boolean) | `True`, `False` | `<class 'bool'>` |
| ทูเพิล (Tuple) | `(1, 2, 3)` | `<class 'tuple'>` |
| ลิสต์ (List) | `[1, 2, 3]` | `<class 'list'>` |

> [!note] ไพทอนไม่มีชนิด `char`
> อักขระตัวเดียวก็เป็น `str` และ `7 / 7` ได้ `1.0` (float) เสมอ ส่วน `7 // 7` ได้ `1` (int)

### การต่อสายอักขระและ f-string
```python
fname = "Sarayut"; lname = "Gowirat"
full_name = fname + " " + lname         # ต่อด้วย +
full_name = f"{fname} {lname}"          # f-string → Sarayut Gowirat
full_name = "{fname} {lname}"           # ไม่มี f → {fname} {lname}
full_name = f"(fname) (lname)"          # วงเล็บธรรมดา → (fname) (lname)
```

> [!important] กฎของ f-string
> 1. ต้องมีอักษร `f` นำหน้าเครื่องหมายคำพูด
> 2. ชื่อตัวแปรหรือนิพจน์ต้องอยู่ใน **วงเล็บปีกกา** `{ }` เช่น `f"a * b = {a * b}"`
> 3. จัดรูปแบบได้ เช่น `{x:.2f}` ทศนิยม 2 ตำแหน่ง, `{s:<10}` ชิดซ้ายกว้าง 10, `{s:>5}` ชิดขวากว้าง 5

![เปรียบเทียบ f-string แบบถูกและแบบผิด พร้อมโครงสร้าง {นิพจน์:รูปแบบ} และการจัดความกว้างช่อง](/infographics/02/fstring-rules.svg)

**วิธีอ่านภาพ**
1. ตาราง ✓/✗ — อ่านแต่ละแถวจากซ้ายไปขวา: โค้ดในวงเล็บของ `print()` → สิ่งที่พิมพ์ออกมาจริง → เหตุผล แถวสีแดงคือความผิดพลาดที่พบบ่อยที่สุด (ลืม `f` หรือใช้วงเล็บธรรมดาแทนปีกกา) ซึ่ง **ไม่เกิด error** แต่พิมพ์ข้อความผิด
2. แยก `{2/3:.3f}` เป็นนิพจน์ (น้ำเงิน) ตัวคั่น `:` (ส้ม) และรูปแบบ (ม่วง) แล้วตามลูกศร: คำนวณ `2/3` ได้ `0.6666…` ก่อน จากนั้นจัดรูป `.3f` เป็น `0.667`
3. แถวช่องสี่เหลี่ยม 1 ช่อง = 1 อักขระ ช่องเส้นประคือช่องว่าง จะเห็นว่า `>4` เติมช่องว่างไว้ **ด้านซ้าย** ส่วน `<6` เติมไว้ **ด้านขวา**
4. รวมทั้งบรรทัด `print(f"{2/3:.3f}|{'ab':>4}|")` ได้คำตอบในกรอบสีส้ม `0.667|␣␣ab|` (␣ = ช่องว่าง)
5. กล่อง ✗/✓ ล่างสุด: ต่อ `str` กับ `int` ด้วย `+` เกิด `TypeError` ต้องแปลงด้วย `str()` หรือใช้ f-string

### ไพทอนประมวลผล f-string อย่างไร (ทีละขั้น)
เมื่อไพทอนพบ `f"a * b = {a * b}"` โดย `a = 5`, `b = 2` จะทำงานดังนี้

| ขั้น | สิ่งที่เกิดขึ้น | ผลระหว่างทาง |
|---|---|---|
| 1 | เห็นอักษร `f` จึงรู้ว่าต้องค้นหาปีกกา | `"a * b = {a * b}"` |
| 2 | ข้อความนอกปีกกาเก็บไว้ตามเดิม (รวม `*` ตัวแรก) | `"a * b = "` |
| 3 | คำนวณนิพจน์ในปีกกา `a * b` | `10` |
| 4 | แปลงผลเป็นสายอักขระแล้วต่อท้าย | `"a * b = 10"` |

สังเกตว่าเครื่องหมาย `*` ที่อยู่ **นอก** ปีกกาเป็นเพียงตัวอักษรธรรมดา ส่วน `*` ที่อยู่ **ใน** ปีกกาคือการคูณจริง ถ้ามีรูปแบบ เช่น `{10/3:.2f}` ขั้นที่ 3 จะได้ `3.3333333333333335` แล้วขั้นที่ 4 จัดรูปแบบเป็น `3.33` ก่อนต่อ — ค่าในตัวแปรไม่เปลี่ยน เปลี่ยนเฉพาะ "หน้าตาที่แสดง"

### เลือกวิธีแสดงผลให้เหมาะ
| วิธี | ตัวอย่าง (`age = 20`) | ข้อควรระวัง |
|---|---|---|
| คั่นด้วยจุลภาค | `print("age:", age)` | เติมช่องว่างให้อัตโนมัติ เลือกจุดทศนิยมไม่ได้ |
| ต่อด้วย `+` | `print("age: " + str(age))` | ต้องแปลงเป็น `str` เอง ไม่เช่นนั้น `TypeError` |
| f-string | `print(f"age: {age}")` | ต้องมี `f` และปีกกา — แนะนำให้ใช้เป็นหลัก |

### `+` และ `*` กับสายอักขระ (แนวข้อสอบ)
ตัวดำเนินการเดียวกันทำงานต่างกันตาม **ชนิดข้อมูล** ของตัวถูกดำเนินการ — ตัวเลขในเครื่องหมายคำพูดเป็น `str` ไม่ใช่ตัวเลข

| นิพจน์ | ผลลัพธ์ | ชนิด | เหตุผล |
|---|---|---|---|
| `"15" + "5"` | `'155'` | `str` | `str + str` = **ต่อ (Concatenation)** ไม่ใช่บวก |
| `15 + 5` | `20` | `int` | บวกเลขจริง |
| `int("15") + int("5")` | `20` | `int` | แปลงเป็นตัวเลขก่อนจึงบวกได้ |
| `"7" * 2` | `'77'` | `str` | `str * int` = **ทำซ้ำ (Repetition)** 2 ครั้ง |
| `7 * 2` | `14` | `int` | คูณเลขจริง |
| `"#" * 5` | `'#####'` | `str` | หลักเดียวกับ `linespace()` ในหัวข้อ 5 |
| `"15" + 5` | `TypeError` | — | ต่อ `str` กับ `int` ไม่ได้ ต้องใช้ `str(5)` หรือ f-string |

> [!tip] จำง่าย
> ดูชนิดก่อนคำนวณ: มีเครื่องหมายคำพูด = ข้อความ → `+` คือ "ต่อท้าย" และ `*` คือ "พิมพ์ซ้ำ" — รายละเอียดการรับค่าจาก `input()` ที่ได้ `str` เสมอจะเรียนต่อใน [บทที่ 3](/module/03) (เช่น ป้อน `15` และ `5` แล้วลืมแปลงด้วย `int()` จะได้ `155`)

### f-string กับพารามิเตอร์ของฟังก์ชัน
เมื่อ f-string อยู่ในฟังก์ชัน ค่าในปีกกามาจาก **พารามิเตอร์ (Parameter)** ซึ่งรับค่าจาก **อาร์กิวเมนต์ (Argument)** ตอนเรียกใช้ โดยจับคู่ **ตามลำดับตำแหน่ง** ตัวที่ 1 → พารามิเตอร์ตัวที่ 1, ตัวที่ 2 → พารามิเตอร์ตัวที่ 2 (ทบทวนส่วนประกอบของฟังก์ชันที่ [หัวข้อ 4](#topic-4))

```python
def greeting(name, age):
    print(f"Hello, {name}, I'm {name} years old ")   # ← บั๊ก: ใช้ name สองครั้ง

greeting("Sarayut", 40)
```
```
Hello, Sarayut, I'm Sarayut years old 
```

![การเรียก greeting("Sarayut", 40) ส่งอาร์กิวเมนต์เข้าพารามิเตอร์ name และ age แล้วเติมช่องปีกกาทั้งสองช่องด้วย name จนได้ output ที่ไม่มี 40 พร้อมวิธีแก้](/infographics/02/fstring-function.svg)

**วิธีอ่านภาพ** (สีน้ำเงิน = `name`, ส้ม = `age`, แดง = จุดที่เป็นบั๊ก)
1. อาร์กิวเมนต์ `"Sarayut"` (ตัวที่ 1) และ `40` (ตัวที่ 2) ถูกผูกกับพารามิเตอร์ `name` และ `age` ตามลำดับตำแหน่ง — กล่องเส้นประสีแดงเตือนว่า `age` รับค่าแล้วแต่ไม่มีช่องใดใช้
2. ช่อง `{ }` ทั้งสองช่องในแม่แบบเขียนว่า `{name}` จึงลากเส้นจากกล่อง `name` ไปทั้งคู่ (เส้นสีแดงคือช่องที่ผิด ควรเป็น `{age}`)
3. output ในกรอบสีส้มจึงมี `Sarayut` ซ้ำสองครั้ง ไม่มี `40` และไม่มี error ส่วน `␣` แทนช่องว่างท้ายบรรทัดที่มาจากช่องว่างก่อน `"` ปิด
4. ตัวอย่างนิพจน์ในปีกกา: `hi("Somsri", 19)` คำนวณ `{age + 1}` = 19 + 1 = 20 ได้ `Hi Somsri, next year you are 20`
5. กล่อง ✗/✓: อย่าเดาจากความหมายของประโยค ให้อ่านชื่อในปีกกาตามจริง และแก้ช่องที่สองเป็น `{age}` จะได้ `I'm 40 years old`

**วิธีหาคำตอบโจทย์แบบนี้ (3 ขั้น)**

| ขั้น | ทำอะไร | ตัวอย่าง `greeting("Sarayut", 40)` |
|---|---|---|
| 1 | เขียนการผูกค่า พารามิเตอร์ = อาร์กิวเมนต์ ตามตำแหน่ง | `name = "Sarayut"`, `age = 40` |
| 2 | ไล่ทีละช่อง `{ }` ว่าเขียนชื่อพารามิเตอร์อะไร **ตามที่เห็นจริง** ไม่ใช่ตามที่ควรเป็น | ช่อง 1 = `{name}`, ช่อง 2 = `{name}` |
| 3 | แทนค่า ข้อความนอกปีกกาคงเดิมทุกตัวอักษร (รวมช่องว่าง) | `Hello, Sarayut, I'm Sarayut years old ` |

> [!warning] กับดัก: อ่านตามความหมาย ไม่อ่านตามโค้ด
> ข้อความ "I'm ... years old" ชวนให้เดาว่าช่องที่สองคืออายุ แต่ไพทอนไม่เดา — พิมพ์ตาม **ชื่อในปีกกา** เท่านั้น ถ้าโจทย์เขียน `def greeting(name, year): print(f"Hello, {year}, I'm {year} years old ")` แล้วเรียกโดยส่ง `year = 21` ผลคือ `Hello, 21, I'm 21 years old ` ทั้งสองช่องเป็น 21 เพราะเขียน `{year}` ซ้ำ ส่วนพารามิเตอร์ที่ไม่ถูกใช้ (`age`, `name`) **ไม่ทำให้เกิด error**

**ในปีกกาใส่ "นิพจน์" อะไรก็ได้** ไม่จำเป็นต้องเป็นชื่อตัวแปรเดี่ยว ไพทอนคำนวณนิพจน์ก่อนแล้วจึงแปลงผลเป็นข้อความ

```python
def hi(name, age):
    print(f"Hi {name}, next year you are {age + 1}")

hi("Somsri", 19)
```
```
Hi Somsri, next year you are 20
```

| เขียนในปีกกา | ค่าที่ได้ (`name = "Somsri"`, `age = 19`) | หมายเหตุ |
|---|---|---|
| `{age + 1}` | `20` | คำนวณก่อน ค่า `age` ยังเป็น 19 เหมือนเดิม |
| `{age * 12}` | `228` | อายุเป็นเดือน |
| `{name.upper()}` | `SOMSRI` | เรียกเมทอดได้ |
| `{len(name)}` | `6` | เรียกฟังก์ชันได้ |
| `{age >= 18}` | `True` | นิพจน์เปรียบเทียบได้ค่าบูลีน (หัวข้อ 2) |
| `{age} + 1` | `19 + 1` | `+ 1` อยู่นอกปีกกาจึงเป็นข้อความธรรมดา |

## 2. ค่าเฉลี่ยและตัวดำเนินการคณิตศาสตร์

```python
n1, n2, n3 = 5, 10, 15
total = n1 + n2 + n3
avg = total / 3
print(f"average of {n1} {n2} and {n3} is {avg}.")   # 10.0
```

ค่าเฉลี่ยเลขคณิต (Arithmetic Mean) ของข้อมูล $x_1, x_2, \dots, x_n$ คือ
$$\bar{x} = \frac{1}{n}\sum_{i=1}^{n} x_i$$

### ตัวดำเนินการที่ต้องแยกให้ออก
| ตัวดำเนินการ | ความหมาย | ตัวอย่าง |
|---|---|---|
| `/` | หาร (ได้ float เสมอ) | `10 / 4 = 2.5` |
| `//` | หารปัดลง | `10 // 4 = 2`, `-7 // 2 = -4` |
| `%` | เศษจากการหาร (เครื่องหมายตามตัวหาร) | `10 % 4 = 2`, `-7 % 2 = 1` |
| `**` | ยกกำลัง | `2 ** 10 = 1024`, `(-1) ** 3 = -1` |

> [!warning] `/` กับ `//` ในการหาค่าเฉลี่ย
> `sum / n` ได้จำนวนจริงเสมอ แต่ `sum // n` ตัดเศษทิ้ง เช่น `10 // 4 = 2` จึง **ไม่ควรใช้ `//` หาค่าเฉลี่ย**

### ทำไม `-7 // 2 = -4` และ `-7 % 2 = 1`
`//` คือ **การหารปัดลง (Floor Division)** — ปัดไปทางลบอนันต์ ไม่ใช่ตัดทศนิยมทิ้ง และ `%` ถูกนิยามให้สอดคล้องกับ `//` เสมอตามเอกลักษณ์
$$a = (a \,/\!/\, b)\times b + (a \,\%\, b)$$

| นิพจน์ | ขั้นที่ 1: หารจริง | ขั้นที่ 2: ปัดลง (`//`) | ขั้นที่ 3: เศษ = a − (a // b)·b |
|---|---|---|---|
| `10 // 4`, `10 % 4` | 2.5 | 2 | 10 − 8 = 2 |
| `-7 // 2`, `-7 % 2` | −3.5 | −4 (ไม่ใช่ −3) | −7 − (−8) = 1 |
| `7 // -2`, `7 % -2` | −3.5 | −4 | 7 − 8 = −1 |

ดังนั้นเศษจึงมี **เครื่องหมายตามตัวหาร** เสมอ — คุณสมบัตินี้ทำให้ `x % 2` ใช้ตรวจเลขคู่/คี่ได้ทั้งจำนวนบวกและลบ และจะใช้ `//` กับ `%` แปลงดัชนีเป็นแถว/คอลัมน์ของตาราง (บทที่ 4) และกริด (บทที่ 8)

### ลำดับการคำนวณ (Operator Precedence)
`**` ทำก่อน → `*` `/` `//` `%` → `+` `-` (ระดับเดียวกันทำจากซ้ายไปขวา ยกเว้น `**` ทำจากขวาไปซ้าย)

| นิพจน์ | ผล | เหตุผล |
|---|---|---|
| `2 + 3 * 4` | `14` | คูณก่อนบวก |
| `(2 + 3) * 4` | `20` | วงเล็บทำก่อน |
| `2 ** 3 ** 2` | `512` | $2^{(3^2)} = 2^9$ ขวาไปซ้าย |
| `-2 ** 2` | `-4` | ยกกำลังก่อนติดลบ คือ $-(2^2)$ |
| `n1 + n2 + n3 / 3` (5, 10, 15) | `20.0` | หารแค่ `n3` — **bug ค่าเฉลี่ยที่พบบ่อย** ต้องเขียน `(n1 + n2 + n3) / 3` = `10.0` |

การปัดเศษแสดงผล: `round(3.14159, 2)` → `3.14` (ในคาบใช้ `lena = round(lena, 2)` แสดงขนาดเวกเตอร์)

### การปัดเศษและฟังก์ชันใน `math`
ต้อง `import math` ก่อนจึงใช้ `math.sqrt()` (รากที่สอง คืนค่า `float` เสมอ) และค่าคงที่ `math.pi` ได้ ส่วน `round(x, n)` เป็นฟังก์ชันในตัว (Built-in) ปัด `x` ให้เหลือทศนิยม `n` ตำแหน่ง ถ้าไม่ใส่ `n` จะได้จำนวนเต็ม (`int`)

```python
import math
print(round(math.sqrt(2), 2))   # sqrt(2) = 1.41421356... → 1.41
print(round(math.pi, 3))        # pi = 3.14159265... → 3.142
print(round(10 / 3, 2))         # 3.33333... → 3.33
print(math.sqrt(16))            # 4.0  (float แม้รากลงตัว)
```
```
1.41
3.142
3.33
4.0
```

**วิธีคิดในข้อสอบ**: เขียนค่าจริงให้ยาวกว่าที่ต้องการ 1 ตำแหน่ง แล้วดูหลักถัดไป เช่น $\pi = 3.1415\ldots$ ต้องการ 3 ตำแหน่ง → หลักที่ 4 คือ 5 จึงปัดขึ้นเป็น 3.142 · $\sqrt{2} = 1.414\ldots$ หลักที่ 3 คือ 4 จึงปัดลงเป็น 1.41

| นิพจน์ | ผลลัพธ์ | ชนิด | หลักการ |
|---|---|---|---|
| `round(math.sqrt(2), 2)` | `1.41` | `float` | ปัดให้เหลือ 2 ตำแหน่ง |
| `round(math.pi, 3)` | `3.142` | `float` | หลักที่ 4 เป็น 5 → ปัดขึ้น |
| `round(10 / 3, 2)` | `3.33` | `float` | `/` ได้ 3.333… ก่อน แล้วจึงปัด |
| `round(3.7)` | `4` | `int` | ไม่ใส่ `n` → ปัดเป็นจำนวนเต็มที่ใกล้ที่สุด |
| `int(3.7)` | `3` | `int` | **ตัดทศนิยมทิ้ง** (เข้าหาศูนย์) ไม่ปัด |
| `int(-3.7)` | `-3` | `int` | ตัดทิ้งเข้าหาศูนย์ |
| `-3.7 // 1` | `-4.0` | `float` | `//` ปัดลงไปทางลบอนันต์ (และเป็น float เพราะ −3.7 เป็น float) |
| `7 // 2` | `3` | `int` | หารปัดลง |
| `round(7 / 2)` | `4` | `int` | 3.5 → จำนวนคู่ที่ใกล้ที่สุดคือ 4 |
| `round(2.5)` | `2` | `int` | **ปัดครึ่งไปหาเลขคู่ (Banker's Rounding)** ไม่ใช่ 3 |
| `round(3.5)`, `round(0.5)` | `4`, `0` | `int` | กฎเดียวกัน: ครึ่งพอดีไปหาเลขคู่ |

> [!warning] `round` · `int` · `//` ไม่เหมือนกัน
> - `round()` = **ปัด** ไปค่าที่ใกล้ที่สุด (ครึ่งพอดีไปหาเลขคู่)
> - `int()` = **ตัด** ทศนิยมทิ้งเข้าหาศูนย์ (`int(3.9) = 3`, `int(-3.9) = -3`)
> - `//` = **ปัดลง** ไปทางลบอนันต์ (`-7 // 2 = -4`) และคืน `float` ถ้ามีตัวใดเป็น `float`
>
> ไพทอน 3 ใช้ Banker's Rounding เพื่อลดความเอนเอียงเมื่อปัดข้อมูลจำนวนมาก จึงได้ `round(2.5) = 2` ต่างจากที่เรียนมาว่า "5 ขึ้นเสมอ" — ข้อสอบมักใช้ค่าที่ไม่ใช่ครึ่งพอดี (เช่น 1.414…, 3.1415…) จึงปัดตามปกติได้ นอกจากนี้ทศนิยมบางค่าเก็บในคอมพิวเตอร์ไม่ตรงพอดี เช่น `round(2.675, 2)` ได้ `2.67` เพราะค่าจริงที่เก็บคือ 2.67499…

### ตรรกะบูลีน: `and` `or` `not`
นิพจน์เปรียบเทียบ เช่น `age >= 18` ให้ค่าความจริง (Boolean) `True` หรือ `False` และนำมารวมกันได้ด้วยตัวดำเนินการตรรกะ (Logical Operator) 3 ตัว

| ตัวดำเนินการ | ได้ `True` เมื่อ | ตัวอย่าง |
|---|---|---|
| `A and B` | `A` **และ** `B` เป็นจริงทั้งคู่ | `True and False` → `False` |
| `A or B` | อย่างน้อยหนึ่งตัวเป็นจริง | `True or False` → `True` |
| `not A` | `A` เป็นเท็จ (กลับค่า) | `not True` → `False` |

**ลำดับความสำคัญ**: วงเล็บ `( )` ทำก่อนเสมอ → `not` → `and` → `or` (เทียบได้กับ วงเล็บ → เครื่องหมายลบหน้าตัวเลข → คูณ → บวก) และตัวดำเนินการตรรกะทั้งหมดทำ **หลัง** การเปรียบเทียบ (`<`, `==`, `>=` …) และหลังเลขคณิต

![ตารางความจริงของ and or not และต้นไม้การประเมินนิพจน์ (True and False) or True, (False or True) and False, (True or False) and True ทีละขั้น](/infographics/02/boolean-logic.svg)

**วิธีอ่านภาพ** (สีเขียว = `True`, แดง = `False`, ส้ม = ส่วนที่ต้องทำก่อน)
1. ตารางความจริง: `and` มีช่องเขียวเพียงแถวเดียว (จริงทั้งคู่) ส่วน `or` มีช่องแดงเพียงแถวเดียว (เท็จทั้งคู่) และ `not` กลับค่า
2. แถบลำดับความสำคัญ อ่านซ้ายไปขวา: `( )` → `not` → `and` → `or`
3. ต้นไม้ทั้งสามข้อ อ่านจากใบด้านล่างขึ้นไป: กรอบเส้นประสีส้มคือส่วนในวงเล็บ ได้ค่าในป้ายข้างตัวดำเนินการ แล้วนำไปรวมกับใบขวาที่ราก ขั้น 1–2 ใต้ต้นไม้คือการลดรูปเดียวกันในรูปข้อความ กรอบคำตอบสีส้มสรุปว่าข้อ 1–3 พิมพ์ `True`, `False`, `True`
4. การลัดวงจร: `False and X` และ `True or X` รู้คำตอบโดยไม่ต้องประเมิน `X`
5. กล่อง ✗/✓: `True or False and False` ห้ามทำซ้ายไปขวา (ได้ `False` ผิด) ต้องทำ `and` ก่อนจึงได้ `True`

**ไล่ค่าทีละขั้น (แนวข้อสอบ)**

| นิพจน์ | ขั้น 1: ในวงเล็บ | ขั้น 2: นอกวงเล็บ | `print` ได้ |
|---|---|---|---|
| `(True and False) or True` | `True and False` → `False` | `False or True` → `True` | `True` |
| `(False or True) and False` | `False or True` → `True` | `True and False` → `False` | `False` |
| `(True or False) and True` | `True or False` → `True` | `True and True` → `True` | `True` |

**ถ้าไม่มีวงเล็บ** ต้องใส่วงเล็บให้เองตามลำดับความสำคัญก่อนคำนวณ

| นิพจน์ | ใส่วงเล็บตามลำดับ | ผล |
|---|---|---|
| `True or False and False` | `True or (False and False)` | `True` (ถ้าทำซ้ายไปขวาจะได้ `False` — ผิด) |
| `not True or True` | `(not True) or True` | `True` |
| `not (True or True)` | วงเล็บก่อน แล้ว `not` | `False` |
| `not False and False` | `(not False) and False` | `False` |
| `3 > 2 and 5 < 4` | `(3 > 2) and (5 < 4)` | `True and False` → `False` |

> [!tip] การลัดวงจร (Short-circuit Evaluation)
> ไพทอนหยุดประเมินทันทีเมื่อรู้คำตอบแล้ว: `False and X` ได้ `False` โดย **ไม่ประเมิน X** และ `True or X` ได้ `True` โดยไม่ประเมิน X เช่น `0 and 1/0` ได้ `0` โดยไม่เกิด `ZeroDivisionError` เพราะไม่เคยคำนวณ `1/0` — ในเกมใช้หลักนี้เขียน `if other is not self and self.rect.colliderect(other.rect):` (บทที่ 7) ให้ตรวจเงื่อนไขที่ถูกกว่าก่อน
>
> หมายเหตุ: เมื่อตัวถูกดำเนินการไม่ใช่บูลีน `and`/`or` จะคืน **ตัวถูกดำเนินการตัวที่ตัดสินผล** ไม่ใช่ `True`/`False` เช่น `5 and 7` ได้ `7`, `0 or "x"` ได้ `'x'` — ข้อสอบบทนี้ใช้เฉพาะ `True`/`False` จึงได้ผลเป็นบูลีนเสมอ

> [!question]- ฝึกทำ: จงหาผลลัพธ์ของ `print(9 // 4, 9 % 4, 9 / 4, 9 ** 0.5)`
> > [!success]- เฉลย
> > `2 1 2.25 3.0`

> [!question]- ฝึกทำ: จงหาผลลัพธ์ของ `print(30 // 4, 30 % 4, -9 // 4, 2 + 6 / 2)`
> > [!success]- เฉลย
> > `7 2 -3 5.0` — $30 = 7 \times 4 + 2$ · $-9/4 = -2.25$ ปัดลงเป็น $-3$ · `6 / 2` ทำก่อนได้ `3.0` แล้วบวก 2 ได้ `5.0` (เป็น float เพราะ `/`)

> [!question]- ฝึกทำ: จงบอกผลลัพธ์ของ `print((True and False) or True)`, `print((False or True) and False)` และ `print((True or False) and True)`
> > [!success]- เฉลย
> > `True`, `False`, `True` — ข้อ 1: `True and False` = `False` แล้ว `False or True` = `True` · ข้อ 2: `False or True` = `True` แล้ว `True and False` = `False` · ข้อ 3: `True or False` = `True` แล้ว `True and True` = `True`

> [!question]- ฝึกทำ: จงบอกผลลัพธ์ของ `print(True or False and False, not (False and False), 5 > 3 and not 2 > 1)`
> > [!success]- เฉลย
> > `True True False` — ข้อแรก `and` ทำก่อน: `True or (False and False)` = `True or False` = `True` · ข้อสอง วงเล็บก่อน `False and False` = `False` แล้ว `not False` = `True` · ข้อสาม เปรียบเทียบก่อน: `True and not True` = `True and False` = `False`

> [!question]- ฝึกทำ: จงบอกผลลัพธ์ของ `print(round(math.sqrt(2), 2), round(math.pi, 3), round(10 / 3, 2), round(2.5), int(2.9))`
> > [!success]- เฉลย
> > `1.41 3.142 3.33 2 2` — $\sqrt{2} = 1.414\ldots$ → 1.41 · $\pi = 3.1415\ldots$ หลักที่ 4 เป็น 5 → 3.142 · $10/3 = 3.333\ldots$ → 3.33 · `round(2.5)` ครึ่งพอดีไปหาเลขคู่ได้ 2 · `int(2.9)` ตัดทศนิยมได้ 2 (ไม่ใช่ 3)

## 3. ผลคูณจุดของเวกเตอร์ (Dot Product)

### นิยาม
$$\mathbf{a} \cdot \mathbf{b} = \sum_{i=1}^{n} a_i b_i = a_1b_1 + a_2b_2 + \dots + a_nb_n$$
ผลลัพธ์เป็น **สเกลาร์ (Scalar)** ไม่ใช่เวกเตอร์

### ความหมายเชิงเรขาคณิต
$$\mathbf{a} \cdot \mathbf{b} = |\mathbf{a}|\,|\mathbf{b}|\cos\theta$$
- มากกว่า 0 → มุมระหว่างเวกเตอร์น้อยกว่า 90° (ชี้ไปทางเดียวกัน)
- เท่ากับ 0 → ตั้งฉากกัน (Perpendicular)
- น้อยกว่า 0 → มุมมากกว่า 90° (ชี้ไปทางตรงข้าม)

![ผลคูณจุดของ a = (4, 2) และ b = (1, 3) วาดตามสเกล พร้อมขั้นตอนคูณทีละตำแหน่ง บวก และตรวจมุมด้วย cos](/infographics/02/dot-product.svg)

**วิธีอ่านภาพ** (น้ำเงิน = $\mathbf{a}$, เขียว = $\mathbf{b}$, ม่วง = มุม)
1. คูณสมาชิกดัชนีเดียวกัน: $4 \times 1 = 4$ และ $2 \times 3 = 6$
2. บวกผลคูณ $4 + 6 = 10$ ได้ตัวเลขตัวเดียว (สเกลาร์)
3. หาขนาด $\lvert\mathbf{a}\rvert = \sqrt{20} \approx 4.472$ และ $\lvert\mathbf{b}\rvert = \sqrt{10} \approx 3.162$
4. $\cos\theta = 10/(4.472 \times 3.162) = 10/\sqrt{200} \approx 0.7071$ จึงได้ $\theta = 45^\circ$ ตรงกับส่วนโค้งสีม่วงในกราฟซ้ายที่วาดตามสเกลจริง — กรอบคำตอบสีส้มสรุป $\mathbf{a}\cdot\mathbf{b} = 10$, $\theta = 45^\circ$
5. แถบสามกล่องบอกว่าเครื่องหมายของผลคูณจุดบอกชนิดมุมได้ทันที (บวก = แหลม, 0 = ตั้งฉาก, ลบ = ป้าน) และกล่อง ✗/✓ เตือนว่าคูณแล้วต้องบวก ไม่ใช่ได้เวกเตอร์ $(4, 6)$

### หามุมระหว่างเวกเตอร์ทีละขั้น
จัดรูปสูตรใหม่ได้ $\cos\theta = \dfrac{\mathbf{a}\cdot\mathbf{b}}{\lvert\mathbf{a}\rvert\,\lvert\mathbf{b}\rvert}$ ตัวอย่าง $\mathbf{a} = (4, 2)$, $\mathbf{b} = (1, 3)$

1. ผลคูณจุด: $4(1) + 2(3) = 10$
2. ขนาด: $\lvert\mathbf{a}\rvert = \sqrt{16 + 4} = \sqrt{20} \approx 4.472$ และ $\lvert\mathbf{b}\rvert = \sqrt{1 + 9} = \sqrt{10} \approx 3.162$
3. $\cos\theta = 10 / (4.472 \times 3.162) = 10/\sqrt{200} \approx 0.7071$
4. $\theta = \cos^{-1}(0.7071) = 45^\circ$

```python
import math
a, b = (4, 2), (1, 3)
dot = a[0]*b[0] + a[1]*b[1]
cos_t = dot / (math.sqrt(20) * math.sqrt(10))
print(dot, round(cos_t, 4), round(math.degrees(math.acos(cos_t)), 1))
```
```
10 0.7071 45.0
```

> [!tip] ใช้ในเกมที่ไหน
> เกมไม่ได้ต้องการมุมทุกครั้ง บ่อยครั้งแค่ดู **เครื่องหมาย** ของผลคูณจุดก็พอ เช่น ศัตรูอยู่ "ข้างหน้า" ยานหรือไม่ (ผลคูณจุดของทิศหัวยานกับเวกเตอร์จากยานไปศัตรูเป็นบวก) ซึ่งต่อยอดจากการหมุนและทิศของยานในบทที่ 6–7

### จากสูตรสู่โค้ด
```python
# 3 มิติแบบเขียนตรง
def dotv3(v, u):
    return v[0]*u[0] + v[1]*u[1] + v[2]*u[2]

print(dotv3((1, 2, 3), (1, 0, 1)))    # 1 + 0 + 3 = 4
```
เวกเตอร์ในบทนี้เก็บเป็น **ทูเพิล** `(1, 2, 3)` เข้าถึงสมาชิกด้วยดัชนี `v[0]`, `v[1]`, `v[2]` (ดัชนีเริ่มที่ 0)

### ตัวอย่างคำนวณมือ
$(1, 2, 3) \cdot (1, 0, 1) = 1\cdot1 + 2\cdot0 + 3\cdot1 = 4$

$(1, 2, 0, 4) \cdot (1, 2, 3, 4) = 1 + 4 + 0 + 16 = 21$

เขียนเป็นตารางคูณทีละดัชนีจะไม่หลงตำแหน่ง (เทคนิคที่ใช้ในข้อสอบ)

| ดัชนี `i` | `v[i]` | `u[i]` | `v[i]*u[i]` |
|---|---|---|---|
| 0 | 1 | 1 | 1 |
| 1 | 2 | 2 | 4 |
| 2 | 0 | 3 | 0 |
| 3 | 4 | 4 | 16 |
| **รวม** | | | **21** |

> [!warning] `dotv3` กับเวกเตอร์ 4 มิติ
> ถ้าเรียก `dotv3((1, 2, 0, 4), (1, 2, 3, 4))` จะได้ `5` (เฉพาะ 3 แถวแรกของตาราง) โดย **ไม่มี error** เพราะ `dotv3` ไม่เคยอ่าน `v[3]` — นี่คือเหตุผลที่หัวข้อถัดไปต้องเปลี่ยนเป็นการวนซ้ำ

> [!question]- ฝึกทำ: จงหา $(2, -1, 4) \cdot (3, 5, 1)$
> > [!success]- เฉลย
> > $6 - 5 + 4 = 5$

> [!question]- ฝึกทำ: เวกเตอร์ (3, 4) และ (−4, 3) ตั้งฉากกันหรือไม่
> > [!success]- เฉลย
> > $3(-4) + 4(3) = -12 + 12 = 0$ จึงตั้งฉากกัน (เป็นผลจากการหมุน 90° ซึ่งจะเรียนในบทที่ 6)

## 4. ขนาดของเวกเตอร์และการวนซ้ำกี่มิติก็ได้

### ขนาดของเวกเตอร์ (Magnitude)
มาจากทฤษฎีบทพีทาโกรัส
$$|\mathbf{v}| = \sqrt{v_1^2 + v_2^2 + \dots + v_n^2} = \sqrt{\mathbf{v}\cdot\mathbf{v}}$$

```python
import math

def lenv3(v):
    s = v[0]*v[0] + v[1]*v[1] + v[2]*v[2]
    return math.sqrt(s)

def lenv(v):                      # ขนาดของเวกเตอร์กี่มิติก็ได้
    sumofPower2 = 0
    for i in range(len(v)):
        sumofPower2 += v[i]*v[i]
    return math.sqrt(sumofPower2)

print(lenv((1, 2, 3, 4)))         # sqrt(30) ≈ 5.477
```

### ทำไมต้องวนซ้ำ
`lenv3` เขียนบวกสามพจน์ตายตัว จึงใช้ได้เฉพาะ 3 มิติ ส่วน `lenv` ใช้ `for i in range(len(v))` วนตามจำนวนสมาชิกจริง จึงใช้ได้ทั้ง 2, 3, 4 มิติ หรือมากกว่า — หลักเดียวกันใช้ทำ `dotv` ให้รองรับทุกมิติ:

```python
def dotv(v, u):
    total = 0
    for i in range(len(v)):
        total += v[i] * u[i]
    return total
```

### ไล่ค่า `lenv((1, 2, 3, 4))` ทีละรอบ
`len(v) = 4` ดังนั้น `range(4)` ให้ `i = 0, 1, 2, 3` และตัวแปรสะสม `sumofPower2` เริ่มที่ 0

| รอบ | `i` | `v[i]` | `v[i]*v[i]` | `sumofPower2` หลังบวก |
|---|---|---|---|---|
| 1 | 0 | 1 | 1 | 0 + 1 = 1 |
| 2 | 1 | 2 | 4 | 1 + 4 = 5 |
| 3 | 2 | 3 | 9 | 5 + 9 = 14 |
| 4 | 3 | 4 | 16 | 14 + 16 = 30 |
| จบลูป | | | | `math.sqrt(30)` ≈ 5.477 |

รูปแบบ "ตั้งตัวแปรสะสมเป็น 0 → วนบวกทีละตัว → ใช้ผลหลังจบลูป" เรียกว่า **รูปแบบตัวสะสม (Accumulator Pattern)** เป็นแม่แบบของ `dotv`, ผลรวม, ค่าเฉลี่ย และการนับ ข้อสังเกตสำคัญ: `return` ต้องอยู่ **นอกลูป** (ย่อหน้าระดับเดียวกับ `for`) ถ้าย่อหน้าเข้าไปในลูป ฟังก์ชันจะคืนค่าหลังรอบแรก ได้ $\sqrt{1} = 1.0$

![ขนาดของเวกเตอร์: พีทาโกรัสของ (3, 4) และการไล่ค่า lenv((1, 2, 3, 4)) ที่สะสมกำลังสอง 1, 5, 14, 30 จนได้ √30 ≈ 5.477](/infographics/02/magnitude-loop.svg)

**วิธีอ่านภาพ** (น้ำเงิน = ค่าจากเวกเตอร์, เขียว = ตัวสะสม, ส้ม = คำตอบ)
1. ที่มาของสูตร: เวกเตอร์ $(3, 4)$ วาดตามสเกลเป็นสามเหลี่ยมมุมฉาก ด้านตรงข้ามมุมฉากยาว $\sqrt{9 + 16} = 5$ — กล่องโค้ดขวาขยายแนวคิดเดียวกันไปกี่มิติก็ได้
2. `len(v) = 4` ทำให้ `range(4)` ให้ `i = 0, 1, 2, 3` แต่ละช่องคือ `v[i]` ที่ถูกอ่าน
3. แท่งสีเขียวยาวขึ้นตามตัวสะสม ($+1, +4, +9, +16$ → 1, 5, 14, 30) ตรงกับตารางไล่ค่าด้านล่าง
4. จบลูปแล้วจึงถอดราก ได้ $\sqrt{30} \approx 5.477$ (ปัด 2 ตำแหน่ง = 5.48) ในกรอบคำตอบ
5. กล่อง ✗/✓: ถ้าย่อหน้า `return` เข้าไปในลูป ฟังก์ชันคืน $\sqrt{1} = 1.0$ ตั้งแต่รอบแรก

### เทียบ `dotv3` กับ `dotv` บนเวกเตอร์ 4 มิติ
| การเรียก | ดัชนีที่ถูกอ่าน | ผลลัพธ์ | ถูกหรือไม่ |
|---|---|---|---|
| `dotv3((1,2,0,4), (1,2,3,4))` | 0, 1, 2 (ตายตัว) | `5` | ✗ ตก `4·4 = 16` |
| `dotv((1,2,0,4), (1,2,3,4))` | 0, 1, 2, 3 (ตาม `len(v)`) | `21` | ✓ |
| `dotv((3,4), (-4,3))` | 0, 1 | `0` | ✓ ใช้กับ 2 มิติได้ด้วย |

และเมื่อมี `dotv` แล้ว ขนาดเวกเตอร์เขียนสั้นได้เป็น `math.sqrt(dotv(v, v))` เพราะ $\lvert\mathbf{v}\rvert = \sqrt{\mathbf{v}\cdot\mathbf{v}}$ — เป็นตัวอย่างการนำฟังก์ชันกลับมาใช้ซ้ำ

### เวกเตอร์หนึ่งหน่วย (Unit Vector)
หารสมาชิกทุกตัวด้วยขนาด ได้เวกเตอร์ทิศเดิมที่ยาว 1 หน่วย: $\hat{\mathbf{v}} = \mathbf{v} / \lvert\mathbf{v}\rvert$ เช่น $(3, 4)$ มีขนาด 5 จึงได้ $(0.6, 0.8)$ ซึ่ง $\sqrt{0.36 + 0.64} = 1$ ในเกมบทที่ 6–8 ใช้แนวคิดนี้ผ่าน `normalize()` ให้ยาน ศัตรู และกระสุนเคลื่อนที่ด้วยความเร็วเท่ากันทุกทิศ (ต้องระวังเวกเตอร์ศูนย์ที่ขนาดเป็น 0 ห้ามหาร)

> [!warning] ถ้าเวกเตอร์ยาวไม่เท่ากัน
> `dotv((1,2,3), (1,2))` วนตาม `len(v) = 3` เมื่อ `i = 2` จะเรียก `u[2]` ซึ่งไม่มี → `IndexError` ควรตรวจ `len(v) == len(u)` ก่อน

### ส่วนประกอบของฟังก์ชัน
```python
def greeting(name):                  # def ชื่อ(พารามิเตอร์):
    print(f"# My name is {name}. #")

greeting("Aj. Bank")                 # อาร์กิวเมนต์ (Argument)
```

- หลายพารามิเตอร์จับคู่กับอาร์กิวเมนต์ **ตามลำดับตำแหน่ง**: `def greeting(name, age)` + `greeting("Sarayut", 40)` → `name = "Sarayut"`, `age = 40` (สลับลำดับอาร์กิวเมนต์ = สลับค่า) ส่วนพารามิเตอร์ที่รับมาแต่ไม่ได้ใช้ในตัวฟังก์ชันไม่ทำให้เกิด error — ดูตัวอย่างบั๊ก `{name}` ซ้ำสองช่องใน [หัวข้อ 1](#topic-1)

## 5. การวนซ้ำและการวาดรูปด้วย # แบบ Top-Down Design

### `for` กับ `range()`
| คำสั่ง | ค่าที่ได้ | จำนวนรอบ |
|---|---|---|
| `range(5)` | 0, 1, 2, 3, 4 | 5 |
| `range(1, 6)` | 1, 2, 3, 4, 5 | 5 |
| `range(1, 10, 3)` | 1, 4, 7 | 3 |
| `range(5, 0, -1)` | 5, 4, 3, 2, 1 | 5 |

`range(start, stop, step)` **ไม่รวม** ค่า `stop`

### วาดเส้นและสี่เหลี่ยม
```python
def line(n):
    for i in range(n):
        print("#", end="")      # end="" ไม่ขึ้นบรรทัดใหม่
    print()                     # ขึ้นบรรทัดใหม่เมื่อครบแถว

def block(row, col):
    for i in range(row):
        line(col)

block(2, 10)
```

`line(n)` ใช้การวนซ้ำ 1 ชั้น ส่วน `block(row, col)` เรียก `line()` ซ้ำ ซึ่งเทียบเท่า **การวนซ้ำซ้อน (Nested Loop)** — จำนวนครั้งที่พิมพ์ `#` = row × col = 20

![ตาราง 2 × 10 แสดงลำดับการพิมพ์ # ของ block(2, 10) และบันไดของ triangle(4) พร้อมตารางสะสมจำนวน #](/infographics/02/nested-loop-grid.svg)

**วิธีอ่านภาพ** (น้ำเงิน = ลูปใน, ส้ม = ลูปนอก, เขียว = `triangle`)
1. อ่านโค้ด `line(n)` (ลูปใน สีน้ำเงิน) และ `block(row, col)` (ลูปนอก สีส้ม) ที่เรียก `line(col)` ซ้ำ `row` ครั้ง
2. ตาราง 2 × 10: แถว `i=0`, `i=1` คือรอบของลูปนอก คอลัมน์ 0–9 คือรอบของลูปใน เลขในช่องคือ # ตัวที่เท่าไร — พิมพ์ครบ 10 ตัวของแถวแรก (1–10) แล้ว `print()` ขึ้นบรรทัด (↵) ก่อนเริ่ม 11–20
3. นับได้ row × col = 2 × 10 = **20** ตัว (กรอบคำตอบ)
4. `triangle(4)`: แถวที่ `i` เรียก `line(i + 1)` จึงยาว 1, 2, 3, 4 และตารางขวาสะสม 1 → 3 → 6 → 10
5. สูตร $n(n+1)/2$: $4 \times 5 / 2 = 10$ (`triangle(10)` = 55) และกล่อง ✗/✓ เตือนว่าลืม `end=""` ทุก # จะขึ้นบรรทัดใหม่กลายเป็นเสา

### ไล่ลำดับการทำงานของลูปซ้อน
ถ้าเขียน `block(2, 3)` แบบลูปซ้อนตรง ๆ (ใช้ `j` สำหรับลูปในเพื่อไม่ให้สับสน)
```python
for i in range(2):          # ลูปนอก: แถว
    for j in range(3):      # ลูปใน: คอลัมน์
        print("#", end="")
    print()                 # อยู่ในลูปนอก แต่อยู่นอกลูปใน
```

| ลำดับ | `i` | `j` | การกระทำ |
|---|---|---|---|
| 1–3 | 0 | 0, 1, 2 | พิมพ์ `###` |
| — | 0 | (จบลูปใน) | `print()` ขึ้นบรรทัด |
| 4–6 | 1 | 0, 1, 2 | พิมพ์ `###` |
| — | 1 | (จบลูปใน) | `print()` ขึ้นบรรทัด |

กฎจำ: **ลูปในวิ่งครบทุกรอบ ต่อ 1 รอบของลูปนอก** จำนวนครั้งที่คำสั่งในสุดทำงานจึงเท่ากับผลคูณของจำนวนรอบ (2 × 3 = 6) และตำแหน่งย่อหน้าของ `print()` เป็นตัวกำหนดว่าขึ้นบรรทัดเมื่อไร

### การออกแบบจากบนลงล่าง (Top-Down Design)
แยกปัญหาใหญ่เป็นปัญหาย่อย แก้ทีละส่วนด้วยฟังก์ชันเล็ก แล้วประกอบกลับ

| ฟังก์ชัน | หน้าที่ | เรียกใช้ |
|---|---|---|
| `line(n)` | พิมพ์ # n ตัวแล้วขึ้นบรรทัด | — |
| `block(row, col)` | สี่เหลี่ยม | `line(col)` row ครั้ง |
| `triangle(n)` | สามเหลี่ยมชิดซ้าย | `line(i + 1)` |
| `tree()` | ต้นไม้ (การบ้าน) | `top_leaf()`, `bottom_leaf()`, `clone()` |

ข้อดี: อ่านง่าย ทดสอบทีละส่วนได้ แก้ไขที่เดียว และนำกลับมาใช้ซ้ำ (Reuse) — ดูเพิ่มที่ [EN-001-002 บท 05 การออกแบบจากบนลงล่าง](https://en-001-002-computer-programming.vercel.app/module/05)

### ตัวอย่างเต็ม: ต้นไม้จาก `tree()`
การบ้านของบทนี้คือวาดต้นไม้ ขั้นแรกของ Top-Down คือ **มองภาพผลลัพธ์แล้วแบ่งเป็นส่วน** (ใบบน 3 แถว · ใบล่าง 3 แถว · ลำต้น 2 แถว) ขั้นที่สองคือหาว่าทุกแถวมีรูปแบบร่วมกันคือ "ช่องว่าง `s` ตัว ตามด้วย `#` `n` ตัว" จึงสร้างฟังก์ชันพื้นฐาน `linespace(s, n)` ขึ้นมาตัวเดียว

```python
def linespace(s, n):            # ฟังก์ชันระดับล่างสุด
    for i in range(s):
        print(" ", end="")
    for i in range(n):
        print("#", end="")
    print()

def top_leaf():                 # ใบบน: (3,1) (2,3) (1,5)
    for i in range(3):
        linespace(3 - i, 2*i + 1)

def bottom_leaf():              # ใบล่าง: (2,3) (1,5) (0,7)
    for i in range(3):
        linespace(2 - i, 2*i + 3)

def clone():                    # ลำต้น: (3,1) สองครั้ง
    for i in range(2):
        linespace(3, 1)

def tree():                     # ฟังก์ชันระดับบนสุด อ่านแล้วเข้าใจทันที
    top_leaf()
    bottom_leaf()
    clone()

tree()
```

**วิธีอ่านภาพ** (เขียว = ใบบน, น้ำเงิน = ใบล่าง, ส้ม = ลำต้น)
1. ระดับบนสุด: `tree()` เรียก 3 ฟังก์ชันจากซ้ายไปขวาตามลำดับ
2. ระดับกลาง: `top_leaf()` (ใบบน 3 แถว) `bottom_leaf()` (ใบล่าง 3 แถว) `clone()` (ลำต้น 2 แถว) — กล่องซ้ายล่างสรุปว่าแต่ละตัวส่ง `(s, n)` อะไรให้ `linespace`
3. ระดับล่างสุด: ทั้งสามเรียก `linespace(s, n)` ตัวเดียวกัน ซึ่งพิมพ์ช่องว่าง `s` ตัวตามด้วย `#` `n` ตัว
4. ผลลัพธ์ 8 แถวทางขวา ช่องเส้นประคือช่องว่าง สีของ `#` บอกว่าฟังก์ชันใดพิมพ์ และ `(s, n)` ท้ายแถวคืออาร์กิวเมนต์ของแถวนั้น
5. ไล่ 1 แถว: `top_leaf` รอบ `i = 2` → `s = 3 − 2 = 1`, `n = 2×2 + 1 = 5` → `linespace(1, 5)` = แถวที่ 3 กรอบคำตอบรวม `#` ทั้งหมด 1+3+5+3+5+7+1+1 = **26** ตัว และกล่อง ✗/✓ เทียบการเขียน `print` 8 บรรทัดกับการแบ่งฟังก์ชันแบบ Top-Down

ลองตรวจสูตรของ `top_leaf()` ทีละรอบ: `i = 0` → `linespace(3, 1)` · `i = 1` → `linespace(2, 3)` · `i = 2` → `linespace(1, 5)` — ช่องว่างลด 1 และ `#` เพิ่ม 2 ทุกแถว ทำให้ `#` อยู่กึ่งกลางที่คอลัมน์ 3 เสมอ ถ้าต้องการต้นไม้ที่ใหญ่ขึ้นก็แก้แค่ฟังก์ชันระดับกลาง ไม่ต้องแตะ `linespace` เลย นี่คือประโยชน์ของการแยกระดับ

> [!tip] ถ้าเปลี่ยน `print("#", end="")` เป็น `print("#")`
> ทุก `#` จะขึ้นบรรทัดใหม่ รูปสี่เหลี่ยมจะกลายเป็นเสา `#` ยาว row × col บรรทัด
