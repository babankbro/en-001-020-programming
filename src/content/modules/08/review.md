## ภาพรวมบท
บทสุดท้ายของเกมยิงยานอวกาศ: ยิงกระสุนไปยังเมาส์ด้วยเวกเตอร์หนึ่งหน่วย ตรวจการชนด้วยกล่องขอบเขต (AABB) ลบกระสุนและศัตรูออกจากลิสต์อย่างปลอดภัย แล้วลดงานตรวจชนจาก 80,000 เหลือราว 1,700 ครั้งต่อเฟรมด้วยกริด พร้อมวิเคราะห์ด้วย Big-O และวัดผลจริงด้วย FPS

![บทที่ 8 ในภาพเดียว: การ์ด 4 ใบของการยิงไปที่เมาส์ AABB การลบจากลิสต์ และกริด พร้อมตัวอย่างตัวเลขและกับดัก และลำดับงาน 6 ขั้นใน 1 เฟรมกับงบเวลา 16.7 ms](/infographics/08/summary.svg)

**วิธีอ่านภาพ**
1. การ์ด 1 ยิงไปที่เมาส์: (60, 80) → normalize (0.6, 0.8) → × 10 = (6, 8) ทุกนัดเร็วเท่ากัน
2. การ์ด 2 AABB: จุดในกล่องต้องผ่านทั้ง x **และ** y เช่น (225, 320) อยู่ในศัตรู (200, 300) ขนาด 50×50 (กับดัก: ใช้ `or`)
3. การ์ด 3 ลบอย่างปลอดภัย: วนบนสำเนา `xs[:]` ได้ [1, 3] ถ้าลบขณะวนต้นฉบับได้ [1, 2, 3]
4. การ์ด 4 กริด: (row, col) = (y // 150, x // 150) เช่น (1000, 820) → `cells[5][6]`
5. การ์ด 5 ลำดับงานใน 1 เฟรม อ่านตามลูกศร ①→⑥: สร้างกระสุน → อัปเดตตำแหน่ง → ใส่ศัตรูลงกริด → ตรวจชนในช่อง → ลบที่ถูกยิง → วัด FPS พร้อมตัวเลข 80,000 → ≈1,667 ครั้งต่อเฟรม และ 28.4 ms ที่เกินงบ 16.7 ms

## สิ่งที่ต้องจำ (Key Facts)

### 1. ยิงกระสุนไปยังเมาส์ด้วยเวกเตอร์หนึ่งหน่วย
- ทิศกระสุน = **เมาส์ − ยาน** → `normalize()` (ขนาด 1) → `* bullet_speed` ทุกนัดจึงเร็วเท่ากัน
- (400, 300) → (460, 380): $(60, 80)$ ขนาด 100 → $(0.6, 0.8)$ → $(6, 8)$ ขนาด 10
- ไม่ normalize → ความเร็ว = ระยะเมาส์ เมาส์ยิ่งไกลยิ่งเร็ว · ห้าม normalize $(0, 0)$ ต้องตรวจ `length() > 0`
- กระสุนเคลื่อนที่ **ความเร็วคงที่** `pos += vel` → ตำแหน่ง $p_0 + n\mathbf{v}$ · ออกนอกจอ → `self.kill()`
- ยิงทุก k เฟรม: `if time_steps % k != 0: return None` → $60/k$ นัดต่อวินาทีที่ 60 FPS

### 2. การตรวจจับการชนแบบกล่องขอบเขต (AABB)
- **จุดในกล่อง**: `x <= px <= x+w` **and** `y <= py <= y+h` — ต้องจริงทั้งสองแกน
- ใช้ `or` ไม่ error แต่ผิด: นับชนทุกจุดที่อยู่แนวเดียวกับศัตรู (รูปกากบาท) ศัตรูตายทั้งแถว
- **กล่องซ้อนทับ**: $A_l < B_r \land A_r > B_l \land A_t < B_b \land A_b > B_t$ (ซ้อนทั้งแกน x และ y)
- Pygame: `a.rect.colliderect(b.rect)` · แตะขอบพอดี (เช่น $50 > 50$ เป็นเท็จ) = ไม่ชน
- ตรวจกระสุน B ลูกกับศัตรู E ตัวทุกคู่ = $B \times E$ ครั้ง

### 3. ลบวัตถุออกจากลิสต์อย่างปลอดภัย
- **ห้าม `remove` จากลิสต์ที่กำลังวน**: `for` เดินด้วยดัชนี ลบแล้วสมาชิกเลื่อนซ้าย ตัวถัดไปถูกข้าม
- `[1, 2, 2, 3]` ลบ 2 ขณะวน → `[1, 2, 3]` ✗ · วนบน `xs[:]` → `[1, 3]` ✓
- ทางแก้ 3 แบบ: วนบนสำเนา `bullets[:]` · จดไว้ใน `mask_to_remove` แล้วลบทีหลัง · List Comprehension
- `remove(x)` ลบเฉพาะตัว **แรก** ที่เท่ากับ x และต้องค้นหา → $O(B)$ ต่อครั้ง
- Sprite ใน Group ใช้ `self.kill()` ถอดตัวเองออกจากทุกกลุ่มได้อย่างปลอดภัย

### 4. การแบ่งพื้นที่ด้วยกริด (Spatial Grid)
- `cols = width // cell_size`, `rows = height // cell_size` → 1200×900 ช่อง 150 = **8 × 6 = 48 ช่อง**
- `get_cell(x, y)` คืน **(row, col) = (y // cell, x // cell)** · เข้าถึงด้วย `cells[row][col]`
- สร้างช่องว่างด้วย `[[] for _ in range(cols)]` ห้ามใช้ `[[]] * cols` (ลิสต์เดียวกันทุกช่อง)
- ทุกเฟรม: `clear()` → `add()` ศัตรูทุกตัว → ตรวจกระสุนกับศัตรูในช่องเดียวกัน
- พลาดวัตถุที่ **คร่อมเส้นแบ่ง** (ใบงาน: 129 จาก 181 คู่) → ตรวจช่องข้างเคียงด้วยได้ครบ 181 คู่ ใช้ 5,688 ครั้ง
- วัตถุที่ y = 900 พอดีได้ row = 6 → `IndexError` ต้องจำกัดด้วย `min(row, rows - 1)`

### 5. ความซับซ้อน Big-O และการวัด FPS
- Big-O บอกว่างานโตตามขนาดข้อมูลอย่างไร ไม่สนค่าคงที่ · ทุกคู่ $O(B \cdot E)$ · กริด $\approx O(B \cdot E / C)$
- $E$ เพิ่ม 2 เท่า → ตรวจทุกคู่เพิ่ม 2 เท่า · `triangle(n)` $O(n^2)$: $n$ เพิ่ม 2 เท่า งานเพิ่ม ≈ 4 เท่า
- `append` $O(1)$ · `remove` $O(B)$ · ตัวเลขกริดสมมติว่าวัตถุกระจายเท่ากัน (กรณีแย่ที่สุดยังเป็น $B \times E$)
- `clock.tick(60)` = เพดาน · `clock.get_fps()` = อัตราจริง ต่ำกว่า 60 แปลว่างานต่อเฟรมเกิน 16.7 ms
- `[s for s in all_sprites if isinstance(s, Bullet)]` นับเฉพาะกระสุนในกลุ่มที่ปนหลายชนิด

## สูตร (Formulas)
| เรื่อง | สูตร | โค้ด | ตัวอย่างตัวเลข |
|---|---|---|---|
| เวกเตอร์ยาน → เมาส์ | $\mathbf{d} = (m_x - s_x,\ m_y - s_y)$ | `dx = mouse_x - space.rect.centerx` | (460−400, 380−300) = (60, 80) |
| ความเร็วกระสุน | $\mathbf{v} = \dfrac{\mathbf{d}}{\lvert\mathbf{d}\rvert} \times \text{speed}$ | `Vector2(dx, dy).normalize() * bullet_speed` | (60, 80)/100 × 10 = (6, 8) |
| ตำแหน่งหลัง n เฟรม | $p_n = p_0 + n\mathbf{v}$ | `pos += vel` | n = 3: (418, 324) |
| อัตราการยิง | $\text{FPS} / k$ | `time_steps % k == 0` | 60 / 10 = 6 นัด/วินาที |
| จุดในกล่อง | $x \le p_x \le x+w \land y \le p_y \le y+h$ | `(px >= x and px <= x+w) and (py >= y and py <= y+h)` | (305, 148) ใน (260, 100, 50, 50) ✓ |
| กล่องซ้อนทับ | $A_l < B_r \land A_r > B_l \land A_t < B_b \land A_b > B_t$ | `a.rect.colliderect(b.rect)` | A (10, 10, 40, 40), B (45, 30, 20, 20) ✓ |
| ช่องกริด | $\text{row} = \lfloor y/c \rfloor,\ \text{col} = \lfloor x/c \rfloor$ | `return y // cell, x // cell` | (1000, 820) → (5, 6) |
| จำนวนช่อง | $\lfloor W/c \rfloor \times \lfloor H/c \rfloor$ | `cols * rows` | 8 × 6 = 48 |
| เปรียบเทียบทุกคู่ | $B \times E$ | `for b in bullets: for e in enemies:` | 40 × 2,000 = 80,000 |
| เปรียบเทียบด้วยกริด | $\approx B \times E / C$ | ตรวจเฉพาะ `cells[row][col]` | 80,000 / 48 ≈ 1,667 |
| งบเวลาต่อเฟรม | $1000 / \text{FPS}$ ms | `clock.tick(60)` | 1000 / 60 ≈ 16.7 ms |

## โค้ดที่ต้องเขียนได้โดยไม่ดู
```python
# 1) ความเร็วกระสุน
def bullet_velocity(sx, sy, mx, my, speed):
    dx, dy = mx - sx, my - sy
    length = math.sqrt(dx * dx + dy * dy)
    if length == 0:
        return (0, 0)
    return (dx / length * speed, dy / length * speed)

# 2) AABB
def point_in_box(px, py, x, y, w, h):
    return (px >= x and px <= x + w) and (py >= y and py <= y + h)

def boxes_overlap(ax, ay, aw, ah, bx, by, bw, bh):
    return ax < bx + bw and ax + aw > bx and ay < by + bh and ay + ah > by

# 3) ลบอย่างปลอดภัย
for bullet in bullets[:]:            # วนบนสำเนา
    if bullet.off_screen():
        bullets.remove(bullet)       # ลบจากต้นฉบับ

# 4) กริด
class Grid:
    def __init__(self, width, height, cell_size):
        self.cell_size = cell_size
        self.cols = width // cell_size
        self.rows = height // cell_size
        self.cells = [[[] for c in range(self.cols)] for r in range(self.rows)]

    def get_cell(self, x, y):
        return y // self.cell_size, x // self.cell_size

# 5) วัด FPS
fps_text = font.render(f"FPS: {clock.get_fps():.1f}", True, (255, 255, 255))
clock.tick(60)
```

## ตัวเลขที่ออกสอบบ่อย
- ยาน (400, 300) เมาส์ (460, 380) speed 10 → $(60, 80)$ → $(0.6, 0.8)$ → **(6, 8)** · ยาน (100, 100) เมาส์ (−20, 260) speed 15 → **(−9, 12)** · (300, 200) → (300, 50) → (0, −10)
- `time_steps % 10` ที่ 60 FPS = **6 นัด/วินาที** · `% 15` = 4 · `% 20` = 3
- ศัตรู (200, 300) 50×50: (225, 320) ชน · (260, 320) ไม่ชน · (230, 360) ไม่ชน · (250, 350) ชน (ขอบ) · กระสุน (305, 148) กับศัตรู (260, 100) **ชน**
- A (10, 10) 40×40 กับ B (45, 30) 20×20 ซ้อน · B (50, 30) แตะขอบ ไม่ซ้อน · B (20, 60) ไม่ซ้อน
- `[1, 2, 2, 3]` ลบ 2 ขณะวน → `[1, 2, 3]` · วนบนสำเนา → `[1, 3]` · `[[]] * 3` แล้ว append → `[[1], [1], [1]]`
- จอ 1200×900 cell 150 → **8 × 6 = 48 ช่อง** · (1000, 820) → **(5, 6)** · (150, 149) → (0, 1) · (1199, 899) → (5, 7)
- cell 100 → 12 × 9 = 108 ช่อง · (1199, 0) → (0, 11) · จอ 1600×1000 cell 200 → 8 × 5 = 40 · (1450, 610) → (3, 7)
- กระสุน 40 ศัตรู 2,000: ทุกคู่ **80,000** (60 FPS = 4.8 ล้านครั้ง/วินาที) · กริด 48 ช่อง ≈ **1,667** · 108 ช่อง ≈ 741
- ใบงาน `random.seed(8)`: ทุกคู่ 80,000 / ชน 181 · กริด 1,649 / ชน 129 (ลด 48.5 เท่า) · กริด + ช่องข้างเคียง 5,688 / ชน 181 (ลด ≈ 14 เท่า)
- กระสุน 30 ศัตรู 500 = 15,000 → ศัตรู 1,000 = 30,000 · กระสุน 50 ศัตรู 2,000 = 100,000
- `get_fps()` = 35.2 → เฟรมละ ≈ 28 ms เกินงบ 16.7 ms

## กับดักที่พบบ่อย
| ✗ ผิด | ✓ ถูก |
|---|---|
| ใช้ `(dx, dy)` เป็นความเร็วโดยไม่ normalize → เมาส์ไกลกระสุนเร็ว | `Vector2(dx, dy).normalize() * bullet_speed` |
| `normalize()` ตอนเมาส์อยู่กลางยาน → `ValueError` | ตรวจ `if direction.length() > 0:` ก่อน |
| เงื่อนไข AABB ใช้ `or` → ศัตรูตายทั้งแถว | ใช้ `and` ทั้งสองแกน |
| คิดว่าแตะขอบพอดีนับเป็นชนใน `boxes_overlap` | ใช้ `<` / `>` แบบเข้ม แตะขอบ ($50 > 50$) ไม่นับ |
| `for b in bullets: bullets.remove(b)` → ลบไม่หมด | วนบน `bullets[:]` หรือสร้างลิสต์ใหม่ |
| `get_cell` คืน `(x // cell, y // cell)` | คืน `(y // cell, x // cell)` = (row, col) |
| `cells = [[]] * cols` → ทุกช่องคือลิสต์เดียวกัน | `[[] for _ in range(cols)]` |
| วัตถุที่ y = 900 พอดี → row = 6 → `IndexError` | `min(row, self.rows - 1)` หรือใช้จุดศูนย์กลางที่อยู่ในจอ |
| เชื่อว่ากริดให้ผลเหมือนตรวจทุกคู่ | กริดช่องเดียวพลาดวัตถุคร่อมเส้นแบ่ง (129 vs 181) ต้องตรวจช่องข้างเคียง |
| อ่าน `clock.tick(60)` เป็น FPS จริง | ดูอัตราจริงจาก `clock.get_fps()` |

> [!question]- 2. ศัตรูมุมบนซ้าย (100, 130) ขนาด 50×50 กระสุนที่ (170, 150) ชนหรือไม่ ถ้าใช้ `and` และถ้าใช้ `or`
> > [!success]- เฉลย
> > x: $100 \le 170 \le 150$ เป็นเท็จ, y: $130 \le 150 \le 180$ เป็นจริง → `and` ได้ **ไม่ชน** (ถูก) แต่ `or` ได้ **ชน** (ผิด เพราะกระสุนอยู่ขวาของศัตรู 20 พิกเซล)

> [!question]- 3. โค้ดต่อไปนี้พิมพ์อะไร
> ```python
> xs = [2, 2, 3, 2]
> for x in xs:
>     if x == 2:
>         xs.remove(x)
> print(xs)
> ```
> > [!success]- เฉลย
> > `[3, 2]` — รอบ 1 (ดัชนี 0) ลบ 2 ได้ `[2, 3, 2]` · รอบ 2 (ดัชนี 1) ได้ x = 3 ไม่ลบ · รอบ 3 (ดัชนี 2) ได้ x = 2 แต่ `remove(2)` ลบตัว **แรก** ที่ดัชนี 0 ได้ `[3, 2]` · ดัชนี 3 ≥ ความยาว 2 จึงจบ

> [!question]- 4. กริดจอ 1200×900 `cell_size = 150` วัตถุที่ (735, 455) อยู่ช่อง (row, col) ใด
> > [!success]- เฉลย
> > row = 455 // 150 = 3, col = 735 // 150 = 4 → **(3, 4)** เข้าถึงด้วย `cells[3][4]`

> [!question]- 5. กระสุน 60 ลูก ศัตรู 1,200 ตัว ตรวจทุกคู่กี่ครั้งต่อเฟรม และถ้าใช้กริด 48 ช่องที่กระจายเท่ากันจะประมาณกี่ครั้ง
> > [!success]- เฉลย
> > ทุกคู่ $60 \times 1200 = 72{,}000$ ครั้ง · กริด $\approx 72{,}000 / 48 = 1{,}500$ ครั้ง
