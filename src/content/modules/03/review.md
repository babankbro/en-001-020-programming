**วิธีอ่านภาพ** (การ์ดสีน้ำเงินคือหัวข้อ แถบสีส้มคือตัวอย่างตัวเลขที่ต้องจำ ลูกศรเทาคือเหตุผลที่ต่อไปหัวข้อถัดไป)
1. ① `input()` คืน `str` เสมอ — `"15" + "5" = "155"` แต่ `int("15") + int("5") = 20`
2. ② ลิสต์และเมท็อด — จาก `[5, 10, 15, 20, 30]` หลัง `insert(1, 7)` ค่า `ns[2]` กลายเป็น 10
3. ③ ค่าเฉลี่ยด้วยการวนซ้ำ — `total`: 0 → 5 → 15 → 30 → 50 → 80 และ $80 / 5 = 16.0$
4. ④ การสุ่มและแผนภูมิ — `normal(50, 15)`: ช่วง $\mu \pm 2\sigma$ = 20–80 มีประมาณ 95 จาก 100 จุด
5. ⑤ สามเหลี่ยมชิดขวา — `triangle(4)` มี `#` 10 ตัว ช่องว่าง 6 ช่อง
6. กรอบสีเขียวคือที่ที่ความรู้นี้ถูกใช้ต่อ (ลิสต์ลูกบอลและศัตรูสุ่มในเกมบทที่ 5–8) และกล่อง ✗/✓ คือกับดักใหญ่ของบท: ลืมแปลงชนิดหลัง `input()`

## สิ่งที่ต้องจำ (Key Facts)

### 1. input() และการแปลงชนิดข้อมูล
- `input()` คืน **`str` เสมอ** แม้ผู้ใช้พิมพ์ตัวเลข → `"15" + "5"` = `"155"` (ต่อสายอักขระ ไม่ error แต่ผิด)
- แปลงก่อนคำนวณ: `int(input())` สำหรับจำนวนเต็ม · `float(input())` สำหรับทศนิยม
- `int("15")` = 15 · `int(3.9)` = 3 และ `int(-3.7)` = −3 (ตัดทศนิยมทิ้ง ไม่ปัด) · `int("3.5")` → `ValueError`
- `"7" * 2` = `"77"` (ทำซ้ำ) · `"10" + 20` → `TypeError` (ชนิดต่างกันบวกกันไม่ได้)
- `int(input(...))` ทำงานจากในออกนอก: แสดงข้อความ → รอพิมพ์ → ได้ str → แปลงเป็น int

### 2. ลิสต์และเมท็อดพื้นฐาน
- ลิสต์แก้ไขได้ (Mutable) ดัชนีเริ่ม 0 · `ns[-1]` ตัวสุดท้าย · ดัชนีสูงสุด `len(ns) - 1` เกินนั้น `IndexError`
- `append(x)` ต่อท้าย · `insert(i, x)` แทรกที่ดัชนี i ตัวหลังเลื่อนขวา · `pop()` ลบท้ายและคืนค่า · `pop(i)` ลบตามดัชนี · `remove(x)` ลบตาม **ค่า** ตัวแรก
- `append`/`insert`/`remove` คืน `None` → `ns = ns.append(x)` ทำให้ `ns` เป็น `None`
- `b = a` ไม่ได้สำเนา (สองชื่อ ลิสต์เดียว) · สำเนาจริงใช้ `a.copy()` หรือ `a[:]`
- ห้ามลบสมาชิกขณะวนลิสต์เดิม ให้วนบนสำเนา `for x in xs[:]:`

### 3. ค่าเฉลี่ย ผลรวม และการวนซ้ำบนลิสต์
- ค่าเฉลี่ย = `sum(ns) / len(ns)` ใช้ได้กับข้อมูลกี่ตัวก็ได้ (ต่างจาก `(n1 + n2 + n3) / 3`)
- ใช้ `/` เท่านั้น — `//` ทิ้งเศษ (`sum([1, 2, 3, 4]) // 4` = 2 แทน 2.5)
- วนเอง: `total = 0` → `for x in ns: total += x` → `total / len(ns)`
- `for x in ns` ได้ค่า · `for i in range(len(ns))` ได้ดัชนี (ใช้เมื่อต้องแก้ `ns[i]`)
- หา max เอง: เริ่ม `biggest = ns[0]` แล้วเทียบทีละตัว

### 4. การสุ่ม การแจกแจง และแผนภูมิด้วย Matplotlib/pandas
- `random.uniform(a, b)` จำนวนจริง · `random.randint(a, b)` จำนวนเต็ม **รวม b** · `random.seed(n)` สุ่มซ้ำได้เหมือนเดิม
- Uniform `np.random.uniform(low, high, size)` กระจายเท่ากันทั่วช่วง ค่าเฉลี่ย $(a+b)/2$ ไม่มีค่านอกช่วง
- Normal `np.random.normal(loc=μ, scale=σ, size)` กระจุกรอบ μ **ไม่มีขอบเขต** (seed 2 ได้ค่าสูงสุด 111.63)
- กฎ 68–95–99.7: $\mu\pm\sigma$ ≈ 68% · $\mu\pm2\sigma$ ≈ 95% · $\mu\pm3\sigma$ ≈ 99.7%
- `plt.scatter` สำหรับข้อมูลสุ่ม · `plt.plot` เชื่อมจุดตามลำดับ · `fig, (ax1, ax2) = plt.subplots(1, 2)` แล้วใช้ `ax.set_title`/`ax.set_xlim`
- `pd.read_csv(...)` ได้ DataFrame · `df["col"]` ได้ Series ส่งเข้า `scatter` ได้ · `len(df)` = จำนวนแถว

### 5. สามเหลี่ยมชิดขวาด้วย linespace และ Top-Down Design
- `linespace(s, n)` พิมพ์ช่องว่าง s ตัวตามด้วย `#` n ตัว แล้วขึ้นบรรทัดใหม่
- ชิดขวา: แถว i เรียก `linespace(n - i - 1, i + 1)` → ทุกแถวยาว n
- พีระมิด: `linespace(n - i - 1, 2*i + 1)` → แถวล่างกว้าง $2n - 1$
- `#` รวม $n(n+1)/2$ · ช่องว่างรวม $n(n-1)/2$
- Top-Down: ทดสอบฟังก์ชันพื้นฐานให้ถูกก่อน แล้วรูปใหญ่ที่เรียกใช้จะถูกตาม แก้ที่เดียวเปลี่ยนทุกรูป

## สูตร (Formulas)
| เรื่อง | สูตร | โค้ด | ตัวอย่างตัวเลข |
|---|---|---|---|
| ค่าเฉลี่ย | $\bar{x} = \frac{1}{n}\sum x_i$ | `sum(ns) / len(ns)` | `[5, 10, 15, 20, 30]` → 80/5 = 16.0 |
| ค่าเฉลี่ย uniform $[a, b]$ | $\frac{a+b}{2}$ | `random.uniform(a, b)` | `uniform(-5, 5)` → 0 · `uniform(0, 100)` → 50 |
| ช่วงของ normal | $\mu \pm k\sigma$ | `normal(loc=μ, scale=σ)` | μ = 50, σ = 15: 35–65, 20–80, 5–95 |
| จำนวนข้อมูลในช่วง | สัดส่วน × size | | `size=1000`, $\mu\pm\sigma$ → ≈ 683 (≈ 680) |
| แถว i ชิดขวา | ว่าง $n-i-1$, `#` $i+1$ | `linespace(n - i - 1, i + 1)` | n = 4, i = 1 → `"  ##"` |
| แถว i พีระมิด | ว่าง $n-i-1$, `#` $2i+1$ | `linespace(n - i - 1, 2*i + 1)` | n = 3, i = 2 → `"#####"` |
| `#` / ช่องว่างทั้งรูป | $\frac{n(n+1)}{2}$ / $\frac{n(n-1)}{2}$ | | n = 4 → 10 / 6 · n = 10 → 55 / 45 |

## โค้ดที่ต้องเขียนได้โดยไม่ดู
```python
# รับ 5 ค่า เก็บในลิสต์ แล้วหา max min ค่าเฉลี่ย
ns = []
for i in range(5):
    ns.append(int(input(f"n{i+1}: ")))
print(max(ns), min(ns), sum(ns) / len(ns))

# หาค่าเฉลี่ยด้วยการวนเอง
total = 0
for x in ns:
    total += x
avg = total / len(ns)

# สุ่มและวาดเทียบสองการแจกแจง
import numpy as np
import matplotlib.pyplot as plt
xs = np.random.uniform(low=0, high=100, size=100)
us = np.random.uniform(low=0, high=100, size=100)
ns = np.random.normal(loc=50, scale=15, size=100)
fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(14, 6))
ax1.scatter(xs, us, color='green', s=50); ax1.set_title('Uniform')
ax2.scatter(xs, ns, color='orange', s=50); ax2.set_title('Normal')
plt.show()

# สามเหลี่ยมชิดขวา
def linespace(s, n):
    for i in range(s):
        print(" ", end="")
    for i in range(n):
        print("#", end="")
    print()

def triangle(n):
    for i in range(n):
        linespace(n - i - 1, i + 1)
```

## ตัวอย่างไล่ค่า (Trace)
**ก. หาผลรวมด้วยลูป** `ns = [5, 10, 15, 20, 30]`

| รอบ | `x` | `total` ก่อน | `total` หลัง |
|---|---|---|---|
| 1 | 5 | 0 | 5 |
| 2 | 10 | 5 | 15 |
| 3 | 15 | 15 | 30 |
| 4 | 20 | 30 | 50 |
| 5 | 30 | 50 | 80 |

จบลูป `total = 80` → `80 / 5 = 16.0`

**ข. หาค่ามากสุดด้วยมือ** `ns = [12, 7, 20, 3, 9]` เริ่ม `biggest = ns[0] = 12`

| รอบ | `x` | `x > biggest` ? | `biggest` หลังรอบ |
|---|---|---|---|
| 1 | 12 | 12 > 12 ไม่จริง | 12 |
| 2 | 7 | 7 > 12 ไม่จริง | 12 |
| 3 | 20 | 20 > 12 **จริง** | 20 |
| 4 | 3 | 3 > 20 ไม่จริง | 20 |
| 5 | 9 | 9 > 20 ไม่จริง | 20 |

## ตัวเลขที่ออกสอบบ่อย
- ป้อน 15, 5: `n1 + n2` = `155` · `int(n1) + int(n2)` = 20 · ป้อน 7, 3: `a * 2, int(a) * int(b)` = `77 21`
- `[5, 10, 15, 20, 30]`: sum 80, len 5, max 30, min 5, avg 16.0 · append(40) → insert(1, 7) → pop() คืน 40 → pop(1) คืน 7 → กลับเป็น `[5, 10, 15, 20, 30]`
- `[2, 4, 6]` insert(0, 1) → append(8) → pop(2) คืน 4 → `ns[0] = 9` → `[9, 2, 6, 8]` · `[3, 6, 9]` insert(2, 7), pop(0), append → `[6, 7, 9, 3]`
- `[4, 8, 15, 16, 23, 42]` sum 108 avg 18.0 · `[12, 7, 20, 3, 9]` avg 10.2 มี 2 ตัวมากกว่าค่าเฉลี่ย (12, 20)
- `normal(loc=50, scale=15, size=100)` seed 2: 66 / 93 / 98 จุดใน 35–65 / 20–80 / 5–95 (ทฤษฎี 68.27% / 95.45% / 99.73%)
- `normal(loc=100, scale=10, size=1000)`: ใน 90–110 ≈ 680 ค่า · นอก 80–120 ≈ 50 ค่า (5% ของ 1000; ใช้ 4.55% ได้ ≈ 46)
- `triangle(4)`: `"   #"`, `"  ##"`, `" ###"`, `"####"` · `#` 10 ช่องว่าง 6 · `triangle(5)` ช่องว่าง 10 · `pyramid(5)` `#` รวม 25

## กับดักที่พบบ่อย
| ✗ ผิด | ✓ ถูก | เหตุผล |
|---|---|---|
| `n = input(); print(n + 5)` | `n = int(input()); print(n + 5)` | `"10" + 5` → `TypeError`; ลืมแปลงทั้งสองตัวได้ `"155"` |
| `r = int(input())` แล้วป้อน 2.5 | `r = float(input())` | `int("2.5")` → `ValueError` |
| `ns = ns.append(x)` | `ns.append(x)` | `append` คืน `None` |
| `ns.remove(1)` เพื่อลบตำแหน่ง 1 | `ns.pop(1)` | `remove` ลบตาม **ค่า** |
| `b = a` แล้วแก้ `b` | `b = a.copy()` | `b = a` คือลิสต์เดียวกัน |
| `for x in xs: xs.remove(x)` | `for x in xs[:]:` | ดัชนีเลื่อน ทำให้ข้ามสมาชิก |
| `avg = sum(ns) // len(ns)` | `avg = sum(ns) / len(ns)` | `//` ทิ้งเศษ |
| `range(1, 6)` จำลองลูกเต๋า | `random.randint(1, 6)` | `range` ไม่รวม 6 แต่ `randint` รวม |
| `plt.title(...)` กับแกนย่อย | `ax1.set_title(...)` | แกนจาก `subplots` ใช้เมท็อด `set_` |
| `plt.plot(xs, ys)` กับข้อมูลสุ่ม | `plt.scatter(xs, ys)` | `plot` เชื่อมจุดตามลำดับ ได้เส้นยุ่ง |
| `linespace(n - i, i + 1)` | `linespace(n - i - 1, i + 1)` | แถวยาว n + 1 รูปเลื่อนขวา |

> [!question]- ข้อ 2: เริ่มจาก `ns = [3, 6, 9, 12]` แล้วรัน `ns.insert(2, 7); x = ns.pop(); ns.append(x * 2)` ค่าของ `ns` และ `x` คืออะไร
> > [!success]- เฉลย
> > insert ได้ `[3, 6, 7, 9, 12]` → pop คืน `x = 12` เหลือ `[3, 6, 7, 9]` → append 24 ได้ `ns = [3, 6, 7, 9, 24]`, `x = 12`

> [!question]- ข้อ 3: `ns = [10, 20, 30, 45]` ค่าเฉลี่ยเท่าใด และมีกี่ตัวที่มากกว่าค่าเฉลี่ย

> > $105 / 4 = 26.25$ มี 2 ตัวที่มากกว่า (30 และ 45)

> [!question]- ข้อ 4: `np.random.normal(loc=70, scale=8, size=500)` ประมาณกี่ค่าอยู่ในช่วง 54–86
> > [!success]- เฉลย
> > 54–86 คือ $70 \pm 2 \times 8 = \mu \pm 2\sigma$ → ประมาณ 95% ของ 500 ≈ 475 ค่า (ใช้ 95.45% ได้ ≈ 477)

> [!question]- ข้อ 5: `triangle(6)` แบบชิดขวา แถว `i = 3` พิมพ์อะไร และทั้งรูปมี `#` กับช่องว่างกี่ตัว
> > [!success]- เฉลย
> > `linespace(2, 4)` → `"  ####"` · `#` รวม $6 \times 7 / 2 = 21$ · ช่องว่างรวม $6 \times 5 / 2 = 15$
