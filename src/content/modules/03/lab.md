## ส่วนที่ 3: การสุ่ม แผนภาพการกระจาย และสามเหลี่ยมชิดขวา (50 นาที)

### ขั้นตอนที่ 7: สุ่ม 100 ค่าแบบสม่ำเสมอและแบบปกติ
11. ใช้ `np.random.seed(2)` เพื่อให้ทุกคนได้ตัวเลขชุดเดียวกัน (ถ้าไม่ตั้ง seed ตัวเลขจะต่างกันทุกครั้งที่รัน แต่รูปร่างการกระจายเหมือนเดิม)

```python
import numpy as np
import matplotlib.pyplot as plt

np.random.seed(2)
xs = np.random.uniform(low=0, high=100, size=100)   # แจกแจงแบบสม่ำเสมอ 0–100
ys = np.random.normal(loc=50, scale=15, size=100)   # แจกแจงแบบปกติ μ=50 σ=15
print(len(xs), type(xs))
print(f"uniform: mean={xs.mean():.2f} min={xs.min():.2f} max={xs.max():.2f}")
print(f"normal : mean={ys.mean():.2f} std={ys.std():.2f} min={ys.min():.2f} max={ys.max():.2f}")
inside = ((ys >= 20) & (ys <= 80)).sum()
print(f"normal values in 20-80: {inside} / 100")
```
```
100 <class 'numpy.ndarray'>
uniform: mean=46.00 min=1.30 max=99.39
normal : mean=51.60 std=16.94 min=14.85 max=111.63
normal values in 20-80: 93 / 100
```

> [!question]- คำถาม 3.1: ค่าเฉลี่ยทางทฤษฎีของ `uniform(0, 100)` คือ 50 และของ `normal(loc=50)` คือ 50 แต่ผลที่ได้คือ 46.00 และ 51.60 — เพราะอะไร และ `max=111.63` ของแบบปกติผิดปกติหรือไม่
> > [!success]- แนวคำตอบ
> > ตัวอย่างเพียง 100 ค่าจึงคลาดเคลื่อนจากทฤษฎีได้ ยิ่ง `size` มากค่าเฉลี่ยยิ่งเข้าใกล้ 50 ส่วนการแจกแจงแบบปกติ **ไม่มีขอบเขต** ค่าเกิน 100 เกิดได้ (111.63 ห่างจาก μ ประมาณ 4σ ซึ่งหายาก แต่ไม่ผิด) ต่างจาก uniform ที่ไม่มีทางเกิน `high`

### ขั้นตอนที่ 10: สามเหลี่ยมชิดขวาด้วย linespace
15. เขียน `linespace(s, n)` แล้วทดสอบเดี่ยว ๆ ก่อน จากนั้นเขียน `triangle(n)` โดย **เรียก `linespace()`** เท่านั้น

```python
def linespace(s, n):
    for i in range(s):
        print(" ", end="")
    for i in range(n):
        print("#", end="")
    print()

def triangle(n):
    for i in range(n):
        linespace(n - i - 1, i + 1)

linespace(2, 3)
triangle(4)
```
