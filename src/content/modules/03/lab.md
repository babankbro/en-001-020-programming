### ขั้นตอนที่ 7: สุ่ม 100 ค่าแบบสม่ำเสมอและแบบปกติ
11. ใช้ `np.random.seed(2)` เพื่อให้ทุกคนได้ตัวเลขชุดเดียวกัน (ถ้าไม่ตั้ง seed ตัวเลขจะต่างกันทุกครั้งที่รัน แต่รูปร่างการกระจายเหมือนเดิม)

```python
import numpy as np
import matplotlib.pyplot as plt

np.random.seed(2)
xs = np.random.uniform(low=0, high=100, size=100)   # แจกแจงแบบสม่ำเสมอ 0–100
ys = np.random.normal(loc=50, scale=15, size=100)   # แจกแจงแบบปกติ μ=50 σ=15
print(len(xs), type(xs))
print(f"uniform: mean={xs.mean():.2f} min={xs.min():.2f} max={xs.max():.2f}")
print(f"normal : mean={ys.mean():.2f} std={ys.std():.2f} min={ys.min():.2f} max={ys.max():.2f}")
inside = ((ys >= 20) & (ys <= 80)).sum()
print(f"normal values in 20-80: {inside} / 100")
```

### ขั้นตอนที่ 10: สามเหลี่ยมชิดขวาด้วย linespace
15. เขียน `linespace(s, n)` แล้วทดสอบเดี่ยว ๆ ก่อน จากนั้นเขียน `triangle(n)` โดย **เรียก `linespace()`** เท่านั้น

```python
def linespace(s, n):
    for i in range(s):
        print(" ", end="")
    for i in range(n):
        print("#", end="")
    print()

def triangle(n):
    for i in range(n):
        linespace(n - i - 1, i + 1)

linespace(2, 3)
triangle(4)
```
```
  ###
   #
  ##
 ###
####
```

16. ไล่ค่า `triangle(4)`: แถว i = 0 → `linespace(3, 1)`, i = 1 → `linespace(2, 2)`, i = 2 → `linespace(1, 3)`, i = 3 → `linespace(0, 4)` ทุกแถวยาว 4 เสมอ
17. (การบ้าน) เขียน `pyramid(n)` ให้ `pyramid(3)` ได้

```

 ###
#####
```

![ตารางช่องของ linespace(2, 3) การไล่ค่า triangle(4) แต่ละแถว ตัวอย่างพลาดไปหนึ่ง (off-by-one) และตารางนับช่องสำหรับการบ้าน pyramid(3)](/infographics/03/lab-part3-triangle.svg)

**วิธีอ่านภาพ** (ช่องเทามีจุด · = ช่องว่าง `" "`, ช่องน้ำเงิน = `#`, ม่วง = เป้าหมายการบ้าน)
1. ① `linespace(2, 3)`: ช่องว่าง 2 ช่อง (s = 2) ตามด้วย `#` 3 ตัว (n = 3) แล้ว `print()` ขึ้นบรรทัดใหม่ จึงได้บรรทัดแรก `"  ###"` ยาว 5
2. ② `triangle(4)`: อ่านทีละแถว — `i` = 0 ถึง 3, คอลัมน์ `n-i-1` คือจำนวนช่องว่าง (3, 2, 1, 0) และ `i+1` คือจำนวน `#` (1, 2, 3, 4) ภาพตารางทางขวาแสดงแถวที่พิมพ์ ทุกแถวกว้าง 4 ช่องเท่ากัน ขอบขวาจึงตรงกัน (เส้นเขียว)
3. ③ ตัวอย่างพลาดไปหนึ่ง: ถ้าเขียน `linespace(n - i - 1, i)` แถว i = 0 จะไม่มี `#` เลย ได้สามเหลี่ยมสูงแค่ 3 (กรอบแดง) เทียบกับโค้ดถูก (กรอบเขียว) ที่ใช้ `i + 1`
4. ④ การบ้าน `pyramid(3)`: นับช่องว่างและ `#` ของแต่ละแถวจากภาพเป้าหมายสีม่วง แล้วกรอกช่อง `?` ในตาราง จากนั้นหาสูตรที่ขึ้นกับ `i` ก่อนเขียนโค้ด
5. กล่อง "จุดที่มักผิด": ลืม `end=""` ทำให้ `#` แต่ละตัวขึ้นบรรทัดใหม่ และลืม `print()` ท้าย `linespace` ทำให้ทุกแถวต่อกันเป็นบรรทัดเดียว
