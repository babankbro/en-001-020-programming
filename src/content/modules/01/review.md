## ภาพรวมบท
บทแรกวางรากฐานของทั้งรายวิชา ได้แก่ แผนที่ 8 บทสู่เกมยิงยานอวกาศ วงจรแก้ปัญหา 4 ขั้นพร้อมตารางไล่ค่า การติดตั้ง Python, VS Code, Jupyter/Colab และ pip การรันโปรแกรมทั้งแบบ `.py` และ `.ipynb` การอ่าน Traceback และการทบทวนพื้นฐานจาก EN-001-002 ที่ใช้ซ้ำทุกบท

![แผนที่แนวคิด 5 หัวข้อของบทที่ 1 เชื่อมกับหัวข้อกลางของบท](/infographics/01/summary.svg)

อ่านภาพจากวงรีกลางออกไปหาการ์ด 5 ใบตามหมายเลขหัวข้อ แต่ละการ์ดมีประเด็นที่ต้องจำ 4 ข้อ แถบด้านล่างบอกว่าหัวข้อทั้งห้าต่อยอดกันอย่างไร: รู้เส้นทาง → มีวิธีคิด → เครื่องมือพร้อม → รันและแก้ error ได้ → พื้นฐานพร้อมสำหรับบทที่ 2

## สิ่งที่ต้องจำ (Key Facts)

### 1. ภาพรวมรายวิชาและเส้นทางสร้างเกมยิงยานอวกาศ 8 บท
- 1 เครื่องมือ → 2 ไพทอน + เวกเตอร์ → 3 input/ลิสต์/แผนภูมิ → 4 ตาราง/สแตก → 5 Pygame ลูกบอลเด้ง → 6 เมทริกซ์/หมุน/ยาน → 7 ศัตรู → 8 กระสุน/ชน/กริด
- บท 1–4 เป็นไพทอนล้วนบน Notebook ส่วนบท 5–8 เป็น Pygame บนเครื่องตนเอง
- วงวนเกม 6 ขั้น: `event.get()` → `fill()` → อัปเดต → วาด → `flip()` → `tick(60)`
- ข้อสอบมีอัตนัย 60 คะแนนและปรนัย 40 ข้อ (ตอบผิดหักข้อละ 0.2) นำเอกสารลายมือเข้าได้ 5 แผ่น

### 2. การแก้ปัญหาด้วยโปรแกรม: วิเคราะห์โจทย์ → ออกแบบ → เขียน → ทดสอบ
- **วิเคราะห์** (input/output/กรณีพิเศษ) → **ออกแบบ** (pseudocode/ผังงาน) → **เขียนโค้ด** → **ทดสอบ** (trace table + รันจริง) และวนกลับเมื่อผลไม่ตรง
- trace table ต้องไล่ **ตามลำดับบรรทัดจริง** (`y += vy` ก่อน `vy += GRAVITY`)
- โค้ดที่ "รันได้แต่ผิด" อันตรายกว่า error เพราะไม่มีอะไรเตือน
- ทดสอบค่าขอบเสมอ เช่น ทดสอบทั้ง 50 และ 49 เมื่อเงื่อนไขคือ `score >= 50`

### 3. ติดตั้งและใช้เครื่องมือ: Python 3, VS Code, Jupyter/Colab และ pip
- `python --version` (macOS/Linux ใช้ `python3`) · บน Windows ต้องติ๊ก **Add python.exe to PATH**
- `python -m pip install pygame numpy matplotlib pandas` ติดตั้งให้ไพทอนตัวเดียวกับที่ใช้รัน
- ถ้าได้ `ModuleNotFoundError` ให้เทียบ `sys.executable` กับ `python -m pip --version` และเลือก interpreter ใน VS Code ให้ตรงกัน
- Colab มี numpy/matplotlib/pandas ติดตั้งมาแล้ว แต่ **เปิดหน้าต่าง Pygame ไม่ได้**
- virtual environment: `python -m venv .venv` แล้ว activate ก่อนติดตั้ง

### 4. โปรแกรมแรก การรัน .py กับ .ipynb และการอ่าน error message
- `.py` รันทั้งไฟล์จากบนลงล่าง ตัวแปรเริ่มใหม่ทุกครั้ง · `.ipynb` รันทีละเซลล์ ตัวแปรค้างใน kernel จนกว่าจะ Restart
- ใน Notebook บรรทัดสุดท้ายของเซลล์แสดงค่าเองได้ และ `In[n]` บอกลำดับที่เซลล์ถูกรันจริง
- อ่าน Traceback **จากบรรทัดสุดท้าย** (ชนิด + ข้อความ) → ชั้นล่างสุดคือบรรทัดที่พัง → ไล่ขึ้นไปหาผู้เรียก
- `SyntaxError`/`IndentationError` ถูกตรวจ **ก่อนรัน** จึงไม่มีบรรทัดใดทำงานเลย · error อื่นเกิด **ขณะรัน** และบรรทัดก่อนหน้าทำงานไปแล้ว

### 5. ทบทวนพื้นฐานจาก EN-001-002 ที่ต้องใช้ตลอดวิชา
- `/` ได้ float · `//` หารปัดลง · `%` เศษ · `**` ยกกำลัง · ไม่ควรเทียบ float ด้วย `==`
- `if/elif` เข้าเงื่อนไขแรกที่เป็นจริง · `range` ไม่รวมค่า stop · `while` ตรวจเงื่อนไขก่อนทุกรอบ
- ตัวแปรที่สร้างในฟังก์ชันเป็นตัวแปรภายใน · พารามิเตอร์มีค่าปริยายได้ · ฟังก์ชันที่ไม่มี `return` คืน `None`
- ลิสต์: ดัชนีเริ่มที่ 0 และ `-1` คือตัวสุดท้าย · พจนานุกรม: `get(key, default)` ไม่เกิด `KeyError` · คลาส: `__init__` และ `self`

## สูตร (Formulas)
| เรื่อง | สูตร | โค้ด | ตัวอย่างตัวเลข |
|---|---|---|---|
| ค่าเฉลี่ย 3 จำนวน | $\bar{x} = (n_1+n_2+n_3)/3$ | `avg = total / 3` | (5 + 10 + 15) / 3 = 10.0 |
| ตกภายใต้ความโน้มถ่วง (1 เฟรม) | $y_{t+1} = y_t + v_t,\ v_{t+1} = v_t + g$ | `y += vy` แล้ว `vy += GRAVITY` | เฟรม 1: y = 100, vy = 0.1 |
| ตำแหน่งหลัง $n$ เฟรม ($v_0 = 0$) | $y_n = y_0 + g\,\dfrac{n(n-1)}{2}$ | | n = 5: 100 + 0.1 × 10 = 101.0 |
| เวลาต่อเฟรม | $1000 / \text{FPS}$ ms | `clock.tick(60)` | ≈ 16.7 ms |
| สี RGB | $(R, G, B)$ แต่ละค่า 0–255 | `screen.fill((0, 0, 0))` | (0,0,255) น้ำเงิน · (255,255,0) เหลือง |
| เศษและการหารปัดลง | $a = (a /\!/ b)b + a \% b$ | `7 // 2`, `7 % 2` | 3 และ 1 |

## โค้ดที่ต้องเขียนได้โดยไม่ดู
```python
# ตรวจเวอร์ชันและตำแหน่งของ interpreter
import sys, pygame, numpy
print(sys.version.split()[0], sys.executable)
print(pygame.version.ver, numpy.__version__)

# หน้าต่าง Pygame ขั้นต่ำ
import pygame
pygame.init()
screen = pygame.display.set_mode((800, 600))
clock = pygame.time.Clock()
running = True
while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False
    screen.fill((0, 0, 0))
    pygame.display.flip()
    clock.tick(60)
pygame.quit()

# แก้ TypeError ตอนต่อข้อความกับตัวเลข
print(f"sum = {total}")       # หรือ "sum = " + str(total)
```

## ตัวอย่างไล่ค่า (Trace)
**ลูกบอลตก `y = 100, vy = 0, GRAVITY = 0.1` (`y += vy` ก่อน `vy += GRAVITY`)**

| เฟรม | `y` หลัง `y += vy` | `vy` หลัง `vy += 0.1` |
|---|---|---|
| เริ่ม | 100 | 0 |
| 1 | 100 + 0 = 100 | 0.1 |
| 2 | 100 + 0.1 = 100.1 | 0.2 |
| 3 | 100.1 + 0.2 = 100.3 | 0.3 |
| 4 | 100.3 + 0.3 = 100.6 | 0.4 |
| 5 | 100.6 + 0.4 = 101.0 | 0.5 |

**รันเซลล์ใน Notebook (A: `x = 5`, B: `x = x + 1; x`)**

| การกระทำ | `x` ใน kernel | ผลที่แสดง |
|---|---|---|
| รัน A | 5 | — |
| รัน B | 6 | `Out[2]: 6` |
| รัน B ซ้ำ | 7 | `Out[3]: 7` |
| Restart แล้วรัน B | — | `NameError` |

## ตัวเลขที่ออกสอบบ่อย
- ลูกบอลตก เฟรม 1–8: y = 100, 100.1, 100.3, 100.6, 101.0, 101.5, 102.1, 102.8 · vy = 0.1 … 0.8 · เฟรม 10: y = 104.5
- ถ้าสลับลำดับ (`vy += 0.1` ก่อน): y = 100.1, 100.3, 100.6, 101.0, 101.5, 102.1
- `sum(range(4))` = 6 · `sum(i*i for i in range(1, 5))` = 30 · `range(1, 6, 2)` → 1, 3, 5
- `7 / 2 = 3.5`, `7 // 2 = 3`, `7 % 2 = 1`, `2 ** 3 = 8` · `0.1 + 0.2 = 0.30000000000000004`
- `while count < 5: count += 2` หยุดที่ 6 · `len("Pygame")` = 6 · `"5" + "5"` = `"55"`
- `Ball(400, 3)` เรียก `move()` 2 ครั้งได้ `x = 406` · `Ball(400, -3)` เรียก 3 ครั้งได้ 391
- หน้าต่างขนาด 800×600 ที่ 60 FPS (≈ 16.7 ms ต่อเฟรม)
