```python
running = True
while running:
    for event in pygame.event.get():      # 1. รับเหตุการณ์ (ปุ่ม เมาส์ ปิดหน้าต่าง)
        if event.type == pygame.QUIT:
            running = False
    screen.fill((0, 0, 0))                # 2. ล้างจอด้วยสีดำ
    # 3. อัปเดตตำแหน่ง  4. วาดวัตถุ  (บทที่ 5 เป็นต้นไป)
    pygame.display.flip()                 # 5. แสดงภาพที่วาดเสร็จ
    clock.tick(60)                        # 6. คุมอัตราเฟรมไม่เกิน 60 FPS
```

## 2. การแก้ปัญหาด้วยโปรแกรม: วิเคราะห์โจทย์ → ออกแบบ → เขียน → ทดสอบ

### ทำไมไม่ลงมือพิมพ์โค้ดทันที
ผู้เริ่มต้นมักพิมพ์โค้ดก่อนแล้วค่อยคิด ผลคือ "โค้ดรันได้แต่ผิด" ซึ่งอันตรายกว่า error เพราะโปรแกรมไม่เตือน (ดูตัวอย่าง `dotv3` กับเวกเตอร์ 4 มิติในบทที่ 2) การแก้ปัญหาอย่างเป็นระบบมี 4 ขั้น:

| ขั้น | คำถามที่ต้องตอบ | ผลลัพธ์ |
|---|---|---|
| 1. วิเคราะห์โจทย์ (Analyze) | อินพุตคืออะไร เอาต์พุตคืออะไร มีข้อจำกัด/กรณีพิเศษอะไร | รายการ input/output |
| 2. ออกแบบ (Design) | ทำทีละขั้นอย่างไร แยกเป็นฟังก์ชันย่อยอะไรได้บ้าง | pseudocode / ผังงาน |
| 3. เขียนโค้ด (Code) | แปลง pseudocode เป็นไพทอนทีละบรรทัด | ไฟล์ `.py` / `.ipynb` |
| 4. ทดสอบ (Test) | ผลลัพธ์ตรงกับที่คำนวณมือหรือไม่ กรณีพิเศษผ่านหรือไม่ | trace table + ผลรัน |

### ตัวอย่างที่ 1: ค่าเฉลี่ยของตัวเลข 3 จำนวน
**วิเคราะห์:** อินพุต = จำนวน 3 ค่า (`n1`, `n2`, `n3`) · เอาต์พุต = ค่าเฉลี่ย · ข้อจำกัด = ต้องหารด้วย `/` ไม่ใช่ `//` เพื่อไม่ให้เศษหาย

**ออกแบบ (pseudocode):**
```text
1. กำหนด n1, n2, n3
2. total ← n1 + n2 + n3
3. avg ← total / 3
4. แสดง avg
```

**เขียนโค้ด** (จากบทที่ 2):
```python
n1, n2, n3 = 5, 10, 15
total = n1 + n2 + n3
avg = total / 3
print(f"average of {n1} {n2} and {n3} is {avg}.")
```
```
average of 5 10 and 15 is 10.0.
```

**ทดสอบ:** คำนวณมือ $(5+10+15)/3 = 30/3 = 10$ ตรงกับผลรัน `10.0` (เป็น float เพราะ `/`)

### ตัวอย่างที่ 2: ลูกบอลตกภายใต้ความโน้มถ่วง (จากบทที่ 5)
กฎการเคลื่อนที่ในเกมคือ "ตำแหน่งเปลี่ยนตามความเร็ว แล้วความเร็วเปลี่ยนตามความโน้มถ่วง" โดยใช้ค่าคงที่ `GRAVITY = 0.1` ตามโค้ดต้นฉบับ `ball.py`
```python
GRAVITY = 0.1
y, vy = 100, 0
for frame in range(1, 6):
    y += vy            # ตำแหน่งเปลี่ยนตามความเร็ว
    vy += GRAVITY      # ความเร็วเพิ่มตามความโน้มถ่วง
    print(frame, round(y, 2), round(vy, 2))
```

### ตารางไล่ค่า (Trace Table)
ตารางไล่ค่าคือการ "เป็นคอมพิวเตอร์ด้วยมือ" ไล่ค่าตัวแปรทีละรอบตามลำดับคำสั่ง — ต้องทำตามลำดับบรรทัดจริง (`y += vy` **ก่อน** `vy += GRAVITY`)

| เฟรม | `y` หลัง `y += vy` | `vy` หลัง `vy += 0.1` |
|---|---|---|
| เริ่ม | 100 | 0 |
| 1 | 100 + 0 = 100 | 0.1 |
| 2 | 100 + 0.1 = 100.1 | 0.2 |
| 3 | 100.1 + 0.2 = 100.3 | 0.3 |
| 4 | 100.3 + 0.3 = 100.6 | 0.4 |
| 5 | 100.6 + 0.4 = 101.0 | 0.5 |

```
1 100 0.1
2 100.1 0.2
3 100.3 0.3
4 100.6 0.4
5 101.0 0.5
```

> [!warning] ลำดับบรรทัดมีผลต่อคำตอบ
> ถ้าสลับเป็น `vy += GRAVITY` ก่อน `y += vy` เฟรมที่ 1 จะได้ `y = 100.1` ไม่ใช่ `100` ข้อสอบไล่ค่าทีละเฟรมในบทที่ 5–7 วัดตรงจุดนี้

> [!tip] จุดสังเกตจากตาราง
> `y` ตกเร็วขึ้นเรื่อย ๆ (เพิ่ม 0, 0.1, 0.2, 0.3, 0.4) เพราะ `vy` โตเป็นเส้นตรง นี่คือการตกแบบมีความเร่ง (Accelerated Motion) ที่จะเรียนในบทที่ 5

### ผังงาน (Flowchart) แบบข้อความ
```text
เริ่ม → กำหนด y=100, vy=0 → [เฟรม ≤ 5?] ──ไม่──→ จบ
                                 │ใช่
                                 ↓
                         y ← y + vy
                         vy ← vy + 0.1
                         แสดงค่า → กลับไปตรวจเงื่อนไข
```

ทบทวนแนวคิดการแยกงานเป็นขั้น ๆ ได้ที่ [EN-001-002 บท 01 เริ่มต้นเขียนโปรแกรม](https://en-001-002-computer-programming.vercel.app/module/01)

> [!question]- ฝึกทำ: จงไล่ค่า `y` และ `vy` ต่อจนถึงเฟรมที่ 8 (ไม่ต้องรันโปรแกรม)
> > [!success]- เฉลย
> > เฟรม 6: y = 101.0 + 0.5 = 101.5, vy = 0.6 · เฟรม 7: y = 102.1, vy = 0.7 · เฟรม 8: y = 102.8, vy = 0.8

> [!question]- ฝึกทำ: จงเขียน pseudocode สำหรับ "รับคะแนน 1 ค่า ถ้า ≥ 50 แสดง PASS ไม่เช่นนั้นแสดง FAIL" แล้วระบุอินพุต เอาต์พุต และกรณีพิเศษที่ควรทดสอบ
> > [!success]- เฉลย
> > อินพุต: คะแนน (จำนวน) · เอาต์พุต: ข้อความ PASS/FAIL · pseudocode: `1. รับ score  2. ถ้า score >= 50 แสดง "PASS" ไม่เช่นนั้นแสดง "FAIL"` · กรณีพิเศษ: ค่าขอบ 50 (ต้อง PASS), 49 (FAIL), อินพุตที่ไม่ใช่ตัวเลข (เกิด `ValueError` เมื่อแปลงด้วย `int()`)

> [!question]- ฝึกทำ: จงไล่ค่าโค้ดต่อไปนี้ด้วย trace table แล้วบอกผลลัพธ์
> ```python
> s = 0
> for i in range(4):
>     s += i
> print(s)
> ```
> > [!success]- เฉลย
> > i = 0 → s = 0 · i = 1 → s = 1 · i = 2 → s = 3 · i = 3 → s = 6 → พิมพ์ `6` (`range(4)` ให้ 0–3 ไม่รวม 4)

### โครงสร้างของ Traceback
เมื่อโปรแกรมผิดพลาดตอนรัน ไพทอนพิมพ์ **Traceback** ให้อ่านจาก **บรรทัดสุดท้ายก่อน** (ชนิดและข้อความของ error) แล้วย้อนขึ้นไปดูว่าเกิดที่ไฟล์ใด บรรทัดใด
```python
print(nmae)
```
```
Traceback (most recent call last):
  File "lab01.py", line 1, in <module>
    print(nmae)
          ^^^^
NameError: name 'nmae' is not defined
```
อ่านว่า: ชนิด `NameError` · ข้อความ "ชื่อ `nmae` ยังไม่ถูกนิยาม" · เกิดที่ `lab01.py` บรรทัด 1 · เครื่องหมาย `^^^^` ชี้ตำแหน่งในบรรทัด → สะกดชื่อตัวแปรผิด

### ชนิดข้อผิดพลาดที่พบบ่อย
| ชนิด | เกิดเมื่อ | ตัวอย่างโค้ด | บรรทัดสุดท้ายของ Traceback |
|---|---|---|---|
| `SyntaxError` | ไวยากรณ์ผิด โปรแกรม **ไม่เริ่มรันเลย** | `print("Hello"` | `SyntaxError: '(' was never closed` |
| `IndentationError` | ย่อหน้าผิด (ชนิดย่อยของ SyntaxError) | `for i in range(3):` แล้วบรรทัดถัดไปไม่ย่อหน้า | `IndentationError: expected an indented block after 'for' statement on line 1` |
| `NameError` | ใช้ชื่อที่ยังไม่นิยาม | `print(nmae)` | `NameError: name 'nmae' is not defined` |
| `TypeError` | ชนิดข้อมูลไม่เข้ากัน | `"age: " + 20` | `TypeError: can only concatenate str (not "int") to str` |
| `ValueError` | ชนิดถูกแต่ค่าใช้ไม่ได้ | `int("abc")` | `ValueError: invalid literal for int() with base 10: 'abc'` |
| `ZeroDivisionError` | หารด้วยศูนย์ | `10 / 0` | `ZeroDivisionError: division by zero` |
| `IndexError` | ดัชนีเกินลิสต์ | `[1, 2, 3][3]` | `IndexError: list index out of range` |
| `ModuleNotFoundError` | ไม่พบไลบรารี | `import pygame` | `ModuleNotFoundError: No module named 'pygame'` |

> [!note] SyntaxError ต่างจาก error อื่น
> `SyntaxError`/`IndentationError` ถูกตรวจพบ **ก่อน** โปรแกรมเริ่มทำงาน จึงไม่มีบรรทัดไหนรันเลยแม้บรรทัดแรก ๆ จะถูกต้อง ส่วน `NameError`, `TypeError` ฯลฯ เป็น **ข้อผิดพลาดขณะรัน (Runtime Error)** บรรทัดก่อนหน้าทำงานไปแล้ว

### แก้ `TypeError` ด้วยการแปลงชนิดหรือ f-string
```python
age = 20
print("age: " + str(age))     # แปลงเป็น str ก่อนต่อ
print(f"age: {age}")          # หรือใช้ f-string (แนะนำ)
print("age:", age)            # หรือคั่นด้วยจุลภาค
```
```
age: 20
age: 20
age: 20
```
เรื่องนี้จะกลับมาในบทที่ 3 เมื่อใช้ `input()` ซึ่งคืนค่าเป็น `str` เสมอ (`"15" + "5"` ได้ `"155"`)

> [!tip] ขั้นตอนแก้ bug อย่างเป็นระบบ
> 1. อ่านบรรทัดสุดท้ายของ Traceback → รู้ชนิดและข้อความ
> 2. ดูเลขบรรทัดและเครื่องหมาย `^` → รู้ตำแหน่ง
> 3. ตั้งสมมติฐาน (สะกดผิด? ชนิดผิด? ยังไม่รันเซลล์บน?) แล้วแก้ **ทีละอย่าง**
> 4. รันซ้ำ ถ้า error เปลี่ยนชนิด แปลว่าคืบหน้า

> [!question]- ฝึกทำ: โค้ดต่อไปนี้เกิดข้อผิดพลาดชนิดใด และบรรทัดแรกจะพิมพ์ออกมาหรือไม่
> ```python
> print("start")
> total = 10
> print("total = " + total)
> ```
> > [!success]- เฉลย
> > พิมพ์ `start` ก่อน แล้วเกิด `TypeError: can only concatenate str (not "int") to str` ที่บรรทัด 3 เพราะเป็น runtime error บรรทัดก่อนหน้าทำงานไปแล้ว แก้ด้วย `f"total = {total}"`

> [!question]- ฝึกทำ: โค้ดต่อไปนี้เกิดข้อผิดพลาดชนิดใด และบรรทัดแรกจะพิมพ์ออกมาหรือไม่
> ```python
> print("start")
> for i in range(3):
> print(i)
> ```
> > [!success]- เฉลย
> > `IndentationError` — ไม่พิมพ์ `start` เลย เพราะไวยากรณ์ถูกตรวจก่อนรัน ต้องย่อหน้า `print(i)` เข้าไป 4 ช่องว่าง

> [!question]- ฝึกทำ: `print(len("Pygame"), "5" + "5", 5 + 5)` แสดงผลอะไร
> > [!success]- เฉลย
> > `6 55 10` — `len` นับอักขระ, `"5" + "5"` ต่อสายอักขระ, `5 + 5` บวกตัวเลข

### 5.6 คลาสและวัตถุ — [EN-001-002 บท 08](https://en-001-002-computer-programming.vercel.app/module/08)
```python
class Ball:
    def __init__(self, x, vx):      # ตัวสร้าง (Constructor) ทำงานตอน Ball(...)
        self.x = x                  # แอตทริบิวต์ (Attribute) ของวัตถุนี้
        self.vx = vx

    def move(self):                 # เมธอด (Method) รับ self เสมอ
        self.x += self.vx

b = Ball(400, 3)
b.move()
b.move()
print(b.x)
```
```
406
```
`self` คือวัตถุที่กำลังถูกเรียก (`b`) · `b.move()` เท่ากับ `Ball.move(b)` · วัตถุแต่ละตัวมี `x`, `vx` ของตนเอง จึงสร้างลูกบอล 100 ลูกที่เคลื่อนที่อิสระกันได้
