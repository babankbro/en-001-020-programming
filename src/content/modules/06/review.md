## ภาพรวมบท
บทนี้เปลี่ยนจากฟังก์ชันเวกเตอร์ที่เขียนเองมาใช้ NumPy บวก ลบ หาขนาด และเวกเตอร์หนึ่งหน่วย คูณเมทริกซ์แบบแถว·คอลัมน์ แปลงองศา–เรเดียนและหามุมด้วย `atan2` แล้วสร้างเมทริกซ์การหมุนเพื่อหมุนจุดรอบจุดศูนย์กลางใด ๆ สุดท้ายรวมทุกอย่างเป็นตรรกะควบคุมยานอวกาศ: ปุ่ม → ทิศ → มุมเป้าหมาย → หมุนทางสั้น → เร่ง → แรงเสียดทาน

**วิธีอ่านภาพ**
1. การ์ด 1 เวกเตอร์ NumPy: B − A = (1, 5) − (4, 1) = (−3, 4) ยาว 5 (กับดัก: ลิสต์บวกกันคือการต่อกัน)
2. การ์ด 2 เมทริกซ์: ช่อง (i, j) = แถว i · คอลัมน์ j เช่น c₁₂ = 22 และต้องใช้ `@` ไม่ใช่ `*`
3. การ์ด 3 มุมและ atan2: แปลงองศาเป็นเรเดียนก่อนเสมอ และ atan2(4, 3) = 53.13°
4. การ์ด 4 เมทริกซ์การหมุน: หมุนรอบจุด c ด้วย R(p − c) + c เช่น (7, 3) รอบ (3, 3) ไป 90° ได้ (3, 7)
5. การ์ด 5 รวมทุกอย่างเป็นยานอวกาศ อ่านตามลูกศรงู ①→⑥: ปุ่ม ↑+→ → normalize → มุมเป้า −45° → หมุนทางสั้น → เร่งตามทิศ → แรงเสียดทาน (วงเล็บใต้กล่องบอกว่าใช้ความรู้หัวข้อใด)

## สิ่งที่ต้องจำ (Key Facts)

### 1. เวกเตอร์ด้วย NumPy: บวก ลบ ขนาด และเวกเตอร์หนึ่งหน่วย
- `np.array([1,2]) + np.array([3,4])` = `[4 6]` (บวกทีละสมาชิก) · `[1,2] + [3,4]` = `[1, 2, 3, 4]` (ต่อลิสต์) · `[1,2] * 2` = `[1, 2, 1, 2]`
- ผลลัพธ์ NumPy พิมพ์ **ไม่มีจุลภาค** `[4 5 3]` ส่วนลิสต์มีจุลภาค
- `np.linalg.norm(v)` = ขนาด · `v / np.linalg.norm(v)` = เวกเตอร์หนึ่งหน่วย · `np.dot(u, v)` = ผลคูณจุด
- `B - A` = ลูกศรจาก A ไป B ขนาดคือระยะห่าง
- ห้าม normalize เวกเตอร์ศูนย์ (`nan` / `ValueError`) · `np.linspace(a, b, n)` ให้ n ค่า **รวมปลาย** ห่างกัน $(b-a)/(n-1)$

### 2. เมทริกซ์และการคูณเมทริกซ์
- $A_{m \times n} B_{n \times p} = C_{m \times p}$ — คอลัมน์ตัวหน้าต้องเท่ากับแถวตัวหลัง
- $c_{ij}$ = (แถว i ของ A) · (คอลัมน์ j ของ B)
- `A @ B` = `np.matmul(A, B)` = `A.dot(B)` · `A * B` คือคูณทีละตำแหน่ง
- โดยทั่วไป $AB \ne BA$ · $AI = IA = A$ · `np.eye(3)` ได้ชนิด float
- เมทริกซ์ 2×2 คูณเวกเตอร์ = แปลงจุดหนึ่งเป็นอีกจุดหนึ่ง

### 3. องศา เรเดียน ตรีโกณมิติ และ atan2
- $\theta_{rad} = \theta_{deg} \times \pi/180$ · `math.radians`, `np.radians`, `math.degrees`
- `math.sin/cos`, `np.cos` รับ **เรเดียน** (`math.cos(30)` ≈ 0.154 ไม่ใช่ 0.866)
- จุดบนวงกลม $(c_x + r\cos\theta,\ c_y + r\sin\theta)$ · $(\cos\theta, \sin\theta)$ ยาว 1 เสมอ
- `math.atan2(y, x)` รับ **y ก่อน** คืนมุมในช่วง (−180°, 180°] แยกจตุภาคได้ ต่างจาก `atan(y/x)`
- ครึ่งบน (y > 0) ได้มุมบวก ครึ่งล่าง (y < 0) ได้มุมลบ

### 4. เมทริกซ์การหมุนและการหมุนรอบจุดใด ๆ
- $R(\theta) = \begin{bmatrix}\cos\theta & -\sin\theta\\ \sin\theta & \cos\theta\end{bmatrix}$ หมุนทวนเข็มรอบ (0, 0) เมื่อ y ชี้ขึ้น
- หมุน 90°: $(x, y) \to (-y, x)$ · หมุน 180°: $(x, y) \to (-x, -y)$
- หมุนรอบ c: `R.dot(p - c) + c` (เลื่อน → หมุน → เลื่อนกลับ)
- การหมุนไม่เปลี่ยนระยะห่างจากจุดศูนย์กลาง · $R(\beta)R(\alpha) = R(\alpha+\beta)$ · หมุนกลับ $R(-\theta) = R(\theta)^T$
- `FuncAnimation(fig, animate, frames=180, interval=20)` + `theta_deg = frame * 2` → ครบรอบใน 3.6 วินาที

### 5. ควบคุมยานอวกาศด้วยเวกเตอร์และมุม
- ปุ่ม → `input_dir` (ขึ้น = y − 1) → `normalize()` ถ้า `length() > 0`
- `target_angle = degrees(atan2(-y, x)) - 90` (กลับแกน y และให้ 0 = หัวขึ้น)
- `diff = (target - angle) % 360` ถ้า > 180 ลบ 360 · `angle += diff * 0.15` (Lerp)
- แรงขับ `accel = (cos(angle+90), -sin(angle+90)) × thrust`
- ปล่อยปุ่ม `velocity *= friction` · จำกัด `scale_to_length(max_speed)` · เก็บ `pos` เป็น float

## โค้ดที่ต้องเขียนได้โดยไม่ดู
```python
import math
import numpy as np

def rotate_about(point, center, theta_deg):
    t = np.radians(theta_deg)
    R = np.array([[np.cos(t), -np.sin(t)],
                  [np.sin(t),  np.cos(t)]])
    p, c = np.array(point), np.array(center)
    return R.dot(p - c) + c                 # เลื่อน → หมุน → เลื่อนกลับ

def target_angle(dx, dy):
    return math.degrees(math.atan2(-dy, dx)) - 90

def shortest_diff(angle, target):
    d = (target - angle) % 360
    if d > 180:
        d -= 360
    return d

def accel_from_angle(angle, thrust):
    rad = math.radians(angle + 90)
    return (math.cos(rad) * thrust, -math.sin(rad) * thrust)
```

## ทดสอบตัวเอง 5 ข้อ

> [!question]- 1. A = (5, 1), B = (2, 5) จงหา `B - A`, ขนาด และเวกเตอร์หนึ่งหน่วยของ `B - A`
> > [!success]- เฉลย
> > `B - A = [-3 4]`, ขนาด $\sqrt{9 + 16} = 5$, หนึ่งหน่วย $(-0.6, 0.8)$

> [!question]- 2. จงหา $\begin{bmatrix}1&0\\2&3\end{bmatrix}\begin{bmatrix}4&1\\0&2\end{bmatrix}$
> > [!success]- เฉลย
> > $c_{11} = 1\cdot4 + 0\cdot0 = 4$, $c_{12} = 1\cdot1 + 0\cdot2 = 1$, $c_{21} = 2\cdot4 + 3\cdot0 = 8$, $c_{22} = 2\cdot1 + 3\cdot2 = 8$ → $\begin{bmatrix}4&1\\8&8\end{bmatrix}$

> [!question]- 3. `math.degrees(math.atan2(-2, 2))` และ `math.degrees(math.atan2(2, -2))` ได้ค่าใด
> > [!success]- เฉลย
> > −45.0 (เวกเตอร์ (2, −2) อยู่ครึ่งล่างขวา) และ 135.0 (เวกเตอร์ (−2, 2) อยู่ครึ่งบนซ้าย) — สังเกตว่าอาร์กิวเมนต์แรกคือ y

> [!question]- 4. หมุนจุด (6, 2) รอบจุดศูนย์กลาง (2, 2) ไป 90°
> > [!success]- เฉลย
> > เลื่อน (6, 2) − (2, 2) = (4, 0) → หมุน 90° ได้ (0, 4) → เลื่อนกลับ (0, 4) + (2, 2) = **(2, 6)**

> [!question]- 5. ยานหันอยู่ −30° มุมเป้าหมาย 200° (smoothness 0.15) จงหา angle_diff และมุมใหม่หลัง 1 เฟรม
